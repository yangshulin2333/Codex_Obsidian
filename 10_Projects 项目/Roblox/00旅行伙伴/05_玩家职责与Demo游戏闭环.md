# 玩家职责与 Demo 游戏闭环

用户已确认：玩家担任岛屿经营者、伙伴照料者和收获决策者；伙伴自行安排生活和探索。自主性主要体现在伙伴的日常选择与探索安排，建设、经营预算和集装箱处置由玩家决定。本文件确立目标设计，不代表待开发功能已经接入。

## 玩家与伙伴职责

| 内容 | 玩家负责 | 伙伴负责 |
|---|---|---|
| 出游准备 | 购买补给、主动装入行囊、安排预算和箱位，选择是否暂缓，后续可提出地点愿望 | 从合法条件中选择时间、已解锁海域和航程 |
| 日常生活 | 提供和改善家园生活条件 | 在已有条件下选择休息、看书、散步等活动 |
| 旅行收获 | 决定开箱、主动上架拍卖、保留封箱，决定入库物品是否出售 | 带回箱子、特产和旅途见闻 |
| 建设与收藏 | 决定住宅与船的升级优先级，查看明信片、记录发现和安排收藏 | 在扩展后的环境和探索范围中出现新的生活表现与见闻 |

伙伴是通用角色概念，海蛙是第一位伙伴。更换角色或模型不改变经营、任务和资产规则。

## 集装箱处置权

第一版由玩家决定打开集装箱、主动上架拍卖或继续保留。伙伴可以搬运、观察、表达兴趣，但不会自行开箱、卖箱或出售玩家物品。

玩家主动上架后，由服务器执行拍卖结算，是执行玩家已经作出的决定。拍卖模式、报价、成交时长和流拍规则尚未冻结，不能提前写入具体交易参数。

开箱偏向获得建设材料、发现物品和收藏；整箱拍卖偏向获得经营资金。整箱成交后，卖家不会同时再获得箱内物品和木材。打开或成交才释放对应箱位，上架期间不能同时开箱或借上架绕过容量约束。

封箱品质可见、箱内内容与实际总价值未知，是前轮讨论的目标方向。具体展示及交易方案仍待细化；当前程序仍隐藏封箱品质。

## 经营循环

购买并装载补给 → 伙伴自主打捞 → 玩家选择开箱或整箱拍卖 → 获得材料、物品与金币 → 升级住宅和船 → 扩展存放、生活与探索条件 → 准备下一趟。

玩家的选择应有不同用途。缺建设材料时可以开箱，缺经营资金时可以考虑整箱拍卖；先升级船扩大海域范围，先升级住宅增加存放空间。开出的商品可由玩家出售，已发现的图鉴记录保留。

玩家不应只负责定期补给和清箱。箱子取舍、建设目标和收藏进展需要形成持续可见的变化，不能把全部经营收益仅用于补充下一趟航海消耗。

## 陪伴与收藏循环

伙伴日常生活与休闲旅游 → 带回见闻、照片和明信片 → 玩家阅读、收藏并改善生活空间 → 看见伙伴生活出现变化 → 期待新的探索与见闻。

建设应能改善伙伴的生活表现，例如住宅升级后增加可用的看书位置。具体活动点和解锁安排需按白模与模型替换边界进一步规划，不据此新增尚未确认的装修系统或购买费用。

打捞远航与休闲旅游的资源边界见 [[04_打捞远航与休闲旅游_方向记录]]。休闲旅游的补给、奖励、频率与离线累计规则仍待讨论；不能把未定义的旅游循环自动接入现有航海收益。

表现方式已确认采用 [[06_3D主岛与2D旅途表现方案|3D 主岛与 2D 旅途]]：玩家经营和伙伴岛内生活保持 3D，远方旅行与收藏见闻用 2D，不因表现切换改变任务或收益规则。

## 第一版日常生活范围

第一版先实现休息、看书、短距离散步。使用几个固定活动点与简单动作，由伙伴自行选择和切换；准备或出航时能结束当前活动。箱区满、缺行囊补给等任务等待状态下，伙伴仍可以继续岛内生活。

生活活动与航海任务分开。任务状态管理补给、箱位、准备与航次；生活行为选择和模型表现不能替玩家作出经济决定，也不能因播放动作而扣航海补给或新增资源收益。

吃饭随后可作为生活表现加入，食物消耗规则另行规划。串门在基础联机稳定后再扩展。活动点、动作时长、选择频率和中断衔接尚未冻结。
