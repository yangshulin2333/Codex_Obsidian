# 封箱品质展示：实现与自测

工程：`F:\HunyueRoblox\TravelBuddy`。本阶段让已归家入库的封箱在开箱前显示品质，箱内物品、数量和实际价值继续保密。代码与原生模板已完成，待用户自测；本轮没有运行测试、构建、Studio 或测试交易，也没有新增 Excel 配置或执行导表。

规则承接 [离线多趟与收获汇总](09_离线多趟与收获汇总_实现与自测.md) 和 [伙伴岛内生活](10_伙伴岛内生活_实现与自测.md)，存档仍为 v5。

## 玩家能看到什么

| 服务端品质 | 展示名称 |
|---|---|
| `Common` | 普通 |
| `Life` | 生活 |
| `Fine` | 精良 |
| 缺失或未知的公开展示值 | 品质未知 |

“品质未知”是展示防错降级，不是新增随机品质。当前实际抽取的三种品质都能在开箱前显示。

已入库封箱的列表、开箱按钮、现有请求提示与 3D 标牌显示同一品质名称。旅行收获明细通过仍在箱区的封箱 ID 关联品质；箱子已经处理时，继续显示原有已处理说明，不用历史记录推测箱内内容。

开箱沿用原有按钮、距离、所属关系与服务端请求，不增加二次确认流程。显示品质不会自动开箱、出售或上架，也不会展示品池、开箱预览或估值。

## 公开数据与存档

`TravelDomain.Public` 只为已经入库的 `state.Containers` 增加 `Quality`，合法值为 `Common/Life/Fine`。箱内 `Items/Wood/Value` 不随封箱品质一起公开；在途的 `Journey.Container`、最近收获、旅行历史和未读汇总不新增箱奖励字段。

品质早在出发时抽取并写入奖励快照，展示直接读取已保存品质。刷新、重进或旧封箱显示都不重抽，不改存档版本，不需要数据迁移。普通开箱成功后仍由原有结算逻辑发放奖励一次，实际开出的品质与该封箱保存的品质一致。

共享 `ContainerQualityPresentation` 只保存 `Names/UnknownName` 展示词。服务端决定真实品质，客户端与 World 只消费公开枚举；共享模块不包含品池、物品概率或价值计算。

## 模型与交互分开

封箱外观、开箱交互、碰撞和品质标牌分别维护，替换美术时保留稳定合同。

| 节点或模板 | 职责 |
|---|---|
| `Root` | 封箱稳定原点与 pivot 部件 |
| `InteractionAnchor/OpenContainerPrompt` | 开箱入口；保留所属关系、交互名称与位置合同 |
| `Collision` | 独立透明简单碰撞 |
| `QualityAnchor` | 品质标牌的独立挂载位置 |
| `Appearance` | 可替换的箱体与标牌外观，外观零件 `CanCollide=false`；实际碰撞单独维护 |
| `ContainerQualityBadge` Template | 独立可选 Model，含 Root 和同名 BillboardGui；`Common/Life/Fine/Unknown` 预设 Frame 各有 Label，颜色与布局保存在原生资源 |

World 只读取公开品质、选择标牌可见状态并改名称文字，合法品质可写入 Model 的公开 `Quality` 属性；不在运行时重排标牌或改色，不把箱奖励写进外观。标牌按 `QualityAnchor` 摆放，旧模型缺少该锚点时回退箱位。缺牌或缺 Label 时回退 `ContainerSign` 与开箱 Prompt 文本，开箱业务继续可用。

每次 Render 都更新同一箱 ID 的品质显示；箱子处理或玩家离开后，清理对应标牌与缓存。原来的开箱提示属性、键位与交互入口保持原有合同。

## 用户自测

1. **三品质一致**：正常游玩获得普通、生活、精良封箱，核对列表、开箱按钮、提示和 3D 标牌名称一致；首次获得哪种品质仍由旅行抽取规则决定。
2. **未知降级**：在展示兼容场景检查缺失或未知品质显示“品质未知”；缺少可选标牌节点时仍能看文本、正常开箱。不要改永久存档来制造坏品质。
3. **开前保密**：检查开箱前已入库封箱条目的公开或网络快照，只新增 `Quality`，不含该封箱的 `Items/Wood/Value`；在途航次与历史汇总没有新增箱奖励字段。
4. **开后一致**：打开封箱，核对开箱结果品质一致；重复点击或原编号重试不会重复发放物品和木材，且没有新增二次确认页。
5. **旧档与重进**：使用已有封箱重进，核对封箱 ID、品质及资产保留；刷新、退出重进不重抽，旧封箱不需要重新旅行或迁移才能显示品质。
6. **替换外观**：只替换 `Appearance`，保留 Root、交互、碰撞和品质锚点，再确认品质标牌及开箱入口仍可用；箱内内容与价值继续保密。

尚未验证：以上玩法与模板替换、真实旧档重进、网络保密、多人归属、手机展示和操作重试。相关测试源已同步品质断言与必要替身，但没有执行；本轮没有测试、格式校验、构建、Studio 验收或交易记录，旧构建 Place 不代表本轮代码已验证。
