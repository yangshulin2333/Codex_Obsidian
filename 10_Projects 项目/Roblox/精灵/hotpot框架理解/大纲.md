**现在先从第 1 课开始：setmetatable**
Lua 里本来没有传统意义上的 `class`。这个项目的“类”，其实是用 `table + setmetatable` 模拟出来的。

先看普通表：

```lua
local t = {}
t.name = "BagGui"

print(t.name)
```

这很好懂，`t` 是一个表，里面有 `name`。

但如果你访问一个不存在的字段：

```lua
print(t.Show)
```

正常结果是 `nil`。

`setmetatable` 的作用是：给这个表加一套“备用规则”。

最常见的是 `__index`：

```lua
local parent = {}
parent.Show = function()
    print("show ui")
end

local child = {}

setmetatable(child, {
    __index = parent
})

child.Show()
```

这里 `child` 自己没有 `Show`，Lua 找不到时，会去 `__index = parent` 里面找。于是 `child.Show()` 最后调用到了 `parent.Show`。

这就是继承的底层原理。

对应到项目里：

```lua
local c = hotpot.class.new(script, hotpot.files.HotpotScreenBase())
```

可以理解成：

```text
BagGui 自己没有 Show / Hide
但是它的父类 HotpotScreenBase 有
所以 BagGui 对象也能调用 Show / Hide
```

再看 `__call`。

普通表不能这样调用：

```lua
local t = {}
t()
```

会报错，因为表不是函数。

但如果给它设置 `__call`：

```lua
local t = {}

setmetatable(t, {
    __call = function()
        print("table 被当成函数调用了")
    end
})

t()
```

这时 `t()` 就能执行。

对应到项目里，`Class.lua` 让 `c` 这个类表可以被当成函数调用：

```lua
local obj = c()
```

这不是普通函数，而是触发了 `__call`。它会创建一个对象，然后调用 `ctor` 构造函数。

所以你看到：

```lua
function c.new()
    return c()
end
```

可以翻译成：

```text
c.new() 的作用就是创建一个 c 类对象
真正干活的是 c()，也就是 __call
```

**这一课你先记住 3 句话**
1. `setmetatable` 是给 table 加“隐藏规则”。
2. `__index` 是“自己没有，就去别人那里找”，用来模拟继承。
3. `__call` 是“让 table 可以像函数一样被调用”，用来模拟创建对象。

