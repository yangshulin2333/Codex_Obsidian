**吸走模块边界**

吸走可以做，但要拆成两层：

Server 仍然只负责权威判定：

- 是否掉落。
- 谁拥有掉落。
- 什么时候可拾取。
- 玩家是否进入有效拾取范围。
- 是否写入 `Resources.SmallGear` 和 `Progression.Exp`。

Client 只负责表现：

- 掉落物抛出。
- 落地。
- 待机轻微浮动。
- 拾取时飞向目标。
- 消失和奖励文字。

后续磁铁玩家要复用时，只换“吸向谁”和“什么条件触发”，不改动画核心。

**002.1 子模块**

1. `002.1A EnemyPresentation / 训练怪表现补强`  
    做血条、受击反馈、死亡状态、刷新反馈。验收不是 Output，而是玩家能看懂敌人状态。
    
2. `002.1B LootDropPresentation / 掉落物表现补强`  
    做 SmallGear 可识别模型、落地、待机、拾取吸走、过期消失。
    
3. `002.1C RewardFeedbackBridge / 奖励临时反馈`  
    正式 HUD 前，至少显示本地 `+1 SmallGear` 和 `+4 Exp`。这不是完整 HUD，只是反馈桥。
    
4. `002.1D WorkflowRepair / 文档和验收修复`  
    更新 002 父级卡，标记原 002C 为 `Implemented but Quality Not Accepted`，补齐“不做事项归属表”，以后不能只写“不做”。
    

**明确验收标准**

002.1 完成后，玩家必须能看到：

- M001 是 R15 训练假人。
- 头顶血条有填充变化，不只是 `20 / 20` 文本。
- 攻击后有受击反馈。
- 死亡状态明确。
- SmallGear 是齿轮/玩具零件形象，不是抽象球。
- 掉落物先落地，再可拾取。
- 拾取时可以吸向玩家，但这是表现模块，不代表 Client 决定奖励。
- 拾取后显示 `+1 SmallGear` 和 `+4 Exp`。
- 多人时私有掉落仍只属于击杀者。
- Server 权威不被破坏。
