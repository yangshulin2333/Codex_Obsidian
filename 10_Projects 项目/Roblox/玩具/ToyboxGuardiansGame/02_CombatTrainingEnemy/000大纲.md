# CombatTrainingEnemy / 第一个真实玩法 Feature 计划

## Summary

严格说文档编号是 `002_CombatTrainingEnemy`，因为 `001_FirstLoop` 已占了编号；但从玩法意义上说，`FirstLoop` 只是技术验证闭环，**现在这个才是第一个真实玩法 Feature**。

这个 Feature 的完整目标是：

```text
玩家看到训练怪
-> 玩家攻击训练怪
-> Server 判定命中和扣血
-> 训练怪死亡
-> Server 生成玩家私有 SmallGear 掉落
-> 玩家靠近拾取
-> Server 写入资源和少量 Exp
-> Client 显示反馈
```

本 Feature 不一次性写完，拆成 3 个小闭环：`002A / 002B / 002C`。

## Feature Plan

### 002A TrainingEnemyWorldStub

当前状态：已实现代码，等待 Studio Play 验收。

目标：

- 场景中出现 R15 训练怪。
- Server 能识别它。
- 玩家能看到头顶血量 `20 / 20`。
- 训练怪站桩，不移动、不攻击、不掉落。

验收：

- `Workspace/GameRuntime/Enemies/M001_TrainingDummy_001` 存在。
- 玩家能看到 R15 训练假人。
- 头顶 `BillboardGui` 显示 `20 / 20`。
- Server Output 有 `TrainingEnemyService` spawn 日志。

### 002B CombatAttackAndDamage

前置：002A Studio Play 验收通过，并单独确认 002B TDD。

目标：

- 玩家点击攻击。
- Client 只发送攻击意图。
- Server 校验目标、距离、角度、冷却、存活状态。
- Server 扣训练怪血量。
- Server 同步训练怪血量变化。

接口：

- 新增 `Combat.Attack`，Client -> Server。
- Payload：`requestId`、`clientTargetId?`、`attackTime`。
- Server 不相信 Client 的伤害、命中、血量、死亡结果。

默认规则：

- 攻击距离：`6 studs`。
- 攻击角度：`120 degrees`。
- 冷却：约 `0.65 - 0.7s`。
- 伤害：`10`。
- 训练怪血量：`20`，两次有效攻击死亡。

验收：

- 6 studs 内攻击，血量 `20 -> 10 -> 0`。
- 太远攻击返回或显示 `TOO_FAR`。
- 快速连点被 `COOLDOWN` 拒绝。
- 死亡后再次攻击返回 `TARGET_DEAD`。
- Client 不能伪造伤害。

### 002C TrainingEnemyDropPickup

前置：002B 验收通过，并单独确认 002C TDD。

目标：

- 训练怪死亡后，Server 生成私有 SmallGear 掉落。
- 只有击杀玩家能看到 / 拾取。
- 玩家靠近后自动拾取。
- Server 写入 `Resources.SmallGear += 1` 和 `Progression.Exp += 4`。
- Debug UI 或现有 FirstLoop 面板能看到资源变化；正式 HUD 不在本 Feature 做。

接口：

- `Loot.PrivateDropSpawned`
- `Loot.PrivateDropPicked`
- `Loot.PrivateDropExpired`

默认规则：

- 掉落资源：`SmallGear = 1`。
- Exp：`4`。
- 拾取半径：`8 studs`。
- 掉落过期：`20s`。
- 检查间隔：`0.25s`。

验收：

- 击败训练怪后出现私有掉落。
- 玩家靠近 8 studs 内拾取成功。
- 资源和 Exp 由 Server 写入。
- 20 秒未拾取自动过期。
- 多人情况下，其他玩家不能抢这个掉落。

## Not In This Feature

这个 Feature 不做：

- 正式 HUD。
- 普通怪 / 精英怪。
- 怪物 AI 追击。
- 怪物攻击玩家。
- 玩家受伤 / 死亡。
- 拼装台。
- 玩具 AI。
- Boss。
- ProfileStore。
- 完整美术模型替换。

完成本 Feature 后，才进入 `003_PlayerHUD` 或下一个已确认小闭环。
