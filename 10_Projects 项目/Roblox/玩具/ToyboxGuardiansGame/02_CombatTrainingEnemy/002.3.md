**002.1D 是什么**  
`002.1D` 要解决的问题是：Server 已经发了奖励，掉落物也飞向玩家了，但玩家仍然不明显知道“我到底拿到了什么”。

现在实际链路是：

```
LootDropService 写入 Resources.SmallGear / Progression.Exp
-> Server 发送 Loot.PrivateDropPicked
-> LootDropController 播放拾取吸走
-> Output 打一行：获得SmallGear +1
```

问题就在最后一步：`Output` 不是玩家反馈。玩家应该在画面上看到轻量提示，比如：

```
+1 SmallGear
+4 EXP
```

但这一步不能做成正式 HUD。它只是把“Server 奖励结果”临时翻译成“玩家看得懂的反馈”。

**为什么叫 Bridge**  
`Bridge` 的意思是桥接层：

```
Server 可信奖励结果
-> Client 临时奖励反馈
-> 未来 003_PlayerHUD / ResourceBar 可以替换它
```

所以它不能把正式 HUD 提前做了，也不能把奖励逻辑搬到 Client。它只负责显示 Server 已经确认的结果。

**当前调用链**  
已有 Server 链路：

```
CombatService 判定训练怪死亡
-> LootDropService:HandleTrainingEnemyDefeated(...)
-> _grantTrainingEnemyExp(...) 写入 Exp
-> _createPrivateDrop(...) 生成私有掉落
-> _pickupDrop(...) 写入 SmallGear
-> FireClient("Loot.PrivateDropPicked", payload)
```

已有 Client 链路：

```
Loot.PrivateDropSpawned
-> LootDropController:_handleDropSpawned
-> LootDropPresentation.Create

Loot.PrivateDropPicked
-> LootDropController:_handleDropPicked
-> LootDropPresentation.PlayPicked
-> PickupMotion.Play
-> Output 打印“获得SmallGear +1”
```

002.1D 要加的是：

```
Loot.PrivateDropPicked
-> RewardFeedbackController
-> RewardFeedbackPresentation.Show(...)
-> 屏幕显示临时奖励反馈
```

**职责边界**  
建议这样拆：

|模块|负责|不负责|
|---|---|---|
|`LootDropService`|Server 发奖、发可信 payload|不做 UI|
|`LootDropController`|掉落物生成、拾取吸走、清理|不做奖励 UI|
|`RewardFeedbackController`|监听奖励事件，把 payload 转成显示数据|不决定奖励数量|
|`RewardFeedbackPresentation`|创建临时 UI、播放淡入 / 上浮 / 淡出|不监听 Remote|
|`RewardFeedbackConfig`|文案、颜色、显示时间、堆叠数量|不放资源掉落规则|

**一个关键设计点**  
现在 `Loot.PrivateDropPicked` 里有：

```
dropId
resourceId
amount
resources
progression
tutorialFlags
serverTime
```

它能直接显示：

```
+1 SmallGear
```

但它不能稳定显示：

```
+4 EXP
```

原因是 `progression.Exp` 是当前总经验，不是本次增加多少经验。不能用总经验反推 delta。

所以 002.1D 有两个方案：

|方案|做法|评价|
|---|---|---|
|A|只显示 `+1 SmallGear`，Exp 留给 003 / 005|最小，但你之前说“经验没感觉”，不够完整|
|B|`PrivateDropPicked` payload 增加 `expGranted = 4`|推荐，改动小，Server 仍权威|
|C|新增 `Reward.Feedback` Remote|更通用，但 002.1D 可能偏重|

我的建议：`002.1D` 选 B。  
也就是 Server 奖励逻辑不变，只是在已确认奖励后，把“本次获得多少 Exp”也放进 payload 给 Client 显示。
