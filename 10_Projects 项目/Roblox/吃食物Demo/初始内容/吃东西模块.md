

## **总目标**
我们现在的目标不是马上完整复刻旧游戏，而是先做到：

```text
看懂旧项目结构
→ 找到核心功能链路
→ 识别无权限资产卡点
→ 选一个最小功能
→ 用可控资产复刻一个能跑的 Demo
```

目前已经选定的最小功能是：**吃东西**。

### **为什么要导出**
Roblox 的 `.rbxl` 对 Codex 来说不是普通源码项目，不能像网页/Unity 那样直接完整读取。所以第一步不是改代码，而是把 Studio 里的信息导成 AI 能读的文本。

我们做的导出，本质上分四类：

```text
1. Explorer 层级：这个项目有哪些对象，放在哪里
2. Remote 通信：客户端和服务端怎么说话
3. 资产审计：哪些动画、音效、图片、模型可能无权限
4. 关键源码：真正的功能逻辑写在哪些 Script / ModuleScript 里
```

这里的原理是：Roblox 项目通常不是从一个入口文件开始，而是分散在这些服务里：

```text
ReplicatedStorage：客户端和服务端共享的模块、Remote、资源
ServerScriptService：服务端入口脚本
ServerStorage：服务端内部模块
StarterPlayer：玩家本地脚本、角色脚本
StarterGui：UI
Workspace：场景对象、掉落物、NPC、地图
```

我们看项目，不是先读全部代码，而是先找：

```text
哪些 RemoteEvent 是核心通信
哪些 Script 是服务端入口
哪些 LocalScript 是玩家操作入口
哪些 ModuleScript 是系统模块
```

### **第三阶段：资产审计**
一开始我们导出资产时遇到两个问题：

```text
1. Studio Output 会截断，输出太长就丢后半段
2. 插件 UI 的资源会污染结果，比如 PluginGuiService/Add Easy Texture
```

这不是失败，是一个重要经验：大型 Roblox 项目不能一次性全量导出，要分段、聚焦导出。

**第四阶段：源码定位**
我们运行源码搜索器后，终于定位到几个无权限资产来源。

产出：

[Source_Asset_Search_Index.md](D:/AI/Codex/Codex_ProjectFixed/Project_Analysis_Package/Source_Asset_Search_Index.md)

关键结论：

```text
85695794590263 → 左手吃动画
89441660388960 → 右手吃动画
18721735423 → 战斗奔跑 / 预加载相关
```

它们出现在：

```text
ReplicatedStorage/Tool/AnimationModule
ReplicatedFirst/FirstPreload/AnimationModule
```

原理是：旧项目不是每个 Animation 对象都提前放好，而是有一个 `AnimationTable`，用动画名字查 AssetId，再运行时创建 Animation 并 `LoadAnimation`。

也就是：

```text
"左手吃"
→ AnimationModule 查表
→ 找到 AssetId
→ 创建 Animation
→ Animator:LoadAnimation()
→ 播放
```

所以无权限动画不是孤立问题，而是动画系统配置表的问题。

**吃东西功能原理**
旧项目吃东西不是 UI 按钮，而是角色附近有检测范围。

完整链路是：

```text
StarterPlayer/StarterCharacterScripts/本地检测吃东西
→ 每 0.1 秒扫描 Workspace/掉落物
→ 如果掉落物进入角色 Eat 范围
→ ReplicatedStorage.Msg["吃"]:FireServer(掉落物类型, 名称)
→ ServerScriptService/吃食物 接收
→ 找到对应掉落物
→ 读取 addAttr / addMoney
→ 调用 ServerStorage/System/SystemEatPlr.EatFood
→ 增加属性和金币
→ 刷新体型
→ 播放左手吃 / 右手吃动画
→ 播放选中物品 / 咀嚼音效
```

**第六阶段：决定复刻策略**


也就是复刻“机制”，不是复制“资产”。

**你现在应该掌握的核心思维**
不是“看到报错就修报错”。

正确顺序是：

```text
1. 先确认真实运行环境
2. 再导出结构
3. 再找通信入口
4. 再找最小功能链路
5. 再查资产依赖
6. 再决定替换策略
7. 最后复刻一个可运行闭环
```

这就是 Roblox 旧项目接手的基本方法。
