# v0.71.0 NPC 模型 / 动作 / 特效替换方案

## 结论

当前 NPC 不应该继续用高 Part 代码模型长期迭代。下一阶段应该把 NPC 视觉改成“低面数 MeshPart / 少量部件 + 运行时代码只管逻辑”，避免每个 NPC 带太多 Part、光圈、粒子和 Billboard。

## 推荐路线

```text
阶段 1：继续用当前占位模型，但减少 Part 和特效。
阶段 2：用 Tripo / Meshy 生成一版低多边形 NPC 草稿。
阶段 3：Blender 清理模型，压面、合并材质、统一比例、做碰撞代理。
阶段 4：导入 Roblox，先作为 MeshPart NPC 外观，不急着接动画。
阶段 5：确认性能后，再接 AnimationController / R15 动作和简单 VFX。
```

## Tripo 生成建议

提示词方向：

```text
stylized low poly Roblox NPC enemy, bulky food fighter, cartoon muscle body, simple face, no weapons, readable silhouette, bright color blocks, game-ready, low poly, clean topology
```

避免：

```text
超写实皮肤
大量毛发
复杂布料
细小链条饰品
透明材质
超高面数
多个贴图材质球
```

## Blender 清理标准

导入 Roblox 前必须做：

```text
Apply Scale / Rotation
模型面数优先控制在 5k 三角面以内
尽量 1-3 个 MeshPart
尽量 1 张贴图或少量纯色材质
删除隐藏面和内部面
设置合适 Origin
按 Roblox 人物比例缩放
另做简单碰撞盒，不用复杂网格碰撞
```

## Roblox 导入策略

第一版建议：

```text
不要直接做完整可换装 Avatar。
先导入成普通 Model / MeshPart，当作 NPC 外观。
代码仍用 PrimaryPart PivotTo 控制移动。
碰撞和吞噬判定仍用服务端距离/属性，不依赖网格碰撞。
```

后续如果要动作：

```text
如果用 R15/Rig：接 Humanoid 或 AnimationController。
如果用非人形怪物：接 AnimationController + 骨骼动画。
第一版动作只做 Idle / Walk / Defeat 三个状态。
```

## VFX 建议

```text
强 NPC：只保留低频脚底脉冲或头顶小光。
成长：只做一次短促浮字或小粒子，不持续喷发。
压制：屏幕提示 + 一次地面冲击圈即可。
巡逻：不要持续粒子，不要每个 NPC 挂大光圈。
```

## 配置入口

本版已加入：

```text
NpcAssetPipelineVersion = "v0.71.0"
NpcExternalModelEnabled = false
NpcModelAssetReviewRequired = true
NpcAnimationAssetReviewRequired = true
NpcVfxAssetReviewRequired = true
NpcModelTargetTriangleBudget = 5000
NpcModelMaxRuntimeParts = 6
```

默认不启用外部模型，等资产过审、导入和性能检查后再接入。
