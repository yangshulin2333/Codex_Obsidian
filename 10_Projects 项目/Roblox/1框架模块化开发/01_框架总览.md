# 框架总览

## 一句话说明

`YanzoFrame_V0` 是一个最小 Roblox 模块开发底座。

它只保留所有模块都会用到的能力：

- Rojo 项目映射
- Server 启动入口
- Client 启动入口
- ServiceRegistry
- ControllerRegistry
- Logger / Lifecycle
- NetService / NetClient
- MemoryStorage / StorageService 最小边界
- StartupSmokeTest

## 当前不包含

- DataStore
- ProfileStore
- 数据迁移
- JSON / Excel 批量维护
- 商店系统
- 背包系统
- 敌人系统
- 复杂 UI 自动布局
- 外部素材系统

这些以后作为独立模块学习。

## 核心文件夹

| Roblox 位置 | 本地职责 |
|---|---|
| `ReplicatedStorage.Framework` | 框架底座共享代码 |
| `ReplicatedStorage.Module` | 当前模块自己的共享配置 |
| `ServerScriptService.Server` | 服务端入口和 Service |
| `StarterPlayerScripts.Client` | 客户端入口和 Controller |

## 底层思想

| 思想 | 用在哪里 | 作用 |
|---|---|---|
| 模块化 | 每个功能一个 ModuleScript | 降低互相影响 |
| 接口边界 | Storage 先定义用法，再换实现 | 以后可以从内存换成真实存储 |
| 少量面向对象 | Registry / Storage 用 `new()` | 方便重复创建和测试 |

## 最重要边界

```text
Framework：所有模块都需要的能力
Module：当前模块自己的配置和共享数据
Server：真实状态修改和校验
Client：玩家输入、UI 显示、请求服务端
Studio：手工 UI / Workspace 外观和位置
```

## 验证命令

```powershell

```
