# Roblox Studio 快捷键速查

> 主要面向场景搭建、模型整理、对象摆放和脚本编辑。  
> 以下按 Windows 默认快捷键整理；部分快捷键可在 Studio 的快捷键设置中自定义。

## 一、模型与对象操作

| 快捷键 | 功能 | 常见用途 |
| --- | --- | --- |
| `Ctrl + G` | 将选中对象组成 `Model` | 把多个零件作为一个整体管理 |
| `Ctrl + U` | 拆解选中的 `Model` 或 `Folder` | 直接取出容器中的子对象 |
| `Ctrl + Alt + G` | 将选中对象组成 `Folder` | 只整理层级，不需要模型功能 |
| `Ctrl + D` | 原地复制选中对象 | 批量铺路、植物、家具等 |
| `Delete` | 删除选中对象 | 删除实例 |
| `Ctrl + Z` | 撤销 | 撤回上一步操作 |
| `Ctrl + Y` | 重做 | 恢复刚撤销的操作 |
| `F` | 聚焦选中对象 | 镜头快速移动到目标位置 |

### Model 和 Folder 的区别

- `Model`：适合需要整体移动、旋转、缩放或设置 `PrimaryPart` 的物体。
- `Folder`：只用于整理 Explorer 层级，不代表一个可整体变换的场景模型。

## 二、快速旋转与坐标切换

| 快捷键 | 功能 | 常见用途 |
| --- | --- | --- |
| `Ctrl + R` | 绕竖直轴快速旋转 90° | 快速改变墙、家具、植物的朝向 |
| `Ctrl + T` | 沿另一个轴翻转或倾斜 90° | 将物体放倒或调整上下方向 |
| `Ctrl + L` | 切换 `Local` / `World` 坐标 | 沿物体自身方向或世界坐标移动 |

### Local 与 World

- `World`：操作轴始终对应整个世界的 X、Y、Z 方向。
- `Local`：操作轴跟随物体自身的旋转方向。

物体已经斜着摆放时，切换到 `Local` 通常更容易沿着物体自身方向继续移动。

## 三、选择和 Explorer 整理

| 快捷键或操作 | 功能 |
| --- | --- |
| `Alt + 左键` | 穿过 `Model`，直接选择内部的 Part 或 MeshPart |
| `Ctrl + 左键` | 不连续多选对象 |
| `Shift + 左键` | 连续多选 Explorer 中的对象 |
| `Ctrl + A` | 全选当前范围或当前搜索结果 |
| `Ctrl + Shift + X` | 快速定位到 Explorer 搜索框 |

### 大量模型的推荐操作

1. 按 `Ctrl + Shift + X` 进入 Explorer 搜索框。
2. 输入共同名称，例如 `Cabbage`。
3. 在结果区域使用 `Ctrl + A` 全选。
4. 根据需要进行移动、删除或重新分组。

## 四、移动、缩放与旋转工具

| 快捷键 | 工具 |
| --- | --- |
| `Ctrl + 1` | Select 选择工具 |
| `Ctrl + 2` | Move 移动工具 |
| `Ctrl + 3` | Scale 缩放工具 |
| `Ctrl + 4` | Rotate 旋转工具 |

### 操作时的辅助按键

- 缩放时按住 `Shift`：保持物体比例。
- 缩放时按住 `Ctrl`：从两侧对称缩放。
- 拖动物体时按 `R`：在拖动过程中旋转。
- 拖动物体时按 `T`：在拖动过程中翻转。

## 五、固定和锁定

| 快捷键 | 功能 |
| --- | --- |
| `Alt + A` | 切换选中零件的 `Anchored` 状态 |
| `Alt + L` | 切换 Lock 工具 |

### 两者区别

- `Anchored`：决定零件运行游戏时是否受物理影响。
- `Locked`：主要防止编辑场景时误选或误操作。

## 六、实体建模

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Shift + G` | `Union`：合并选中的零件 |
| `Ctrl + Shift + N` | `Negate`：将零件设置为负形 |
| `Ctrl + Shift + U` | `Separate`：拆开合并后的实体 |

> Union 和 Negate 更适合简单静态造型。复杂 Mesh 不建议频繁执行实体合并，以免增加编辑、碰撞和性能方面的问题。

## 七、镜头操作

| 快捷键或操作 | 功能 |
| --- | --- |
| `W / A / S / D` | 前后左右移动镜头 |
| `Q / E` | 镜头下降或上升 |
| `Shift + 移动键` | 慢速移动镜头，方便精细观察 |
| `鼠标右键拖动` | 转动镜头 |
| `鼠标滚轮` | 缩放视野 |
| `F` | 聚焦选中的对象 |

## 八、游戏测试

| 快捷键 | 功能 |
| --- | --- |
| `F5` | 开始 Play 测试 |
| `Shift + F5` | 停止测试 |
| `F8` | Run：运行游戏但不生成玩家角色 |

## 九、脚本编辑

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + P` | 快速打开脚本或文件 |
| `Ctrl + F` | 在当前脚本中查找 |
| `Ctrl + H` | 查找并替换 |
| `Ctrl + Shift + F` | 在所有脚本中搜索 |
| `Ctrl + G` | 跳转到指定行 |
| `Ctrl + Shift + C` | 注释或取消注释选中代码 |
| `Ctrl + Alt + ↑ / ↓` | 在上方或下方增加多光标 |
| `Alt + 左键` | 在点击位置增加光标 |
| `Shift + Alt + L` | 选中所有相同匹配并添加多光标 |

> 快捷键会根据当前焦点变化。例如光标位于脚本编辑器时，`Ctrl + G` 是跳转到行；选中场景对象时，`Ctrl + G` 才是组成 Model。

## 十、最值得先记住的组合

### 快速摆放一排物体

1. 选中物体。
2. 按 `Ctrl + D` 原地复制。
3. 使用移动工具将副本移到下一个位置。
4. 重复复制和移动。

### 快速修改模型朝向

- `Ctrl + R`：水平转向。
- `Ctrl + T`：翻转或放倒。
- `Ctrl + L`：切换自身坐标和世界坐标。

### 快速操作嵌套模型

- `Alt + 左键`：直接选内部零件。
- `Ctrl + U`：拆解整个容器。
- `Ctrl + Alt + G`：重新整理为 Folder。

## 十一、查看或修改快捷键

在 Roblox Studio 中打开快捷键自定义界面，搜索对应命令名称，例如：

- `Rotate Selection`
- `Tilt Selection`
- `Group`
- `Ungroup`
- `Group As Folder`
- `Anchor`
- `Local Space`
- `Explorer Search`

不同 Studio 版本、测试功能或个人设置可能改变默认绑定；如果某个快捷键无效，以快捷键自定义界面显示的当前绑定为准。
