# Blender Guru Beginner Blender Tutorial 2026 知识手册

## 视频信息

- 视频：Beginner Blender Tutorial (2026)
- 作者：Blender Guru
- 链接：https://www.youtube.com/watch?v=z-Xl9tGqH14
- 用途：Blender 入门基础操作学习，不是游戏道具专项教程。
- 本手册定位：根据视频主题和当前 Roblox / Tripo / 低模游戏道具需求整理的学习手册，不是逐字稿。

## 一句话总结

这个视频适合用来建立 Blender 的基础操作感：界面、视角、物体操作、编辑模式、建模、材质、纹理、灯光和渲染。对当前目标来说，重点不是完整做甜甜圈，而是把基础操作迁移到 [[Roblox]] 游戏道具、魔法书、武器和 Tripo 模型清理流程。

## 为什么要学它

当前 Tripo 可以生成大概形体，但对硬表面游戏道具的结构理解不稳定。例如魔法书的纸页块、封面厚度、金属护角、水晶和锁扣，最好在 Blender 中手工补成清楚的大块几何。

所以学习目标不是成为 Blender 全能用户，而是掌握一个很小的闭环：

```text
导入或参考 AI 模型
-> 看懂模型结构
-> 拆出可用部件
-> 用简单几何重建主体
-> 倒角、分材质、修法线
-> 导出给 Roblox / 后续工具
```

## 当前只需要掌握的 Blender 能力

### 1. 视角与导航

必须会：

- 旋转视角。
- 平移视角。
- 缩放视角。
- 切换正视图、侧视图、顶视图。
- 看懂坐标轴：X / Y / Z。

学习目标不是把画面调漂亮，而是能检查模型：

```text
这个部件在正面位置对不对？
侧面有没有厚度？
纸页块是否被封面挡住？
护角是否漂浮？
```

### 2. Object Mode 和 Edit Mode

最重要的概念：

- Object Mode：移动、缩放、旋转整个物体。
- Edit Mode：修改物体内部的点、边、面。

对游戏道具的理解：

```text
Object Mode 负责摆部件。
Edit Mode 负责改形状。
```

例子：

- 魔法书封面板整体变大：Object Mode。
- 把封面一侧挤出厚度：Edit Mode。
- 移动整颗水晶到中心：Object Mode。
- 调整水晶某个顶点形状：Edit Mode。

### 3. 基础变换

必须熟悉：

```text
G = Move 移动
S = Scale 缩放
R = Rotate 旋转
X / Y / Z = 锁定轴向
```

常见用法：

```text
G X   沿 X 轴移动
S Z   沿 Z 轴缩放
R Y   绕 Y 轴旋转
```

对魔法书的用途：

- 用 `S` 把 cube 拉成长方体纸页块。
- 用 `G` 把封面板移到纸页块前后。
- 用 `R` 调整吊坠、小宝石、装饰件角度。

### 4. 选择点、边、面

Edit Mode 中要会三种选择：

- Vertex：点。
- Edge：边。
- Face：面。

对当前目标，最常用的是 Face 和 Edge：

- 选面后挤出封面厚度。
- 选边后倒角。
- 选部分面后分离成独立部件。

### 5. 基础建模操作

必须学：

- Add Cube。
- Extrude 挤出。
- Inset 内插。
- Loop Cut 环切。
- Bevel 倒角。

优先级：

```text
Cube > Scale > Bevel > Material
```

对低模道具来说，大多数基础结构都可以从 cube 开始。

魔法书拆法：

```text
纸页块 = 一个奶油色长方体
前封面 = 一个紫色薄长方体
后封面 = 一个紫色薄长方体
书脊 = 一个圆角/柱状深紫结构
金属护角 = 4 个金色小块
中央水晶 = 简化菱形凸起
锁扣 = 长方体带扣 + 宝石小块
```

### 6. Bevel 倒角

Bevel 是低模风格硬表面道具最重要的操作之一。

用途：

- 让 cube 不像生硬方块。
- 让书页块、封面、金属护角有游戏资产感。
- 让边缘能接光，不会像纸片。

建议：

```text
大部件少量倒角。
金属件倒角稍明显。
纸页块倒角很小。
水晶用清晰斜面。
```

不要过度倒角，否则低模资产会变成高密度碎面。

### 7. Modifier 基础

先只重点理解这几个：

- Bevel Modifier：非破坏性倒角。
- Mirror Modifier：做左右对称部件。
- Weighted Normal：让硬表面模型受光更干净。

暂时不用深学：

- Geometry Nodes。
- 复杂布料。
- 毛发。
- 高级粒子。
- 复杂程序材质。

### 8. 材质分配

游戏道具要先把材质分区做清楚：

```text
紫色皮革
奶油色纸页
金色金属
蓝紫水晶
暗色书脊
```

材质的目标不是渲染真实，而是让结构可读。

魔法书优先级：

1. 纸页块一定要是单独材质。
2. 封面和书脊可以同色但最好分部件。
3. 金属护角和金属边框统一金色。
4. 水晶单独材质，颜色高对比。

### 9. UV 与纹理

这个视频会涉及纹理和渲染，但你当前不需要一次掌握完整 UV。

当前只需要理解：

- UV 是把 3D 表面展开到 2D 贴图上。
- 游戏模型最终通常需要贴图或材质分区。
- 如果结构还没干净，不要急着做复杂贴图。

对魔法书：

```text
先让纸页块成为真实几何。
再考虑纸页纹理。
不要用贴图假装纸页厚度。
```

### 10. 灯光、相机、渲染

甜甜圈教程会讲灯光和渲染，但当前优先级较低。

可以先只理解：

- Camera 是最终截图视角。
- Light 影响展示效果。
- Render 是输出图片。

当前目标是 Roblox / 游戏资产，不是渲染宣传图，所以暂时不要把大量时间花在灯光和渲染上。

## 面向游戏道具的练习路线

### 练习 1：极简厚书

目标：不用 Tripo，自己建一本低模厚书。

结构：

- 1 个奶油色纸页块。
- 1 个前封面板。
- 1 个后封面板。
- 1 个书脊。
- 4 个金属护角。

验收：

- 从正面能看到封面。
- 从右侧能看到厚纸页块。
- 从左侧能看到书脊。
- 每个部件都是独立清楚的大块几何。

### 练习 2：给厚书加幻想装饰

目标：在不破坏基础结构的前提下加装饰。

新增：

- 中央水晶。
- 金色星芒框。
- 右侧锁扣。
- 底部吊坠。

验收：

- 装饰件不能糊成一团。
- 纸页块仍然明显。
- 从侧面不能看到完整正面水晶。

### 练习 3：导入 Tripo 模型做参考

目标：把 AI 模型当 3D 草图，不当最终模型。

步骤：

```text
导入 Tripo 模型
-> 分离可用装饰部件
-> 删除糊掉的纸页和碎片
-> 自己重建纸页块、封面、背板、书脊
-> 把可用的水晶/护角/锁扣摆回去
-> 重新分材质
```

验收：

- 主体结构来自干净几何。
- AI 部件只作为装饰或参考。
- 模型可以继续导出测试。

## 魔法书结构清单

| 部件 | 建议来源 | 原因 |
|---|---|---|
| 纸页块 | 手工重建 | Tripo 容易当成纹理吞掉 |
| 前封面 | 手工重建 | 需要明确厚度 |
| 后封面 | 手工重建 | 需要和前封面对齐 |
| 书脊 | 手工重建或参考 AI | 圆弧结构要稳定 |
| 中央水晶 | AI 参考后手工简化 | 形状重要但不应碎裂 |
| 金属护角 | AI 参考后手工重建 | 要低模大块面 |
| 锁扣 | AI 参考后手工重建 | 需要清楚厚度 |
| 吊坠 | 可用 AI 或手工简化 | 小部件可以低优先级 |
