# Blender 快捷键表：中文学习版

## 来源

- 原始文件：[[assets/Blender快捷键表.txt]]
- 原始标题：Blender Keyboard Shortcuts v1.4
- 原始更新日期：2025-10-03
- 中文整理日期：2026-06-27

## 使用原则

不要一开始背完整快捷键表。当前目标是做 Roblox / Tripo / 低模游戏道具，所以先掌握建模和视图相关快捷键。

最小优先级：

```text
视角操作
-> 选择
-> 移动 / 缩放 / 旋转
-> Object Mode / Edit Mode
-> Extrude / Inset / Bevel / Loop Cut
-> Separate / Join / Apply Transform
-> 材质和 UV 基础
```

## 一、通用操作

| 功能 | 快捷键 | 中文说明 |
|---|---|---|
| 工具栏 | `T` | 显示/隐藏左侧工具栏 |
| 属性侧栏 | `N` | 显示/隐藏右侧属性侧栏 |
| 添加物体/节点 | `Shift + A` | 添加 Cube、Mesh、Light、Camera 等 |
| 删除 | `X` 或 `Delete` | 删除选中对象或元素 |
| 搜索命令 | `F3` | 不记得按钮在哪时，用搜索 |
| 移动 | `G` | Grab / Move，移动对象或元素 |
| 缩放 | `S` | Scale，缩放对象或元素 |
| 旋转 | `R` | Rotate，旋转对象或元素 |
| 按轴旋转 | `R` 后按 `X/Y/Z` | 只沿某个轴旋转 |
| 精细移动 | 按住 `Shift` | 变换时更精细 |
| 增量移动 | 按住 `Ctrl` | 变换时按格子/步进吸附 |
| 复制 | `Shift + D` | 复制一个独立对象 |
| 关联复制 | `Alt + D` | 复制但共享数据 |
| 隐藏 | `H` | 隐藏选中对象 |
| 取消全部隐藏 | `Alt + H` | 显示隐藏对象 |
| 只显示选中 | `Shift + H` | 隐藏未选对象 |
| 快捷收藏菜单 | `Q` | 自定义常用命令入口 |


## 四、Object Mode：物体模式

| 功能 | 快捷键 | 中文说明 |
|---|---|---|
| 模式菜单 | `Ctrl + Tab` | 切换模式菜单 |
| Edit/Object 切换 | `Tab` | 在物体模式和编辑模式之间切换 |
| 镜像 | `Ctrl + M` 后按 `X/Y/Z` | 镜像对象 |
| 设置父级 | `Ctrl + P` | 建立父子关系 |
| 清除父级 | `Alt + P` | 取消父子关系 |
| 开关吸附 | `Shift + Tab` | 打开/关闭吸附 |
| 清除位置 | `Alt + G` | 位置归零 |
| 清除旋转 | `Alt + R` | 旋转归零 |
| 清除缩放 | `Alt + S` | 缩放归一 |
| 应用变换 | `Ctrl + A` | Apply Location/Rotation/Scale |
| 合并选中对象 | `Ctrl + J` | 多个对象合成一个对象 |
| 复制属性 | `Ctrl + L` | 把材质等属性复制给其他对象 |
| 移动到 Collection | `M` | 把对象移到集合中 |

对魔法书建模重点：

- `Ctrl + A` 很重要。导出或继续编辑前，经常需要应用缩放。
- `Ctrl + J` 用于把多个确定不再分开的装饰合并。
- 不要太早合并部件。纸页、封面、金属、水晶最好先保持独立。

## 面向魔法书的练习

练习目标：不用复杂功能，只用最小快捷键做一本可控的低模魔法书。

```text
Shift + A 添加 Cube
S 缩放成纸页块
Shift + D 复制成封面和背板
G 移动封面到纸页块前后
Ctrl + B 给边倒角
Shift + A 添加小 Cube 做护角
Shift + D 复制护角
添加材质：紫色、奶油色、金色、蓝色
```

如果做到这一步，你已经比单纯依赖 Tripo 更可控。
