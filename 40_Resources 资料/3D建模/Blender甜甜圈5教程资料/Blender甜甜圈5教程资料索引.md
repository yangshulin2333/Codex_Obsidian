## 对你当前魔法书流程的迁移

甜甜圈教程不是低模魔法书教程，但它能补基础操作：

- 视角操作：用于检查 Tripo 模型有没有缺纸页块。
- 移动 / 缩放 / 旋转：用于摆放封面、纸页、护角、水晶。
- Edit Mode：用于改几何结构。
- Bevel：用于让方块变成游戏道具风格。
- 材质：用于区分紫色皮革、奶油纸页、金属和水晶。
- 参考图：用于从真实物体或概念图提取比例。

## 建议学习方式

不要把目标设成“完整做出漂亮甜甜圈渲染”。你的目标应该是：

```text
看懂 Blender 基础界面
-> 会用 G/S/R 调整物体
-> 会进入 Edit Mode 改点边面
-> 会用 Cube 做基础几何
-> 会加 Bevel
-> 会分材质
-> 会导入 AI 模型作为参考
```
