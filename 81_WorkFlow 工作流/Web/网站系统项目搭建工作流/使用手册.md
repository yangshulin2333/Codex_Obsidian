# premium-local-app-delivery 使用手册

这个 Skill 用来配合 Codex 做“客户可交付”的系统、网站、管理后台和本地业务平台。重点不是只写代码，而是交付一个看起来专业、容易部署、客户电脑重启后还能继续访问的完整包。

## 适合什么场景

- 做企业管理系统，例如合同管理、客户管理、库存管理、项目管理、审批系统。
- 做客户演示系统，需要看起来高端、完整、有真实数据。
- 做本地部署系统，客户电脑没有外网也能安装。
- 做 Windows 内网系统，部署一次后，后续只需要打开浏览器地址。
- 做网站或后台，希望界面“高端大气上档次”，不是临时测试页面。

## 推荐提问方式

直接这样说即可：

```text
用 premium-local-app-delivery 给我做一个客户管理系统，要求高端大气，Windows 本地部署，客户电脑没有外网。
```

或者：

```text
做一个库存管理系统，给客户本地部署用。要求部署一次，以后重启电脑后只打开网页地址即可访问。
```

如果你已经有明确功能，可以这样说：

```text
用 premium-local-app-delivery 做一个设备巡检系统。
功能包括：设备台账、巡检计划、异常记录、图片附件、统计看板、用户权限。
要求：高端界面、SQLite、本地部署、离线安装包、开机自启动。
```

## 你最好提前说明的信息

如果知道这些信息，可以直接告诉 Codex：

- 系统名称，例如“智慧合同中台”“客户运营管理平台”。
- 使用对象，例如老板、销售、财务、法务、仓库人员。
- 主要功能模块。
- 是否需要登录和权限。
- 是否需要导出 Excel 或 CSV。
- 是否需要上传附件、图片、合同、文档。
- 是否需要演示假数据。
- 客户电脑是单机使用还是局域网多人访问。
- 客户电脑是否没有外网。

不知道也没关系，Codex 会按企业系统默认标准补齐。

## Codex 会默认怎么做

使用这个 Skill 后，Codex 会优先按下面标准交付：

- 做正式产品界面，不做简陋测试页面。
- 页面文案面向客户，不暴露 SQLite、Python、Flask 等技术词。
- 带本地 Logo、favicon、图标，不依赖外网 CDN。
- 带仪表盘、列表、详情、搜索、筛选、状态、操作按钮。
- 管理系统默认考虑登录、权限、审计日志、备份。
- 需要演示时生成逼真的假数据。
- Windows 客户机离线部署。
- 打包成一个 zip，客户复制、解压、双击部署。
- 提供开机自启动脚本，客户电脑重启后自动恢复访问。

## 典型交付物

正常情况下，最终会有这些文件：

```text
ContractManager_Offline.zip
deploy_offline.bat
start.bat
start_lan.bat
install_autostart.bat
uninstall_autostart.bat
backup_db.bat
README.md
```

客户电脑部署流程通常是：

```text
复制 zip -> 解压 -> 双击 deploy_offline.bat -> 右键管理员运行 install_autostart.bat -> 打开网页地址
```

## 客户电脑无外网时怎么说

你可以直接要求：

```text
客户电脑没有外网，请把 Python 安装包和所有依赖都打进离线包里。
```

Codex 应该交付一个完整离线包，里面包含：

- Python 离线安装包。
- Python 依赖 wheel 文件。
- 离线部署脚本。
- 开机自启动脚本。
- 系统源码和运行目录。

客户电脑不需要联网，也不需要手动安装依赖。

## 关于“部署一次，后续只打开网页”

你要明确说：

```text
部署完以后，客户电脑重启后也要自动启动，用户只打开浏览器地址即可。
```

Codex 会加入 Windows 计划任务脚本：

```text
install_autostart.bat
uninstall_autostart.bat
```

部署完成后，在客户电脑右键管理员运行 `install_autostart.bat`。之后客户电脑开机后，系统会自动后台启动。

```text
帮我验证：本地能打开、登录正常、主要页面 200、静态资源加载、离线包包含 Python 安装包和开机自启动脚本。
```

也可以要求：

```text

```

或者：

```text

```

## 注意事项

- 客户局域网多人访问时，需要客户电脑防火墙放行系统端口，一般是 `5000`。
- 客户电脑最好设置固定 IP，否则其他人访问地址可能变化。
- 正式使用前要修改默认管理员密码。
- 数据库和附件目录都要备份。
- 如果是公网访问，不要直接暴露本地服务，应放到 VPN、企业网关、HTTPS 或内网环境后面。
