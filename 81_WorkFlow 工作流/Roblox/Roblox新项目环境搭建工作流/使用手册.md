# Roblox Rojo 新项目初始化操作手册

## 这两个文件怎么用

以后新开 Roblox 项目时，把这两个文件交给 Codex：

```text
SKILL.md
使用手册.md
```

然后直接发送这段指令：

```text
请读取我提供的 SKILL.md 和 使用手册.md。
按里面的 Roblox Rojo 新项目初始化流程，在当前工作目录创建一个新项目。

项目名：<填写项目名>
目标：只搭建 Rojo 开发工作流 / 学习环境 / 正式项目起步环境

要求：
1. 不要使用任何旧电脑的固定路径。
2. 如果缺少工具，先告诉我缺什么、怎么安装。
3. 只初始化 Rojo 工作流和开发环境，不要默认实现具体游戏玩法。
4. 生成带中文注释的 Luau 入口文件。
5. 生成 VS Code 推荐插件、settings、tasks。
6. 配置 Comment Translate，用于选中英文单词、注释或报错日志后悬停翻译。
7. 初始化后运行 rojo sourcemap 和 stylua 检查；如果工具缺失，明确说明。
8. 最后解释每个目录、如何启动 Rojo、如何连接 Studio。
```

## 用户只需要提供什么

你只需要提供三件事：

```text
项目名
项目放哪里
用途：Rojo 工作流初始化 / 学习环境 / 正式项目起步环境
```

如果你懒得选路径，就直接说：

```text
在当前工作目录创建。
```

## Codex 应该先检查什么

Codex 不应该一上来就写文件。它应先检查当前环境：

```text
Roblox Studio 是否已安装
VS Code 是否已安装
Git 是否可用
Rojo CLI 是否可用
StyLua 是否可用
当前目录是否适合创建项目
目标项目文件夹是否已存在
```

Windows 下常用检查命令：

```powershell
git --version
rojo --version
stylua --version
code --version
```

Roblox Studio 和 Rojo Studio Plugin 有时需要人工在 Studio 内确认，Codex 应说明清楚。

## 初始化范围

这个手册的目标是搭建 Roblox + Rojo 开发环境，不是创建游戏玩法。

默认只做这些：

```text
创建 Rojo 项目结构
生成 default.project.json
生成服务端入口 Main.server.luau
生成客户端入口 Main.client.luau
生成共享配置模块
生成 VS Code 插件推荐
生成 VS Code tasks
生成 StyLua / Wally 基础文件
生成 Selene Roblox 标准库配置
生成 Comment Translate 使用说明
运行 Rojo / StyLua 验证
```

默认不做这些：

```text
不做 UI 按钮
不做奖励领取
不做 RemoteEvent 玩法链路
不做 DataService
不做战斗 / 模拟器 / 塔防 / 跑酷 / 宠物等具体玩法
不接 DataStore
不接 Robux 商品
不接 UGC / Skin / Aura
```

等游戏类型确定后，再单独设计第一条玩法链路。

## Codex 创建项目时的标准结果

新项目应生成这样的结构：

```text
MyGame/
  default.project.json
  README.md
  .gitignore
  wally.toml
  stylua.toml
  selene.toml
  .vscode/
    extensions.json
    settings.json
    tasks.json
    comment-translate-usage.md
  src/
    ReplicatedStorage/
      Shared/
        GameConfig.luau
        InstanceUtil.luau
    ServerScriptService/
      Main.server.luau
      Services/
    StarterPlayer/
      StarterPlayerScripts/
        Main.client.luau
        ClientModules/
```

## .luau 文件规则

Codex 必须按这个规则生成文件：

```text
Main.server.luau
-> Roblox Script
-> 放在 ServerScriptService
-> 服务端运行
-> 当前只验证服务端入口能通过 Rojo 同步和启动

Main.client.luau
-> Roblox LocalScript
-> 放在 StarterPlayerScripts
-> 每个玩家客户端运行
-> 当前只验证客户端入口能通过 Rojo 同步和启动

普通 .luau
-> Roblox ModuleScript
-> 只有被 require() 时才运行
```

起步阶段只需要：

```text
服务端入口
客户端入口
共享配置
少量通用工具
空的 Services/ 和 ClientModules/ 目录
```

## default.project.json 标准映射

`default.project.json` 应把本地文件映射到 Roblox Studio：

```text
src/ReplicatedStorage/Shared
-> ReplicatedStorage/Shared

src/ServerScriptService
-> ServerScriptService

src/StarterPlayer/StarterPlayerScripts
-> StarterPlayer/StarterPlayerScripts
```

起步项目里 `ReplicatedStorage/Packages` 可以先建成空 Folder。等真正使用 Wally 包时，再处理真实 `Packages/` 映射。

## VS Code 插件要求

`.vscode/extensions.json` 应推荐：

```text
evaera.vscode-rojo
JohnnyMorganz.luau-lsp
JohnnyMorganz.stylua
tamasfe.even-better-toml
ms-vscode.PowerShell
intellsmi.comment-translate
```

用途：

```text
Rojo 插件：辅助 Rojo 工作流
Luau LSP：Luau 语法、补全、诊断
StyLua：格式化 Luau
TOML：编辑 wally.toml
PowerShell：Windows 脚本支持
Comment Translate：选中单词、注释、字符串或报错日志后悬停翻译，不改原文件
```

## Comment Translate 配置

`.vscode/settings.json` 可以生成默认配置：

```json
{
  "commentTranslate.targetLanguage": "zh-CN",
  "commentTranslate.hover.enabled": true,
  "commentTranslate.hover.concise": false,
  "commentTranslate.hover.string": true,
  "commentTranslate.hover.content": true,
  "commentTranslate.multilineMerge": true,
  "commentTranslate.maxTranslationLength": 1500
}
```

默认用法：

```text
鼠标选中英文单词 / 注释 / 报错日志
-> 鼠标停在选中文本上
-> 看 hover 翻译框
```

终端报错如果不能直接翻译，先复制到临时文本：

```text
Ctrl+Shift+P
-> File: New Text File
-> 粘贴报错日志
-> 选中要翻译的英文
-> hover 查看翻译
```

## VS Code Tasks

`.vscode/tasks.json` 至少包含：

```text
Rojo: serve
Rojo: sourcemap
StyLua: check src
```

对应命令：

```powershell
rojo serve default.project.json --address 127.0.0.1 --port 34872
rojo sourcemap default.project.json --output sourcemap.json
stylua --check src
```

说明：

```text
rojo serve 是本机临时同步服务。
电脑重启、终端关闭、VS Code 关闭后，需要重新启动。
它不是发布游戏，也不是 Roblox Studio 永久在线服务。
```

## 验收标准

Codex 完成后必须给出这些结果：

```text
创建了哪些文件
Rojo sourcemap 是否通过
StyLua check 是否通过
VS Code 插件配置是否生成
Comment Translate 是否已配置为选中/悬停翻译
如何启动 rojo serve
如何在 Roblox Studio 连接 Rojo
服务端入口和客户端入口分别在哪里
下一步如何根据游戏类型继续设计玩法
```

如果检查失败，不能含糊说“应该可以”。必须写清楚：

```text
失败命令
失败原因
要用户做什么
Codex 能继续做什么
```

## 禁止事项

新项目初始化阶段不要做这些：

```text
不要默认实现具体游戏玩法
不要默认生成 UI / 奖励 / RemoteEvent 玩法链路
不要接真实 Robux 商品
不要改 DataStore schema
不要接 UGC / Skin / Aura
不要把 API key 写进仓库
不要默认使用旧电脑路径
不要一次性引入大型框架
不要跳过 Roblox Studio 连接步骤解释
```

## 如果只有这两个文件，没有脚本

如果新环境里只有 `SKILL.md` 和本手册，没有 `scripts/New-RobloxRojoProject.ps1`，Codex 应该：

```text
1. 按 SKILL.md 和本手册先重建脚本或直接生成项目文件。
2. 保持同样的目录结构。
3. 保持同样的 VS Code 配置。
4. 只生成 Rojo 工作流入口，不生成具体玩法闭环。
5. 所有 Luau 文件必须带中文注释。
6. 生成后执行相同验收流程。
```

不要因为缺少旧路径而停止。路径由当前工作目录和用户指定目录决定。

