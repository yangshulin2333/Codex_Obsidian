# 效果图转 8 视图门禁

适用于已经确认一张道具效果图，需要继续生成 image-to-3D 多视图参考图的任务。

## 1. 效果图角色

效果图只锁定：

- 配色
- 主轮廓
- 核心识别点
- 材质块面
- 装饰连接层级

效果图不锁定：

- 斜视角
- 透视关系
- 可见侧面宽度
- 顶部或底部曝光

## 2. 连接层级

生成前填写：

```text
L0 主体：
L1 宽底座：
L2 凸出浮雕：
L3 核心件：
```

验收规则：

- L2 必须连接 L1。
- L3 必须嵌入 L1 或 L2。
- 不允许 L2/L3 仅凭视觉悬浮在封面上。
- 细碎装饰无法在侧视图解释时，应合并为宽块面。

## 2.1 双锁定与零件守恒

正式视图生成前先完成 `design_lock.md`：

1. 视觉 DNA 锁定风格，不锁相机。
2. 几何锁定轮廓、比例、L0-L3 和真实厚度。
3. 零件清单为关键结构分配 ID、数量和所属表面。
4. 任何视图都不能新增、删减、拆分或复制关键零件。

如果效果图中的结构无法写进零件清单，说明它只是视觉装饰，必须先删除、合并或增加宽底座。

## 3. 严格正面闸门

第一张正式图必须是 `front.png`：

```text
yaw 0
pitch 0
roll 0
可见面：正面
隐藏面：左侧、右侧、顶部、底部
```

失败条件：

- 仍能看到完整页边或书脊。
- 顶部或底部形成独立平面。
- 把效果图的斜视角直接复制成 front。
- 凸出装饰失去固定底座。

## 4. 正交图顺序

```text
front
back
确认左右侧向可见性合同
spine_left / left
page_edge_right / right
top
bottom
```

生成侧视前，Codex 必须主动询问并复述左右各自必须看见、必须隐藏的结构；对单侧结构记录数量、位置、顺序和遮挡，得到用户确认后才能继续。不得以“是否对称”代替这一步，也不得自行镜像。前一张通过后再生成下一张。每一步都必须检查零件数量、所属表面和远侧遮挡。后视图与侧视图只能解释已有结构，不得发明新的核心装饰。

顶部和底部还要声明两条外轨归属：

```text
正面轨道：允许显示正面浮雕的侧面高度。
背面轨道：只显示背面低浮雕或近似平面。
```

同一张顶/底图不得把正面高凸结构复制到两条轨道。

## 5. 辅助图顺序

```text
left45
right45
```

两张辅助图分别继承对应侧视的可见性合同。只有用户明确授权共用几何时才可镜像，并记录授权和来源。

辅助图只解释连接关系。默认使用水平相机，顶部和底部都不展开；远侧完整装饰计数必须为 0。

## 6. 复杂结构专项检查

| 结构 | 必查项 |
|---|---|
| 巨角、长刺 | 根部是否足够宽，是否与 L1 底座连续 |
| 齿轮、圆环、轨道 | 是否是附着浮雕，是否被误画成悬浮圆盘 |
| 羽翼、羽片 | 是否合并为宽块面，侧视图是否可解释厚度 |
| 巨型宝石 | 是否有完整托座，是否穿入页块 |
| 角部装甲 | 是否分别固定上下封面，是否错误封闭开放端 |

## 7. 单资产闭环

每件资产完成以下文件后才能进入下一件：

```text
front.png
back.png
spine_left.png 或 left.png
page_edge_right.png 或 right.png
top.png
bottom.png
left45.png
right45.png
orthographic_preview_contact_sheet.png
reference_preview_contact_sheet.png
reference_notes.md
design_lock.md
failure_log.md
```

联系表需要同时确认：

- 同一设计。
- 同一比例。
- 同一装饰数量。
- 同一连接层级。
- 相反表面互斥。
- 开放端未被封闭。
- 关键零件数量与所属表面守恒。
- 正面浮雕没有复制到背面轨道。

任一项失败时只修对应视图，失败稿移入 `失败对照/`。正式文件通过后才允许生成下一张或进入下一件资产。
