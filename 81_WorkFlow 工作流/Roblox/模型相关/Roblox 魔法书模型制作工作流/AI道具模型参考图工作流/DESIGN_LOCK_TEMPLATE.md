# 道具设计锁模板

用途：效果图确认后、正式多视图生成前，冻结视觉身份与可验证几何。模板不绑定资产类型、项目路径或具体风格。

## 1. 资产信息

```text
资产名称：
资产类型：
输出用途：
效果图路径：
正式视图数量：
目标画布：
```

## 2. 视觉 DNA 锁

```text
造型语言：

材质语言：
主色：

```

视觉 DNA 锁定“看起来属于哪一套系列”，不锁定效果图中的斜视相机。

### 3.1 XYZ 几何锁与相机取景

```text
X 轴定义：
Y 轴定义：
Z 轴定义：
归一化基准轴与长度：
front/back 投影平面：
left/right 投影平面：
top/bottom 投影平面：
理论同相机尺度包围盒：
各视图交付包围盒：
逐视图正交相机放大倍数：
```

规则：

- X:Y:Z 几何比例与输入图片的相机取景倍率分开记录。
- 单张图内部必须等比缩放，禁止横向或纵向单独拉伸。
- 细窄轴向视图允许使用已记录的统一相机放大，以满足平台主体检测。
- 轴向主体长边建议占画布 `60%-80%`，同时保留原投影平面的长宽比。
- 联系表保留最终交付图片的画布占用，不得再次改变倍率。
- 任一视图出现不属于其投影平面的完整表面时，状态必须为 `rejected`。

## 4. L0-L3 连接层级

```text
L0 主体：
L1 宽底座 / 主承力件：
L2 凸出装甲 / 浮雕：
L3 宝石 / 核心 / 嵌入件：
```

规则：L2 必须连接 L1；L3 必须嵌入 L1 或 L2；无法说明连接路径的零件不得进入正式视图。

规则：

- 固定数量不能在不同视图中增加或减少。
- 正面零件不能复制到背面。

- 未登记的端盖晶体、窗口、尖刺、箍带或装甲数量默认为 0。

## 7. 顶部 / 底部轨道归属

