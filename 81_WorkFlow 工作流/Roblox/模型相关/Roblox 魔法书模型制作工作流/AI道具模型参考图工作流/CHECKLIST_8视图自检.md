# 8 视图自检清单

用途：检查任意 Roblox 单体道具的 image-to-3D 参考图是否适合继续输入 Tripo / 混元 AI / 3D Studio。

这份清单不绑定具体资产类型。  
不同资产可以替换侧面命名，但检查逻辑不变。

## 一票否决项

出现以下问题，应先修图，不建议继续上传 3D 工具：

- 不是单体道具。
- 不是完整物体，被裁切。
- 有人物、手、桌子、场景。
- 有真实可读文字。
- 有复杂光效、烟雾、漂浮粒子遮挡结构。
- 正交图和 45 度图不是同一个设计。
- 侧边或顶部出现无法解释的零件。
- 45 度图变成强透视展示图。
- 同一张图大面积显示左侧和右侧两个相反表面。
- 同一张图同时显示顶部和底部两个相反表面。
- 远侧完整装饰被错误地翻到镜头前方。
- 远侧面形成可单独辨认的连续材质带、侧板或完整厚度区域。
- Prompt 声明隐藏远侧面，但成图中仍能看到远侧面的完整轴套、宝石、锁扣或护板。
- 资产的 `{OPEN_END}` 被护角、端板、框架或跨接件封死。
- 关键零件数量与 `design_lock.md` 不一致。
- 同一关键零件被复制到正面和背面，或近侧面和远侧面。
- 顶部/底部视图的正面与背面两条轨道同时出现正面高凸装饰。
- 实体端盖额外生成未登记的晶体、窗、尖刺或分离零件。
- 逐视图缩放未记录，或单张图内部发生横纵非等比拉伸。
- 轴向主体占比过小，在平台缩略图中无法形成可辨认轮廓。
- top / bottom 大面积展开属于其他投影平面的表面。
- 45 度图只有局部零件发生旋转，其余零件仍以正面贴片朝向相机。
- 生成侧视前没有用户确认的左右可见性合同。
- 侧视遗漏本侧必见结构，或复制了对侧专属结构。
- 未经用户明确授权就镜像或复用另一侧。

## 通用检查项

| 检查项 | 通过标准 | 失败时怎么处理 |
|---|---|---|
| 单物体 | 画面中只有一个目标道具 | 重生整张 |
| 完整可见 | 物体不裁切，边缘完整 | 重生整张 |
| 背景干净 | 白底或浅灰底，无场景干扰 | 重生整张 |
| 视角稳定 | 正交图没有明显 3/4 透视 | 重生对应图 |
| 比例一致 | 8 张图像同一个资产，大小和厚度接近 | 修偏离图 |
| XYZ 几何比例 | X:Y:Z 比例锁定；逐视图相机倍率已记录且单图内部等比 | 按设计锁等比调整偏离图 |
| 主体检测占比 | 轴向图在缩略图中仍可辨认，长边建议占画布 60%-80% | 等比提高轴向相机倍率 |
| 投影平面正确 | front/back、side、top/bottom 只表达各自登记的二维投影 | 删除跨平面的完整表面并重生 |
| 材质分区明确 | 金属、木头、皮革、纸页、玻璃等颜色清楚 | 调整材质或重生 |
| 零件可解释 | 每个扣件、护角、宝石、绑带都有连接关系 | 删除或简化 |
| 45 度服务结构 | 解释厚度和连接，不新增复杂结构 | 重生 45 度图 |
| 45 度刚体一致性 | 主体、连接件、装饰和端件使用同一旋转轴与角度 | 整件重生，禁止局部拼接 |
| 遮挡关系成立 | 只显示相机方向可见的近侧面，远侧面被主体遮挡 | 按相机可见面矩阵重生 |
| 相反表面互斥 | 左/右、顶/底不能成对大面积出现 | 直接否决并重生 |
| 远侧面轮廓限制 | 远侧面最多只有极窄转角，不能形成独立材质带 | 重生整张，不能只擦除装饰 |
| 远侧完整装饰计数 | 必须为 0 | 固定近侧面后重生整张 |
| 效果图到正面重构 | `front.png` 只保留正面设计，不继承效果图的侧面 | 先重做 front，不继续生成其他视图 |
| 凸出装饰连接层级 | L2/L3 装饰均能通过宽底座连接到主体 | 增加底座、合并块面或删除装饰 |
| 多视图装饰守恒 | 同一装饰在可见视图中的数量、位置和材质一致 | 修正偏离视图 |
| 关键零件清单 | 每个 P-ID 的数量、层级和所属表面与 `design_lock.md` 一致 | 只重生偏离视图 |
| 轨道归属 | 顶/底图只有正面轨道显示正面高凸轮廓 | 删除背面轨道的复制装饰并重生 |
| 实体端盖语义 | 端盖附加零件数量与设计锁一致，未登记时为 0 | 重生端盖相关视图 |

## 相机可见面检查

生成前先写清楚 `yaw / pitch / roll`，生成后再检查实际画面，不能只相信 Prompt。

检查时必须先给画面中的可见区域归属表面，再判断是否合格。  
如果无法明确某个区域属于主表面、近侧面还是远侧面，说明参考图本身存在几何歧义，应重生。

| 相机方向 | 应看到 | 不应看到 |
|---|---|---|
| 正面水平 | 正面 | 大面积左侧、右侧、顶部、底部 |
| 右前水平 | 正面、右侧 | 左侧外表面、顶部、底部 |
| 左前水平 | 正面、左侧 | 右侧外表面、顶部、底部 |
| 右上 | 正面、右侧、顶部 | 左侧外表面、底部 |
| 左上 | 正面、左侧、顶部 | 右侧外表面、底部 |

允许远侧曲面或凸出结构露出窄轮廓，但不允许远侧完整宝石、锁扣、侧板或图案清晰朝向镜头。

## 正交图检查

- [ ] 已记录并确认 `left/right` 各自必须看见、必须隐藏的结构。
- [ ] 已记录方向性结构的数量、位置、顺序和遮挡关系。
- [ ] 若使用镜像，存在用户明确授权与来源记录。

### `front.png`

- 只表达正面主结构。
- 不显示大面积侧面。
- 主要装饰不要伸出轮廓太多。
- 不出现侧面无法解释的新零件。
- 从效果图校准时，必须移除效果图中的右页边、左书脊、顶部和底部信息。
- 凸出装饰必须能看见其 L1 固定底座，不得只剩独立晶体、角、齿轮、羽翼或轨道。

### `back.png`

- 只表达背面结构。
- 不复制正面主核心，除非资产真实两面一致。
- 如果正面有连接件，背面必须能解释连接终点。

### `left.png` / `spine_left.png`

- 镜头正对左侧结构。
- 正面和背面只能表现为薄边。
- 左侧装饰必须贴合主体，不漂浮。

### `right.png` / `page_edge_right.png`

- 镜头正对右侧结构。
- 对书本类资产：主可见面应是纸页层，不是封皮或整块金属。
- 对武器类资产：主可见面应解释刃、柄、护手等真实厚度。
- 对瓶罐类资产：主可见面应解释瓶壁、塞子、标签厚度。

### `top.png`

- 顶部主可见面必须符合资产真实材质。
- 对书本类资产：顶部应能看出纸页层，封皮只作为边框或薄板。
- 必须先标注 `{CLOSED_END}` 与 `{OPEN_END}`，再检查两端是否符合真实结构。
- 对书本类资产：左端书脊可以闭合；右端页口必须开放，纸页层必须延伸到右侧边界。
- 对书本类资产：右端上下护角必须保持分离，禁止 U 形、C 形端框、竖向端板或跨页金属桥。
- 对宝箱类资产：顶部应解释盖子厚度和铰链方向。
- 对武器类资产：顶部应解释刃厚、柄厚和对称性。
- 正面轨道可以显示正面高凸装饰的侧面轮廓；背面轨道不得复制同一套高凸装饰。

### `bottom.png`

- 底部结构与顶部/侧面不冲突。
- 如果有底座、脚垫、护角，必须能解释如何连接。
- 不应出现其他视图没有解释过的孤立零件。
- 必须复查 `{OPEN_END}` 是否仍然开放，不得因为底部护角或底座而被错误封闭。
- 对书本类资产：右端纸页必须直接可见，上下封面护角不能跨过纸页互相连接。
- 正面与背面轨道归属必须和 `top.png` 一致，不能上下视图互换装饰所属面。

## 45 度图检查

### `left45.png`

- 解释正面到左侧的厚度过渡。
- 不强透视、不夸张构图。
- 不新增正交图没有的零件。
- 主体、连接件、装饰和端件必须整件同步侧转，不得只旋转主体的一部分。
- 左侧是近侧面，右侧外表面必须被遮挡。
- 默认水平相机时，顶部和底部都不出现。

### `right45.png`

- 解释正面到右侧的厚度过渡。
- 必须让右侧主材质保持清楚。
- 主体、连接件、装饰和端件必须整件同步侧转；正面装饰应出现统一的横向缩短。
- 右侧是近侧面，左侧外表面必须被遮挡。
- 默认水平相机时，顶部和底部都不出现。
- 如果任务明确要求轻微俯视，只允许顶部出现，底部必须隐藏。
- 对非书本资产：顶部和右侧都应符合真实结构，而不是随意换材质。
- 对书本类资产：左侧完整书脊、圆柱轴套、书脊宝石和多段书脊绑带的可见数量必须为 0。
- 左边只允许出现前封面的极窄转角，不能形成与右页边对应的第二条侧面带。

## 零件决策规则

不要默认让道具越高级，侧边零件越复杂。

优先升级：

- 主轮廓
- 材质质感
- 中心核心
- 大块面分区
- 金属边框
- 结构清楚的护角、端板、握柄、底座

谨慎使用：

- 锁扣
- 铰链
- 绑带
- 链条
- 侧边宝石
- 外凸机关

如果某个零件无法在 8 张图里解释清楚：

```text
删除或简化，不要继续堆复杂度。
```

## 文件与联系表规格检查

- [ ] 8 张正式图文件名齐全。
- [ ] 8 张正式图画布比例一致；正方形项目全部为 `1:1`。
- [ ] 8 张正式图像素尺寸一致。
- [ ] `design_lock.md` 已定义 X/Y/Z、基准轴、理论包围盒和交付相机倍率。
- [ ] 逐视图调整只使用等比相机缩放，没有横向或纵向单独拉伸。
- [ ] 轴向图主体在上传缩略图中可以辨认，长边占比处于约 `60%-80%`。
- [ ] 联系表保留每张正式图的原始画布占用，没有二次放大窄面。
- [ ] 非标准比例源图使用等比缩放与补白处理，没有被横向或纵向拉伸。
- [ ] 联系表中的每张图保持原始宽高比。
- [ ] `失败对照`、`候选`、`原始比例备份` 等子目录未混入正式建模输入。
- [ ] 自动校验结果为缺图 0、尺寸错误 0。
- [ ] `design_lock.md` 中每个关键零件 ID 已逐视图复核。
- [ ] `failure_log.md` 与 `失败对照/` 中的稿件未使用正式文件名。

## 常见失败和修正方式

| 失败现象 | 可能原因 | 修正方式 |
|---|---|---|
| 3D 模型长出奇怪机械块 | 参考图里有 fake clasp 或侧边凸片 | 删除侧边零件，重做侧视图 / right45 |
| 侧面变成金属板 | 侧面材质和金属颜色太接近 | 让主体材质和金属护角分色 |
| 顶部生成成错误材质 | top 或 45 度图顶部材质画错 | 重做 top / right45，明确顶部材质 |
| 零件像贴片 | 缺少铰链、底座、接收点 | 增加真实连接，或取消该零件 |
| 45 度图太像图标 | 强透视、装饰过多、侧面信息弱 | 降低装饰密度，强调厚度 |
| 正面合理但侧面解释不通 | 只按单张图标设计 | 回到 6 张正交图修结构 |
| 远侧宝石或侧板完整可见 | AI 为展示细节拼接了相反视角 | 删除远侧完整结构，保留最多一条窄轮廓 |
| 左右侧面同时清楚 | 不是单一相机能得到的画面 | 固定近侧面后重生整张 |
| Prompt 正确但成图仍露出远侧面 | 生成模型忽略了遮挡描述，自检只检查了关键词 | 按实际像素内容判定失败，使用单相机整图重构模板 |
| 书本页口被护角封成端盖 | 把上下封面护角误合并为连续框架 | 重做 top / bottom，保留两块独立护角，让纸页延伸到开放端 |
| 联系表中的物体被压扁或拉长 | 正式图比例不一致，绘图程序强制填满单元格 | 先等比归一化画布，再重建联系表 |
| 书脊箍带数量增加或减少 | 每张图独立生成，没有零件数量锁 | 按 P-ID 和固定数量重生该视图 |
| 上下端盖长出多余晶体 | 华丽度描述覆盖了端盖结构约束 | 明确端盖为实体块，附加晶体数量为 0 |
| 顶/底两条封面轨都很华丽 | 正面浮雕被复制到背面 | 明确轨道归属，只保留正面一侧高凸轮廓 |

## 联系表检查

完成后必须看：

```text
orthographic_preview_contact_sheet.png
reference_preview_contact_sheet.png
```

检查顺序：

1. 先看 6 张正交图是否互相解释。
2. 再看 45 度图是否补充厚度信息。
3. 最后看是否有某张图比其他图复杂太多。

如果联系表里某张图明显不一致，先修那张，不要继续上传给 3D 工具。

批量任务中，每个资产的联系表必须独立通过，才允许开始下一件资产。
