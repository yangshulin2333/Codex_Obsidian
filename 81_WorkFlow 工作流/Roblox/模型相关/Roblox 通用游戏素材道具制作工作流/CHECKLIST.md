# Roblox 低模道具执行与验收清单

## 1. 开始

- [ ] 当前上下文只有这一个道具。
- [ ] 已选择 Four / Six / Eight，并有简短理由。
- [ ] `资产锁_ASSET_LOCK.md` 已写明低模简化方案。
- [ ] 已区分：保留为几何、改为材质、删除的细节。

## 2. 正视图人工门

- [ ] 结构由少量清楚的大形体组成。
- [ ] 轮廓、厚度、连接和材质区清楚。
- [ ] 没有密集碎片、随机切面、微小尖刺和过度透明。
- [ ] 简化但不粗糙：有受控倒角、清楚层次和稳定边缘。
- [ ] 单物体、完整、正交、均匀背景，无 UI / 文字 / 特效。
- [ ] 用户已明确确认正视图。

本节未通过，不扩展多视图。

## 3. 多视图

- [ ] 所有图是同一物品旋转，不是同系列重设计。
- [ ] 主要轮廓、结构块、连接、厚度和材质区一致。
- [ ] `left/right` 是严格 90°。
- [ ] `left45/right45` 是严格 45°，无俯仰和翻滚。
- [ ] 用户已确认 `left/right` 各自必须看见、必须隐藏的结构。
- [ ] 每张侧视符合自己的可见性合同，没有复制对侧专属结构。
- [ ] 若使用镜像，存在用户明确授权和来源记录。
- [ ] 背面简单合理，没有新增主题或机关。
- [ ] Accepted 目录真实包含完整视图集。

装饰性重复结构只检查整体节奏和层级；身份关键零件才检查精确数量。

## 4. 自动检查

- [ ] 画布、背景、文件名和视图数量正确。
- [ ] 主体比例相对 front 的偏差在配置范围内。
- [ ] 自动处理只有整体等比缩放、移动和补边。
- [ ] 获授权的镜像往返像素差为 0。
- [ ] 已生成归一化报告、SHA-256 清单和联系表。
- [ ] 状态停在 `FILES_READY`。

## 5. 联系表人工门

- [ ] 六 / 四 / 八张图明显是同一个道具。
- [ ] 低模复杂度在各视图一致。
- [ ] 没有某一张突然增加碎片、花瓣、尖刺或材质区。
- [ ] 比例、相机角度和接地 / 居中关系稳定。
- [ ] 用户已确认联系表。

确认后才运行审批脚本并生成正式上传目录。

## 6. 完成交接

- [ ] 回显运行目录。
- [ ] 回显待审核或正式上传目录。
- [ ] 回显联系表。
- [ ] 写明状态：`FILES_READY` / `CONTACT_SHEET_APPROVED` / `3D_RESULT_REVIEWED`。
- [ ] 实际 3D 失败时只修给错信号的视图。

## 生图卡顿

- [ ] 45 秒内向用户更新状态。
- [ ] 90 秒无完成或新输出时报告 `GENERATION_STALLED` 并停止等待。
- [ ] 没有自动重复提交同一视图。

详细恢复动作按需查阅 [[FAILURE_CODES]]。
