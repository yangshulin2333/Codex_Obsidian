# Roblox 低模 RPG 道具快速执行卡

## 一句话目标

把卡面或概念图改造成结构简单、轮廓清楚、材质干净、可稳定扩展多视图的 Roblox 低模道具。

## 每个道具只走 7 步

1. 读源图，写 `资产锁_ASSET_LOCK.md`。
2. 只生成低模正视图，立即展示给用户。
3. 用户确认后，按 4 / 6 / 8 视图扩展。
4. Codex 主动询问并复述 `left/right` 各自必须看见、必须隐藏的结构，等待确认。
5. 分别按合同生成左右侧；只有用户明确授权时才本地镜像。
6. 运行归一化脚本，生成联系表，停在 `FILES_READY`。
7. 用户确认联系表后，发布正式上传目录。

## 正视图通过标准

- [ ] 像 Roblox 游戏道具，不像写实摆件或高细分概念雕塑。
- [ ] 少量大形体主导，轮廓一眼可读。
- [ ] 结构简单但有受控倒角、厚度和层次，不是粗糙基础块。
- [ ] 没有密集碎片、随机切面、微小尖刺和过度透明材质。
- [ ] 装饰没有抢过主体结构；能用贴图表达的细节不新增几何。
- [ ] 单物体、完整、正交、均匀背景、无文字 / UI / 特效。

未通过时只修正视图，不生成其他角度。

## 资产锁只写这些

```markdown
# 资产锁

- Identity ID:
- 名称 / 用途:
- 视图集: Four / Six / Eight
- left.png 必须看见 / 必须隐藏:
- right.png 必须看见 / 必须隐藏:
- 镜像授权: none / 用户明确授权的映射
- Approved front:
- 一句话剪影:
- 主要结构块:
- 厚度与前后层次:
- 主材质区:
- 保留为几何的细节:
- 改成贴图 / 材质的细节:
- 删除的噪声细节:
- 背面 / 隐藏结构政策:
- Roblox size: X × Y × Z studs / SCALE_UNCONFIRMED
- Pivot / Forward / Up:
```

只有数量本身影响身份时才写精确数量。装饰花瓣、裂纹、叶脉和光斑通常只锁节奏与层级，不逐片计数。

## 视图选择

- Four：简单体块和薄体。
- Six：分层、花瓣、托架、中空和复杂厚度。
- Eight：顶底结构重要且有证据。

当前红莲和幻彩莲固定用 Six。

## 多视图硬边界

- 同一设计锁、同一轮廓、同一主要结构块、同一材质区。
- 视图变化只来自水平旋转，不改变造型。
- `left/right` 是严格 90°；`left45/right45` 是严格 45°。
- 两侧分别符合已确认的可见性合同。
- 未经用户明确授权，不得镜像或复用另一侧。
- 自动归一化只做整体等比缩放、移动和补边。

## 状态回报

- 45 秒内必须有进度说明。
- 90 秒无完成或新输出：报告 `GENERATION_STALLED` 并停止等待。
- 不自动重复提交同一视图。

## 完成时必须给用户

- 运行目录。
- 待审核或正式上传目录。
- 联系表路径。
- 当前状态：`FILES_READY` 或 `CONTACT_SHEET_APPROVED`。
