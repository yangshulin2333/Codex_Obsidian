# AI 网格到游戏资产清理管线

> 视频：[My Complete FREE AI 3D Workflow — Characters & Props Pipeline](https://www.youtube.com/watch?v=MjsQhbaonDc)  
> 作者：Stefan 3D AI  
> 时长：24:41；上传日期：2026-04-29  
> 视频定位：从概念、基础网格到清理、拓扑、UV、烘焙、贴图、绑定与 UE5 导入的一条游戏资产流程。角色和道具共用前八段，自动绑骨是角色专用分支。

## 一句话结论

AI 生成的网格只能视为基础坯体。要成为游戏资产，至少还要通过结构装配、拓扑、UV、法线和 AO 烘焙、无光照污染的底色贴图、材质图以及引擎验证；静态道具在这些步骤完成后即可停止，不需要套用角色绑骨。

## 全流程与道具适用范围

| 阶段 | 视频中的做法 | 静态 Roblox 道具是否适用 |
| --- | --- | --- |
| 1. 概念与拆件 | 先确定可生产的设计，再按可分离部件生成。 | 是 |
| 2. 基础网格 | 使用图生 3D 得到部件基础几何；结构信息不足时使用多视图。 | 是 |
| 3. 雕刻与装配 | 在 Blender 对齐部件、去掉遮挡面、修洞与重建。 | 是 |
| 4. 拓扑与清理 | 为每个对象生成或手工修正低模四边面。 | 是 |
| 5. UV 展开与打包 | 展 UV、添加接缝、在合适时合图。 | 是 |
| 6. 烘焙 | 高模到低模烘焙 Normal 和 AO。 | 是 |
| 7. AI 贴图与底色 | 以 Albedo 或平色为主，避免把灯光反射烤进颜色贴图。 | 是 |
| 8. 材质图补修 | 手工修复颜色，并独立控制粗糙度、金属度、发光等图。 | 是 |
| 9. 自动绑骨 | 自动绑定、权重和骨骼测试。 | 否，角色专用 |
| 10. UE5 验证 | 导入、材质和场景检查。 | 是，但应替换为 Roblox Studio 导入与性能检查 |

## 1. 概念与基础网格：先决定是否需要多视图

作者先把角色或道具拆成明确的可分离对象，再为各对象生成基础网格。多视图不是默认必须项，而是在背面信息重要、单张图无法说明厚度或连接关系时才使用。

对道具的判断可简化为：

- 单图能说明主体轮廓、厚度和主要材质分区：先从单图尝试。
- 背面含扣具、内腔、机关、开口或非对称结构：补背视或侧视。
- 外壳和挂件、绳带、瓶塞、核心件互相遮挡：分别生成并装配。

这与 [[参考_Stefan图生3D生产级参考图四步法]] 的“设计母版、按风险拆件、按不确定性补视图”是同一条原则。

## 2. Blender 结构清理：四个最小工具

视频将大量初步修形归纳为四类操作。它们不是完整的 Blender 教程，但可作为 AI 网格清理的最小学习优先级。

| 操作 | 用途 | 道具中的典型场景 |
| --- | --- | --- |
| Grab 或 Elastic Grab | 拉比例、对齐部件、调整轮廓。 | 让瓶盖贴合瓶身、让护套贴合刀身。 |
| Mask 与 Mask Cut | 选择并切除被遮挡、无用或互相穿插的面。 | 去掉挂件下面看不见的主体面，减少穿插。 |
| Smooth | 弱化不需要的生成噪声。 | 抹掉不会影响轮廓的毛刺、起伏和脏块。 |
| Inflate 加 Voxel Remesh | 封闭孔洞、补体积、重新构建局部表面。 | 修复破洞、断裂边缘或不连续的外壳。 |

先处理“装配是否正确”，再追求表面是否漂亮。若对象之间仍互相穿透、内部残留面大量存在，后面的拓扑、UV 和烘焙都会更难。

## 3. 拓扑：AI 加速，不替代判断

视频的思路是先对每个独立对象生成低、中、高不同候选，再查看线框，选择最适合的结果。作者认为中等复杂度资产的自动拓扑通常只能完成大部分工作，仍需手工修坏环线、塌陷区和连接区域。

对 Roblox 道具的质量门：

- 主轮廓处的边线足够支撑形状，不出现明显塌陷。
- 不存在大量悬空碎面、极细长三角面或未连接的小岛。
- 接缝、开口、可见边缘的面流可解释，不依赖烘焙贴图掩盖明显破洞。
- 若是简单硬表面物，手工简化或可靠的减面方案可能比复杂自动拓扑更快。
- 任何“自动拓扑完成百分比”的说法都只是作者经验，不能当作验收标准。

## 4. UV 与合图：按资产关系，而非机械塞入一张图

作者用自动 UV 作为简单对象的起点；复杂对象自动结果失败时，在 Blender 手动加接缝并重新展开。之后根据对象关系决定是否放入同一张贴图集，以减少材质和贴图数量。

适用于 Roblox 的判断：

- 总是先确认拓扑和主要接缝，UV 不要建立在尚未稳定的网格上。
- 同一套道具、同一材质逻辑、同一加载场景的简单部件可以考虑合图。
- 需要单独换色、单独发光、独立复用或不同分辨率的部件，不应为了少一张图强行塞进同一 UV 图集。
- UV 边缘要有足够留白，避免压缩和 Mipmap 后出现颜色渗漏。

## 5. 烘焙：把高模细节转给低模

视频建议在 Blender 的 Cycles 中，把高模细节烘焙到低模的 Normal 与 AO。

- Normal：保留凹凸和锐利细节的视觉信息，而不增加同等几何面数。
- AO：提供接缝、凹槽和遮挡处的深度信息。

烘焙前必须确认：

1. 高模与低模是同一部件关系，且对齐正确。
2. 低模已有稳定的 UV。
3. 所有不需要投射的遮挡件已处理，避免误烘焙。
4. 烘焙结果已在实际材质预览下检查，而非只看图片文件。

## 6. 贴图：底色不要携带假灯光

作者在游戏资产贴图阶段强调 Albedo 或平色输出的重要性。若颜色贴图里已经带有高光、环境反射或阴影，进入不同游戏光照后会出现不合理的二次照明。

道具贴图的最低检查：

- Base Color 只描述固有颜色、图案和可见污渍，不画固定方向的强高光。
- Roughness 与 Metallic 单独控制，不要完全相信 AI 同时生成的材质图。
- Logo、文字、缝线、贴片等可用模板或克隆工具局部修复，不必让 AI 反复重画整个模型。
- 有能量核心或灯光部位时，单独使用 Emissive，并在 Studio 中检查是否过曝。

## 7. 静态 Roblox 道具的结束点

视频最后的自动绑骨、角色权重和 UE5 骨骼资产导入，不是普通静态道具的必经步骤。

对静态 Roblox 道具，建议在以下条件同时满足时结束 Blender 阶段：

- [ ] 部件装配正确，没有可见穿插、破洞和无意义内面。
- [ ] 面数和材质数量符合目标用途。
- [ ] UV 无重叠错误，贴图清晰且留有边缘。
- [ ] Normal、AO、Base Color、Roughness、Metallic、Emissive 按需准备。
- [ ] Pivot、比例、正方向和碰撞策略已锁定。
- [ ] 导入 Roblox Studio 后，在目标距离和目标设备性能下测试通过。

## 时间敏感与待核验

- 视频使用的具体图生 3D、自动拓扑、AI 贴图工具及其“免费”状态可能已变化；不要依据视频标题判断当前价格或额度。
- 不同生成器的网格、贴图和多视图能力差异很大。应先用一件小道具做可导入测试，再决定是否进入批量生产。
- 作者展示的是单次生产案例。它证明流程可行，不等于每个工具、每类资产都能稳定获得相同质量。
