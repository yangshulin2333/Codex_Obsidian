# 复杂道具拆件与引擎组装

> 视频：[From AI to Unreal Engine - Crafting a Cinematic 3D Prop in 8K](https://www.youtube.com/watch?v=XwJ1K2GCJDs)  
> 作者：Stefan 3D AI  
> 时长：10:01；上传日期：2025-11-29  
> 视频定位：以王座场景为例，讲解从 AI 概念到拆件图生 3D、再到 Unreal Engine 组装的短流程。

## 一句话结论

复杂道具和场景不要把“整张概念图”直接交给图生 3D。先把经过确认的设计拆成能独立理解的主体与附件；分别生成并清理后，再在场景中组装，质量和可控性都会更高。

## 视频中的实际流程

### 1. 概念先定稿，再谈 3D

作者先用对话式 AI 生成概念和提示词，再在图像模型中迭代王座设计。初稿太暗时继续调整，直到轮廓、材质和氛围达到可接受的平衡。

这一步的交付物不是最终模型，而是一张可作为设计母版的概念图。

### 2. 承认整件生成的能力边界

作者明确指出：如果要做近景或电影镜头质量，现有图生 3D 很难从一张复杂场景图直接给出全局都足够细的模型。因此他不尝试把完整王座一次生成完成，而是只提取自己需要的部分。

视频中的拆出对象包括：

- 王座主体；
- 破损剑体；
- 权杖；
- 黑色面板；
- 徽章和鹰形装饰；
- 不同角度或版本的剑；
- 女性头像等局部组件。

### 3. 为每个部件生成干净输入图

作者使用图像编辑 AI 从概念图中提取单一部件。第一次结果不理想时继续迭代，并且会主动移除背景，避免图生 3D 把背景也误认为资产的一部分。

这里的原则是：一张输入图只应让模型理解一个主要对象和它必要的连接结构。

### 4. 分别图生 3D，再做人工选择

作者将部件逐一送入图生 3D 工具，按最终用途选择更高或更低的细节级别。视频中还对比了不同生成结果，指出暗部、内侧和背面容易出现脏面或伪影。

重要的不是某个工具名称，而是这条反馈规则：

图生 3D 失败时，先判断失败来自参考图歧义、视图缺失，还是“这一部件不该与主体一起生成”；不要只提高分辨率或重复生成整件资产。

### 5. 在引擎中装配，而非依赖单一整模

最后作者把王座主体和单独生成的装饰件放到 Unreal Engine 场景中组合。这样可以保留每个高价值细节，也能单独调整位置、缩放和材质。

## 可复用的拆件判断表

| 结构情况 | 优先做法 | 原因 |
| --- | --- | --- |
| 主体轮廓完整、材质单一、无复杂附件 | 先整体生成 | 整体一致性通常更好，成本更低。 |
| 绑带、扣环、链条、流苏 | 附件单独出图或单独建模 | 细长物和连接关系容易在整体生成时变形、断裂或融合。 |
| 内腔、开口、夹层、机械腔体 | 拆出外壳与内部关键件，并补视图 | 这些结构常被正视概念图遮挡。 |
| 徽章、图案、浮雕、发光核心 | 作为独立装饰或贴图层处理 | 让主体网格承担这些微细节，常导致脏面和不可控面数。 |
| 多种材质明确分层 | 按材质和装配关系拆分 | 便于后续给不同部件独立材质和粗糙度。 |
| 背面或侧面有机关 | 先补对应视图；仍不清晰再拆件 | 先解决信息缺失，避免无必要的碎片化。 |

## Roblox 的转化方式

视频原目标是电影级 Unreal 场景。迁移到 Roblox 时，应保留它的拆件思想，但替换质量目标。

| 视频做法 | Roblox 适配 |
| --- | --- |
| 以 8K 近景为目标，使用高细节组件 | 先写清 Roblox 的面数、贴图尺寸、材质数量和可交互要求。 |
| 在 Unreal Engine 做视觉组装 | 在 Blender 完成资产装配与检查；导入 Studio 后验证层级、碰撞、缩放和性能。 |
| 为画面质量保留大量独立模型 | 只保留会影响轮廓、交互或视觉识别的独立件；微小装饰优先用贴图或合并网格。 |
| 单件在场景内自由摆放 | 若道具需要拾取、装备或动画，提前锁定 Pivot、挂点和碰撞边界。 |

## 最小执行卡

1. 锁定一张干净设计母版，不再让各视图重新设计。
2. 圈出高风险区域：细长附件、内腔、连接点、异材质层、不对称背面。
3. 判断每个区域应补视图、独立生成，还是改为贴图细节。
4. 为每个独立生成件准备单主体、无背景、轮廓完整的输入图。
5. 分别图生 3D，检查轮廓、厚度、背面、接缝和可装配性。
6. 在 Blender 装配并做低模、UV、贴图与导入前检查；最后再进 Roblox Studio 验证。

## 时间敏感与不应照搬的部分

- 视频展示的图生 3D 工具、免费额度、分辨率选项和界面均可能已变化，使用前应重新核验。
- “更高分辨率”不是通用解法。参考图的清晰度、拆件边界和人工清理通常更关键。
- 该视频没有给出 Roblox 的目标面数、贴图预算、碰撞或导入验证，因此不能作为 Roblox 交付规范。
