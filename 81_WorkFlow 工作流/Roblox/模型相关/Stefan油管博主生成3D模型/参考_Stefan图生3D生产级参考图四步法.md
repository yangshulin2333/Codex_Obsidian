# 图生 3D 的生产级参考图四步法

> 来源：Stefan 3D AI，[4-Step System for Production-Ready 3D References](https://www.youtube.com/watch?v=cHC6s3dCMHI)  
> 适用范围：游戏道具、角色部件，以及送入 Hunyuan / Tripo 等图生 3D 工具前的参考图准备。  
> 边界：视频以角色为示例；下文已提炼为通用道具方法。工具对比属于单次案例，不作为 Hunyuan 或 Tripo 的通用结论。

## 一句话结论

图生 3D 的输入目标不是一张好看的概念图，而是一套由同一设计母版派生、能补齐结构信息的参考图。

## 四步法

创意定稿 → 干净主参考图（设计母版） → 按需拆件 → 按需补多视图 → 图生 3D 与结果复核

### 1. 创意定稿

- 先锁定风格、主轮廓、材质、主配色和功能语言。
- 可以混合使用结构参考与风格参考；从多轮候选中保留局部正确的元素继续迭代。
- 此阶段不追求正交视图，也不直接拿候选概念图去生成 3D。

### 2. 干净主参考图：建立设计母版

- 用已确认的设计制作纯白或浅灰背景的完整道具图。
- 去掉角色、手持姿态、场景、UI、文字和会遮挡结构的特效。
- 明确主体轮廓、主要体块、厚度暗示、材质分区和重要附属物。
- 后续拆件、背视图和侧视图都应从这张母版派生；禁止让每张图重新设计同一件道具。

主参考图的作用不是展示氛围，而是保存完整且一致的设计信息。

### 3. 按需拆件：先处理高风险结构

拆件不是强制步骤。仅在一个部件生成错误会导致模型无法识别、无法装配或明显破坏轮廓时拆出。

适合单独出图的典型部件：

- 绑带、扣环、链条、挂件；
- 可拆的护套、瓶盖、刀鞘、弹匣；
- 有内部空间的容器、帽体、机械腔体；
- 与主体材质、厚度或连接关系显著不同的模块；
- 不对称、被遮挡或背面有关键功能信息的零件。

简单整体道具不应为“看起来更完整”而过度拆件。

### 4. 按需补多视图：由不确定性决定数量

- 背面无新增信息：可以不生成背视图。
- 背面存在扣具、开口、文字、机关或明显不对称：生成背视图。
- 厚度、层次、弧度或前后关系不清：生成左/右侧视图。
- 顶部、底部存在关键结构：再补顶/底视图。

视图生成的核心约束：保持同一物品的轮廓、比例、材质、颜色、装饰和部件数量；只改变观察角度，不新增、删除或重新设计部件。

视频作者的做法是先得到设计母版，再单独补背视图或侧视图，而不是一开始就让模型猜一张多视图九宫格。

## 可复用提示词骨架

### 主参考图

基于已确认的设计，生成单个完整的 [道具名称]。纯白背景，无角色、手、场景、UI、文字或特效。保持清晰的低模主体轮廓、主要结构块、厚度关系和材质分区，完整显示道具。

### 补充视图

基于这张已确认的 [道具名称] 主参考图，生成同一物品的 [背面 / 左侧 / 右侧 / 顶部 / 底部] 视图。保持轮廓、比例、材质、颜色、装饰和部件数量完全一致。不要新增、删除或重新设计任何部件。纯白背景，完整显示道具，无角色、手、场景、UI 或文字。

## 进入图生 3D 前的检查

- [ ] 已有一张干净且完整的设计母版。
- [ ] 高风险附件已单独拆出，或已在母版上明确其连接关系。
- [ ] 每个补充视图都只改变角度，没有改变设计。
- [ ] 视图数量由结构缺口决定，而不是为了凑数量。
- [ ] 侧视图为真实侧面；生成前已确认两个观察方向各自必须显示 / 隐藏的结构；镜像只在用户明确授权时使用。
- [ ] 模型生成后仍需检查内腔、遮挡面、接缝、阴影伪影和可装配性。

## 与当前通用道具工作流的关系

本视频的方法与 [[../Roblox 通用游戏素材道具制作工作流/README]] 的主路径一致：

视频：创意 → 设计母版 → 拆件 → 按需视图 → 图生 3D  
当前工作流：资产锁 → 正视图确认 → 4/6/8 视图扩展 → 归一化与联系表 → 3D 结果反馈

实际执行仍以当前工作流为准：

- 先确认正视图，再扩展其他视图。
- 4、6、8 视图由结构证据决定；不为了凑数生成无意义视图。
- 左右侧分别按已确认的可见性合同生成并检查绕向；不按“是否对称”默认分流，镜像只在用户明确授权时使用。
- 视频是参考方法，不替代现有的资产锁、归一化、联系表和人工确认门。
