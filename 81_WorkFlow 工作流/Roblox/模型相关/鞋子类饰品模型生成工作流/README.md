# 鞋子类饰品模型生成工作流

这套工作流用于 Roblox 游戏内鞋子装备模型的前置参考图生产。目标不是普通插画，而是为 Tripo / 混元 3D 等 image-to-3D 工具准备结构清楚、可建模的 2D 输入图。

## 当前目标

让玩家装备鞋子后，脚部外观发生变化。最终在 Roblox Studio 中拆成两个 Accessory：

- `LeftShoe`：绑定 `LeftFootAttachment`
- `RightShoe`：绑定 `RightFootAttachment`

## 核心原则

1. 先确认一双鞋的整体风格，再拆成左右单鞋图。
2. 单鞋图优先服务 3D 建模，不做广告图、海报图或角色穿搭图。
3. 鞋头、鞋底、鞋面、绑带、鞋口、后跟和侧边结构必须清楚。
4. 颜色和形状要有游戏装备感，但不要堆太多小零件。
5. 每次生成都保留风格锚点、Prompt、输入图和检查结论。

## 执行流程

### 1. 生成一双鞋风格锚点

先生成或选择一张左右鞋都可见的 3/4 效果图，用于确认整体装备风格。

检查点：

- 是否像 Roblox 游戏装备
- 是否低多边形友好
- 是否结构清楚
- 是否没有角色、脚、UI、文字和复杂背景

### 2. 拆成左右单鞋输入图

确认风格后分别生成：

- `RightShoe_3Q.png`
- `LeftShoe_3Q.png`

单鞋图必须只出现一只鞋，背景干净，角度稳定。不要把一双鞋直接丢给 3D 工具作为最终模型输入，否则可能生成成一个连体模型，后续拆 Accessory 会麻烦。

### 3. 进行单鞋自检

每张单鞋图至少检查：

- 是否只有一只鞋
- 是否能看出左右方向
- 鞋头、鞋底、鞋面、绑带、鞋口是否明确
- 是否有太多会导致 3D 碎面的细节
- 是否有文字、Logo、UI、水印、脚或角色

### 4. Tripo / 混元测试后回填记录

3D 生成后记录：

- 哪张 2D 图作为输入
- 3D 模型是否能分清鞋口、鞋底和鞋头
- 是否出现连体、塌陷、碎面、错误贴图
- 是否需要补正视图、侧视图或背面图

## 与通用道具工作流的关系

本流程参考了 `AI道具模型参考图工作流` 的原则：结构清楚优先于华丽、视图服务建模、失败后反查输入图。

鞋子类饰品和普通单体道具的区别是：最终必须拆成左右两个 Roblox Accessory，并且需要绑定脚部 Attachment，所以第一阶段重点不是 8 视图，而是先获得稳定的左右单鞋 3/4 输入图。

## 当前风险

- 鞋底侧边如果装饰块太多，Tripo / 混元可能生成碎面。
- 左右鞋如果不是镜像关系，进入 Roblox 后可能穿戴不对称。
- 单张 3/4 图如果不能解释后跟或内侧结构，后续可能需要补侧视图和背面图。
