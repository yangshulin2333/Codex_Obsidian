## NEW_PROJECT_BOOTSTRAP Gate

新对话必须先完成：

- `run_mode=NEW_PROJECT`。
- 建立全新运行目录，不写入旧项目目录。
- `inherited_case_parameters=FORBIDDEN`。
- 保存用户原始附件/构想的稳定路径或来源说明。
- 从模板建立 `00_brief/PROJECT_LOCK.md` 与 `00_brief/RUN_STATE.md`。
- 初始状态保持 `DRAFT`，下一步唯一动作写为“完成 P0 并等待用户确认”。

未完成时不得进入 P1 或调用图像生成。

## P0 主动询问六组信息

1. 武器参考图/文字构想、类型和暂定名称。
2. 用途：展示 Model、Tool 或 NPC 武器；玩家主要观察距离和视角。
3. 风格、主色、材质、核心识别点和明确禁止项。
4. 图生 3D 平台，以及平台允许上传的视图槽位。
5. 目标总长、单位、三角面和贴图预算；不知道时写 `UNCONFIRMED`。
6. Front、Length/Width/Thickness 轴、尖端和尾端的定义。

P0 只输出结构化 Brief、假设/未决项和下一次需要用户确认的内容。不得预设拆件数、每件视图数量或辅助 45°。

## 允许复用与禁止继承

允许复用：Gate、目录、命名规范、接口合同、导出副本、FBX 回导和 Studio 验收规则。

禁止继承：

- 猫猫剑四部件或冰晶战锤两部件结构。
- 历史目标 Stud、贴图尺寸、三角面和材质参数。
- `Handle` 默认 Root、历史 Pivot、Front 或轴向。
- 历史 front-only、镜像、基础四视图或 `4 + 2` 授权。
- 历史接口、Studio 路径、锚定和碰撞策略。

任何继承都必须由用户对准确字段明确授权，并写入 `PROJECT_LOCK.md`。
