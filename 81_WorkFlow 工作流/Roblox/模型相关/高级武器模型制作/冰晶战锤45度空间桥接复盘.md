# 冰晶战锤 45° 空间桥接复盘

> 本文只记录空间证据修复决策。两部件结构、视图组合、比例、接口和材质均不得成为新武器默认参数。

## 触发原因

锤身基础四视图已经锁定正、背和两端轮廓，但四个正交方向仍没有充分表达“平击打端面—冰晶厚侧壁—金属主体—中央正面机构”的连续体积关系。首轮混元模型因此在中央机构和正侧过渡处发生几何误解。

P5A 视觉验收发现该漂移后，只回退锤身视图包，记录 `p5a_outcome=SPATIAL_BRIDGE_REQUIRED`，补充 `left45/right45`；没有重做已经确认的四视图。

- 两张混元结果截图分别为 `P5A_ATTEMPT01_HUNYUAN_FRONT_OBLIQUE.png` 与 `P5A_ATTEMPT01_HUNYUAN_ALTERNATE.png`；记录文件包含基础四图 Manifest、截图 SHA-256、判断和下一动作。

## 两轮 45° 结果

### v1 失败

- 摄像机带高机位，`pitch` 不为 0，不能作为水平 45° 空间证据。
- 出现透视近大远小，不是严格正交投影。
- 原本平坦、多边形的冰晶击打端被球化。
- 背景仍有渐变，不能进入正式建模输入。

### v2 通过二维视图门

- 单摄像机正交投影：相对 front 为 `yaw ±45°`，`pitch=0°`，`roll=0°`。
- 无透视近大远小；近端保持平击打面，并能读取后方厚侧壁。
- 中央正面机构按刚体旋转产生正交压缩，没有继续保持完整正视形状。
- 与基础四视图保持同一锤身身份、比例、材质区和纯色背景。

## 可复用结论

六视图不是所有高级武器的默认值。先用单正视图或基础四视图试模；只有 P5A 已暴露截面、端面或正侧体积过渡的对应几何漂移，并由用户批准修复分支时，才按部件补 `left45/right45`。其他部件继续使用已批准的基础视图集。
