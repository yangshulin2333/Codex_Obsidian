# 01 Blender 导出副本准备

## 目标

保留源文件不动，在新的导出副本中把正式零件整理成同一坐标系、同一公共枢轴和可解释尺寸。

## 第一步：另存导出副本

在 Blender 中执行：

```text
文件 > 另存为
```

保存为：

```text
Asset_ROBLOX_EXPORT_v01.blend
```

后续删除对象、应用变换、改材质和导出 FBX 都只在这个副本中进行。

## 第二步：只保留正式对象

在 Outliner 中确认正式零件，例如：

```text
HammerHead
Handle
```

删除或移出导出集合：

- Camera、Light、Empty。
- 参考图片和平面。
- 旧版零件、候选模型、隐藏高模。
- `ALIGN_PROXY_*`、`*_DELETE_AFTER_ALIGN` 等对位代理。
- 重复共面环、重复端盖和临时接口外壳。

不要按“当前看不见”判断是否会导出；必须通过 `Selected Objects` 控制范围。

## 第三步：保持分件，不要合并

- 不执行 `Ctrl+J`。
- 一个未来需要在 Studio 单独控制、焊接或绑定贴图的部件，保留为一个 Mesh。
- 一个 Mesh 如果有多个材质槽，应先按材质拆分，或把纹理烘焙成一套 Atlas。

Roblox 的通用 Mesh 兼容合同按“每个 Mesh 一套材质”执行。

## 第四步：建立公共枢轴

推荐把公共枢轴放在握柄中心、底座中心或项目指定的 Root 位置。

前置分支：如果任一正式对象存在 Parent、Constraint 或 Delta Transform，先逐件记录 `matrix_world`，再使用 `Clear Parent Keep Transform`，或复制评估后的网格，把世界变换烘焙进导出副本。完成后才能执行下面的公共枢轴步骤；否则 `Alt+G` 清除的是局部位置，可能拆散装配。

新手手动步骤：

1. 只选根件，例如 `Handle`。
2. `物体 > 设置原点 > 原点到几何中心`。
3. `Shift+S > 游标到选中项`。
4. 选中全部正式零件。
5. `物体 > 设置原点 > 原点到 3D 游标`。
6. `Alt+G` 清除位置，让公共枢轴移动到世界原点。
7. `Shift+S > 游标到世界原点`。

结果：零件相对位置保持不变，但每个对象的原点都落在同一个 Root 上。

如果任一步造成零件相对位置变化，立即撤销并回到检查点。公共 Pivot 是本工作流“导入后不再重新拼接”的发布合同，但不是 Roblox 平台对所有 FBX 的绝对要求。

若 Root 不是几何中心，应使用已确认的 Empty/接口基准，而不是强行使用包围盒中心。

## 第五步：确定尺寸

推荐在导出副本中把 `1 Blender Unit` 当作 `1 Stud`：

1. `场景属性 > 单位 > 单位系统 = 无`。
2. 选中全部正式零件。
3. 围绕公共原点整体等比缩放到目标 Stud 尺寸。
4. 不做每件独立缩放，不改变已经确认的装配比例。

如果来源确实按米制作，只做一次：

```text
整体缩放倍数 = 1 / 0.28 = 3.5714286
```

然后停止使用其他单位补偿。

## 第六步：应用变换

保持全部正式零件选中：

```text
Ctrl+A > 旋转与缩放
```

如果前面已经用公共原点和 `Alt+G` 清除了位置，期望值为：

```text
Location = 0, 0, 0
Rotation = 0, 0, 0
Scale    = 1, 1, 1
```

不要在源文件中应用这些变换。

## Gate P1/P3 验收

- [ ] 正面、侧面、3/4 装配仍正确。
- [ ] 正式对象数量与计划一致。
- [ ] 所有对象共享同一个公共原点。
- [ ] 所有对象的 `Location/Rotation/Scale = 0/0/1`。
- [ ] 完整模型尺寸已经用 Stud 记录。
- [ ] 没有使用 `Ctrl+J` 合并零件。
- [ ] 没有同时使用顶点缩放、对象 100 倍缩放和导出 `0.01`。

通过后进入 [[02_材质纹理与FBX导出]]。
