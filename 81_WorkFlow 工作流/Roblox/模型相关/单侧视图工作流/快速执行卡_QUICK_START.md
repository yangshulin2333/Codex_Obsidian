# 单侧视图快速执行卡

## 标准口令

```text
参考：D:\AI\Codex\Codex_Obsidian\81_WorkFlow 工作流\Roblox\模型相关\单侧视图工作流

当前设计锁：<front.png 路径>
目标：只生成 <left.png / right.png / Side A / Side B>
用途：Roblox / Tripo / 图生 3D

请先：
1. 标明每张参考图的角色；
2. 确认单相机正交 90° 相机参数；
3. 判断基础几何类和修饰合同；
4. 复述该侧必须看见、必须隐藏、数量、顺序和遮挡；
5. 只生成一个候选并停下等待确认。
```

## 如果有背视图

追加：

```text
背视图：<back.png 路径>
它只用于确认背面结构、双面装饰和前后层厚。
```

## 如果有已确认另一侧

独立生成时追加：

```text
已确认另一侧：<path>
它只能作为总高度、画布、厚度和锚点基准。
必须从相反方向独立生成；不得复制、翻转、镜像、描摹或复用像素。
```

## 如果允许镜像

只有用户确实允许时写：

```text
我明确授权：<target> 由已确认 <source> 做本地确定性水平镜像。
请记录来源、目标、授权日期，并做往返像素误差 0 校验。
```

不要把“左右看起来一样”当成授权。

## 修复 3/4 侧视

```text
当前候选不是正 90°。
只修相机：single camera、orthographic、yaw=<-90°/+90°>、pitch=0°、roll=0°。
保持设计、总高度、厚度、锚点、材质和可见性合同不变。
禁止 3/4、透视、倾斜和对角摆放。
```

## 修复“正视图压扁”

```text
不要横向压缩 front。
请根据当前几何类重建真实侧面轮廓，只保留厚度、倒角、层次、接口和侧向可见结构。
完整正面纹理、完整宝石面和展开轮廓必须隐藏。
```

## 修复“侧面过薄”

```text
当前侧面厚度不足。
重新检查几何分类：它可能不是 P1，而是 P3 / V1 / V2。
恢复这些层次或体积：<主体层、后置层、正反凸起、圆鼓、箱体深度>。
保持相机、总高度、柄长和背景不变。
```

## 修复“侧面过宽”

```text
当前候选露出了过多正面。
隐藏：<完整正面、完整宝石、展开辐臂、宽护手>。
只保留：<边缘、薄边、浅凸层、真实厚度、接口>。
相机和锚点不变。
```

## 六种基础几何类速查

| 代码 | 一句话规则 |
|---|---|
| `P1_THIN_PLATE` | 薄，但必须有可读厚度；不露完整正面 |
| `P2_LONG_HEAD` | 变窄但不缩短，不丢护颈 / 插槽 |
| `P3_LAYERED_FLAT_VOLUME` | 正面宽结构重叠成窄体块，保留多层厚度 |
| `V1_ROUND_VOLUME` | 侧面仍保留球 / 圆鼓 / 圆柱体积 |
| `V2_BOX_IRREGULAR_VOLUME` | 按深度结构卡保留箱体、台阶和接口 |
| `O1_OPEN_FRAME` | 保留孔洞、空腔、支撑和前后梁关系 |

## 提交前 10 秒检查

- [ ] 只有一个目标侧。
- [ ] 单相机正交 90°。
- [ ] yaw、pitch、roll 写全。
- [ ] 基础几何类正确。
- [ ] must_visible / must_hidden 写清。
- [ ] 锚点和柄长锁定。
- [ ] 没有横向压扁 front。
- [ ] 没有未经授权镜像。
- [ ] 一次只启动一个生成任务。
- [ ] 候选生成后停下等待确认。
