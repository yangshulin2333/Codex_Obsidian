# 00 Blender 中文术语表

这份表是给后面几篇笔记配套用的。

统一写法：

```text
中文操作名（英文界面名）
```

你先看中文理解意思。括号里的英文只用于两种情况：

- Blender 不是中文界面时，用来找按钮。
- 看英文教程或报错时，用来对照术语。

## 模式与选择

| 中文 | 英文界面名 | 直白解释 |
|---|---|---|
| 对象模式 | Object Mode | 选中整个模型、加修改器、导出。 |
| 编辑模式 | Edit Mode | 编辑模型里面的点、线、面。 |
| 点选择 | Vertex Select | 选单个点。 |
| 边选择 | Edge Select | 选边线。 |
| 面选择 | Face Select | 选表面区域。AI 模型清理最常用。 |
| 透视选择 | X-Ray | 能穿透选择背后的点线面，但容易误选。 |

## 基础清理

| 中文 | 英文界面名 | 用途 |
|---|---|---|
| 按距离合并 | Merge by Distance | 把重叠或非常接近的点合并。 |
| 删除松散元素 | Delete Loose | 删除孤立点、孤立边、小碎片。 |
| 重新计算外侧法线 | Recalculate Outside | 修正面的朝向，避免导出后面消失或发黑。 |
| 有限融并 | Limited Dissolve | 清理平面上多余的线，适合大平面，别乱用在浮雕上。 |
| 面朝向显示 | Face Orientation | 用蓝色/红色检查法线方向。 |

## 减面

| 中文 | 英文界面名 | 用途 |
|---|---|---|
| 精简修改器 | Decimate Modifier | 快速降低面数。 |
| 折叠模式 | Collapse | 整体压低三角面数量，最常用。 |
| 平面模式 | Planar | 清理大平面上的多余面。 |
| 反细分 | Un-Subdivide | 适合规则网格，AI 三角面模型通常少用。 |
| 比例 | Ratio | 保留多少面数。0.5 约保留一半，0.1 约保留十分之一。 |
| 应用修改器 | Apply Modifier | 把预览效果真正写进模型。确认前不要急着点。 |

## 局部保护

| 中文 | 英文界面名 | 用途 |
|---|---|---|
| 隐藏选中 | Hide Selected | 暂时隐藏选中的面，快捷键 `H`。 |
| 只显示选中 | Hide Unselected | 只看选中的面，快捷键 `Shift + H`。 |
| 显示全部 | Show All | 把隐藏的面显示回来，快捷键 `Alt + H`。 |
| 分离选中 | Separate Selection | 把选中的面临时拆成新对象，快捷键 `P > Selection`。 |
| 顶点组 | Vertex Group | 给一批点打标签，用于保护区域或后续控制修改器。 |
| 权重绘制 | Weight Paint | 给顶点组刷强弱，红色权重大，蓝色权重小。 |
| 分配 | Assign | 把当前选中的点或面分配给顶点组/材质。 |

## 简单手修

| 中文 | 英文界面名 | 用途 |
|---|---|---|
| 删除面 | Delete Faces | 删除坏面、内部面、小毛刺。 |
| 填充/补面 | Fill | 给简单小洞补一个面，快捷键 `F`。 |
| 挤出 | Extrude | 从已有面拉出新面，快捷键 `E`。不要连续乱按。 |
| 平滑着色 | Shade Smooth | 让圆柱、圆环看起来更圆。 |
| 平直着色 | Shade Flat | 保留硬表面棱角。 |
| 倒角修改器 | Bevel Modifier | 给新建低模边缘加小倒角。AI 高模不建议全局乱加。 |

## 材质与导出

| 中文 | 英文界面名 | 用途 |
|---|---|---|
| 材质槽 | Material Slot | 一个模型里放多个材质的位置。 |
| 新建材质 | New Material | 创建一个新的颜色/材质。 |
| 分配材质 | Assign Material | 把选中的面指定成某个材质。 |
| 应用变换 | Apply Transform | 导出前清理旋转和缩放，常用 `Ctrl + A`。 |
| 旋转与缩放 | Rotation & Scale | 只应用旋转和缩放，不改位置。 |
| 只导出所选对象 | Selected Objects | 导出 FBX 时只导出当前选中的低模，避免把原始高模一起导出。 |
| FBX 导出 | FBX Export | 给 Roblox Studio 导入用的常见模型格式。 |

## 记忆规则

- 看见 `Object Mode`，先理解成“对象模式”。
- 看见 `Edit Mode`，先理解成“编辑模式”。
- 看见 `Decimate`，先理解成“减面/精简”。
- 看见 `Assign`，先问自己：是分配到材质，还是分配到顶点组。
- 看见 `Apply`，先暂停确认，因为它通常代表“把预览变成真实修改”。
