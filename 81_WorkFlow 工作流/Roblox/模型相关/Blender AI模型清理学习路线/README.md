# Blender AI 模型清理学习路线

这套笔记只服务一个目标：

> 把 Tripo / 混元等 3D AI 生成的一体高模，整理成能进入 Roblox 或后续项目使用的低模道具。

它不是完整 Blender 教程，也不要求从零学习建模。  
当前假设是：你已经会基础视图、选择、对象模式（Object Mode）/ 编辑模式（Edit Mode）的切换，但阶段 2 之后还不熟。

## 阅读规则

这套笔记统一使用：

```text
中文操作名（英文界面名）
```

你先看中文意思。括号里的英文只是界面对照，方便你在英文版 Blender 或英文资料里找按钮。  
如果某个词看不懂，先查 [[00_中文术语表]]。

## 使用对象

当前练习对象：

- `D:\Blender\MagicBook.blend`
- 主要对象：`MagicBook` 或 `Book_Low`
- 用途：AI 生成的一体魔法书模型，后续希望做清理、减面、局部修补、材质和导出

## 核心原则

### 1. 永远先复制工作文件

不要直接改原始 AI 模型。

推荐命名：

```text
MagicBook_original.blend
MagicBook_cleaning_01.blend
MagicBook_decimate_50k.blend
MagicBook_export_candidate.blend
```

### 2. AI 模型不是干净零件

Tripo / 混元生成的模型通常是：

- 一体网格
- 高三角面
- 没有清晰材质分区
- 有内部面、重叠面、小毛刺
- 看起来像零件，实际上焊在一起

所以不要把目标定成“自动拆成完美零件”。更现实的目标是：

- 整体保形
- 删除明显坏面
- 合理降低面数
- 让视觉效果能接受
- 导出到 Roblox 后不爆性能

### 3. 学命令要绑定判断标准

每个命令都要问两个问题：

```text
这个命令解决了什么问题？
执行后怎么判断变好了还是变坏了？
```

只会点按钮没有用。你真正要学的是判断：

- 轮廓有没有塌
- 浮雕有没有糊
- 扣条边缘有没有破
- 书脊圆柱是否还圆
- 面数是否真的下降
- 导出后 Roblox 是否能接受

## 每次练习的固定流程

每次打开模型后，先做这个小流程：

1. 另存为新文件。
2. 打开统计信息，看当前面数。
3. 从正面、背面、侧面、斜视四个角度截图或观察。
4. 执行一个小操作。
5. 再看四个角度。
6. 不满意就撤销，不要硬往下做。

## 推荐的学习节奏

| 天数 | 学习内容 | 目标 |
|---|---|---|
| 第 0 天 | 中文术语表 | 能把常见英文按钮对上中文意思 |
| 第 1 天 | 基础清理命令 | 能安全执行按距离合并（Merge by Distance）、删除松散元素（Delete Loose）、重新计算外侧法线（Recalculate Outside） |
| 第 2 天 | 精简修改器（Decimate） | 能做 100k、50k、25k 三个减面版本并比较 |
| 第 3 天 | 局部选择 | 能选中扣条、书脊、封面一块区域，并临时隐藏或分离 |
| 第 4 天 | 简单手修 | 能删除坏面、补简单洞、修法线显示 |
| 第 5 天 | 材质和导出 | 能给不同区域上简单材质并导出 FBX |
| 随时查 | 清理菜单速查 | 能判断清理命令适合哪里、什么时候会破坏模型 |

## 不建议现在学的内容

先不要学这些：

- 完整角色建模
- 高级雕刻
- 完整重拓扑
- 复杂 UV 展开
- 骨骼绑定
- 节点材质
- Geometry Nodes

这些不是当前瓶颈。当前瓶颈是：

> 能不能把 AI 高模清理、减面、修到能用。
