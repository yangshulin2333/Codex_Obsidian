# 02 精简修改器（Decimate）减面与质量判断

本篇目标：

> 学会用精简修改器（Decimate Modifier）做多个减面版本，并判断哪个版本还能用。

不要一上来追求最终低模。先学会做对比。

如果界面是中文，优先找“精简”。如果界面是英文，找 “Decimate”。术语可查 [[00_中文术语表]]。

## 精简修改器（Decimate）是什么

精简修改器（Decimate Modifier）是 Blender 的快速减面工具。

它适合：

- AI 生成的高面数模型
- 不想手动重拓扑的临时低模
- 先快速压一版能用的游戏道具

它不适合：

- 要求干净布线的角色
- 要做动画变形的模型
- 需要非常规整边流的硬表面资产

你的魔法书属于“道具”，所以精简修改器（Decimate）可以作为第一阶段方案。

## 三种模式

### 折叠模式（Collapse）

最常用的整体减面模式。

用途：

- 快速降低三角面数量
- 保留大体轮廓

风险：

- 浮雕会变糊
- 圆柱会变不圆
- 小装饰可能塌

### 平面模式（Planar）

按平面角度清理面。

用途：

- 封面、封底这种大平面
- 页块侧面的平面

风险：

- 对复杂浮雕帮助有限
- 参数过大可能吃掉硬边

### 反细分（Un-Subdivide）

主要适合规则网格。

AI 三角面模型通常不适合。  
当前阶段可以先不学。

## Blender 入口

对象模式（Object Mode）下选中对象：

```text
中文路径：属性面板 > 修改器 > 添加修改器 > 精简
英文路径：Properties > Modifiers > Add Modifier > Decimate
```

## 推荐练习方式

不要直接应用（Apply）。

先复制对象：

1. 选中 `MagicBook`。
2. `Shift + D` 复制。
3. 命名为：

```text
MagicBook_Decimate_Test
```

4. 给复制对象加精简修改器（Decimate Modifier）。
5. 原始对象隐藏保留。

## 折叠模式（Collapse）的参数怎么理解

折叠模式（Collapse）主要看比例（Ratio）。

```text
Ratio = 1.0   保持原面数
Ratio = 0.5   大约保留 50%
Ratio = 0.25  大约保留 25%
Ratio = 0.1   大约保留 10%
```

魔法书高模约 496k 三角面。大致对应：

| Ratio | 预估面数 | 用途 |
|---|---:|---|
| 0.5 | 248k | 高质量参考，仍然太高 |
| 0.25 | 124k | 观察细节损失 |
| 0.10 | 50k | Roblox 高质量候选 |
| 0.05 | 25k | Roblox 实用候选 |
| 0.03 | 15k | 轻量候选，细节会明显损失 |

## 推荐版本

对当前魔法书，建议做 4 个副本：

```text
MagicBook_100k
MagicBook_50k
MagicBook_25k
MagicBook_15k
```

不要只做一个版本。你需要肉眼对比。

## 质量判断 1：轮廓有没有塌

从远处看模型，重点看：

- 书整体外框是否还直
- 四角是否还圆润
- 书脊圆柱是否还像圆柱
- 扣条是否还突出

如果远处轮廓已经塌了，这个版本不能用。

## 质量判断 2：关键装饰有没有糊

近距离看：

- 中心浮雕是否还能看出形状
- 上下小星星是否还存在
- 扣条菱形是否还清楚
- 书脊浮雕是否还能识别

如果这些装饰都糊了，说明减太狠。

## 质量判断 3：平面有没有出现波纹

AI 模型的封面本来可能就有波纹。减面后可能更明显。

检查：

- 正面封面大平面
- 背面封底大平面
- 页块侧面

如果平面出现很多坑洼，可以考虑：

- 局部用平面模式（Planar）
- 手动新建干净封面平面
- 把 AI 高模只作为参考

## 质量判断 4：有没有新增破洞

减面后检查：

- 扣条连接处
- 书脊和封面交界
- 四角装饰边缘
- 浮雕尖角

如果有破洞，说明精简修改器（Decimate）不适合一步到位，需要提高比例（Ratio）或做局部保护。

## 应用修改器（Apply Modifier）是什么

应用（Apply）是把修改器结果真正写进网格。

在应用（Apply）之前：

- 修改器只是预览
- 你可以调 Ratio
- 你可以关闭或删除修改器

应用（Apply）之后：

- 网格真的变成低面数
- 撤销之外不容易回头

所以建议：

```text
确认版本满意后再应用（Apply）。
```

## 魔法书练习

### 练习 A：做 50k 候选

1. 复制 `MagicBook`。
2. 命名 `MagicBook_50k_test`。
3. 添加精简修改器（Decimate Modifier）。
4. 模式（Mode）选折叠（Collapse）。
5. 比例（Ratio）设 `0.10`。
6. 不应用（Apply），先观察。

检查：

- 正面浮雕
- 右侧扣条
- 左侧书脊
- 背面封底

### 练习 B：做 25k 候选

复制另一个对象：

```text
MagicBook_25k_test
```

比例（Ratio）设：

```text
0.05
```

和 50k 对比。

### 练习 C：做 15k 候选

复制另一个对象：

```text
MagicBook_15k_test
```

比例（Ratio）设：

```text
0.03
```

这个版本大概率会损失细节，但可以作为性能下限参考。

## 什么时候用平面模式（Planar）

平面模式（Planar）更适合局部：

- 封面大平面
- 封底大平面
- 页块侧面

不建议直接全模型使用平面模式（Planar）。  
更稳做法是先分离大平面或选中区域，再测试平面模式（Planar）。

## 常见错误

### 错误 1：直接应用（Apply），没留原始对象

处理方式：

- 以后先复制对象
- 原始对象隐藏保留

### 错误 2：只看面数，不看轮廓

面数低不代表可用。  
游戏资产要同时看：

```text
面数 + 轮廓 + 细节 + 导入效果
```

### 错误 3：从 500k 一步压到 10k

这样很容易糊。  
建议先做 100k、50k、25k、15k 四个版本。

## 本章完成标准

你能做到：

- 给对象添加精简修改器（Decimate Modifier）
- 知道折叠模式（Collapse）/ 平面模式（Planar）/ 反细分（Un-Subdivide）的区别
- 做出 3 个不同面数候选
- 判断轮廓有没有塌
- 判断浮雕、扣条、书脊有没有糊
