# 05 材质与 Roblox 导出

本篇目标：

> 给清理后的模型做简单材质分区，并导出 FBX 给 Roblox 测试。

当前先不学复杂 UV 和贴图。  
先能做到基础颜色分区和可靠导出。

## 材质槽是什么

一个网格（Mesh）可以有多个材质槽（Material Slot）。  
你可以把不同面分配给不同材质。

魔法书常见分区：

- 封面
- 封底
- 书脊
- 扣条
- 浮雕
- 页块

## 新建材质槽

步骤：

1. 选中对象。
2. 右侧材质属性（Material Properties）。
3. 点击 `+` 新增材质槽。
4. 点击新建（New）。
5. 命名：

```text
MAT_Cover
MAT_Spine
MAT_Clasp
MAT_Ornament
MAT_Pages
```

6. 设置颜色。

## 分配材质（Assign Material）

给选中的面分配材质。

步骤：

1. 编辑模式（Edit Mode）。
2. 面选择（Face Select）。
3. 选中一块区域。
4. 在材质槽里选择目标材质。
5. 点击分配（Assign）。

判断：

- 选中面应该变成对应颜色。
- 如果没变化，检查是否在编辑模式（Edit Mode），是否真的选中了面。

## 魔法书练习：给扣条上颜色

1. 选中魔法书对象。
2. 新建材质 `MAT_Clasp`。
3. 编辑模式（Edit Mode）。
4. 选中扣条区域。
5. 点击分配（Assign）。
6. 看扣条是否变色。

这一步练的是“选择 + 分配”，不是追求最终美术效果。

## 应用变换（Apply Transform）

导出前建议应用变换。

入口：

```text
中文路径：对象模式 > Ctrl + A > 旋转与缩放
英文路径：Object Mode > Ctrl + A > Rotation & Scale
```

中文可能是：

```text
应用 > 旋转与缩放
```

用途：

- 避免导入 Roblox 后尺寸异常
- 避免旋转轴不一致
- 避免缩放不是 1

注意：

应用变换前先保存一个版本。  
如果模型有复杂父子层级，先不要乱应用（Apply）。

## 原点（Origin）

道具导入 Roblox 时，原点会影响摆放。

魔法书建议：

- 原点放在书本中心
- 或放在底部中心，方便摆放到地面

当前阶段先不强求。  
只要导入后不严重偏移即可。

## FBX 导出（FBX Export）

入口：

```text
中文路径：文件 > 导出 > FBX
英文路径：File > Export > FBX
```

推荐基础设置：

```text
只导出所选对象（Selected Objects）：开启
应用变换（Apply Transform）：视情况开启
网格（Mesh）：开启
骨架（Armature）：不需要
动画（Animation）：关闭
```

如果只是单个道具，导出前先选中最终对象。

## Roblox 导入前检查

导出 FBX 前检查：

- 面数是否在目标范围内
- 没有明显破洞
- 没有漂浮碎片
- 材质槽名称清楚
- 尺寸大致合理
- 原始高模隐藏或不导出

## Roblox 导入后检查

导入 Roblox Studio 后看：

- 尺寸是否正常
- 朝向是否正常
- 是否有面消失
- 材质分区是否保留
- 性能是否可以接受
- 远处看轮廓是否还清楚

## 面数建议

这不是绝对标准，但可以作为初始判断：

| 用途 | 建议三角面 |
|---|---:|
| 普通小道具 | 1k - 5k |
| 中等展示道具 | 5k - 15k |
| 重要近景道具 | 15k - 30k |
| 高质量展示版本 | 30k - 50k |

魔法书这种装饰多的道具，建议先做：

- 50k 展示版
- 25k 实用候选
- 15k 轻量候选

最终用哪个，要看 Roblox 实机效果。

## 常见错误

### 错误 1：导出了隐藏原始高模

导出前开启：

```text
只导出所选对象 / Selected Objects
```

只导出选中的低模候选。

### 错误 2：没有应用缩放（Apply Scale）

导入后尺寸奇怪。  
解决：导出前检查 Transform，必要时 `Ctrl + A > Rotation & Scale`。

### 错误 3：材质太复杂

当前先用简单材质。  
不要一开始研究复杂贴图节点。

## 本章完成标准

你能做到：

- 新建材质槽
- 把材质分配给选中面
- 导出一个 FBX
- 知道导出前检查只导出所选对象（Selected Objects）
- 知道 Roblox 导入后检查尺寸、朝向、材质和面数
