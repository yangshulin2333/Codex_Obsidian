# 03 局部选择与保护

本篇是你最需要反复练的部分。

目标不是马上修好模型，而是先做到：

> 我能准确选中封面、扣条、书脊、浮雕中的一块区域，并单独观察或处理它。

AI 一体模型不好拆，根本原因就是选择困难。  
所以局部选择能力比具体命令更重要。

## 基础模式

进入编辑模式（Edit Mode）后，顶部可以切换：

- 点选择（Vertex Select）：选单个点
- 边选择（Edge Select）：选边线
- 面选择（Face Select）：选表面区域

当前阶段优先用：

```text
面选择 / Face Select
```

因为你要处理的是模型表面区域。

## 选择区域的三种方法

### 方法 1：框选

快捷键：

```text
B
```

适合：

- 大面积封面
- 页块侧面
- 简单矩形区域

风险：

- 容易选到背面
- 容易选到内部面

建议配合正交视图使用。

### 方法 2：圈选

快捷键：

```text
C
```

适合：

- 扣条边缘
- 浮雕局部
- 小星星

操作：

- 鼠标滚轮调整圆圈大小
- 左键涂选
- 中键取消选择
- 右键退出

### 方法 3：L 选择相连区域

鼠标悬停在一块网格上，按：

```text
L
```

适合：

- 真正分离的网格岛

但 Tripo 一体模型通常是整体焊死的，所以 L 不一定有用。

## 正交视图很重要

不要在透视斜视角乱选。

常用视图：

```text
Numpad 1    Front
Numpad 3    Right
Numpad 7    Top
Ctrl + Numpad 1    Back
```

如果没有小键盘，可以用菜单：

```text
视图 > 视点 / View > Viewpoint
```

魔法书建议：

- 正面封面：从正视图（Front）看
- 背面封底：从后视图（Back）看
- 左侧书脊：从侧面看
- 扣条：正面和侧面都看

## 隐藏选中（Hide Selected）/ 只显示选中（Hide Unselected）

### 隐藏选中（Hide Selected）

快捷键：

```text
H
```

作用：隐藏选中的面。

### 只显示选中（Hide Unselected）

快捷键：

```text
Shift + H
```

作用：只显示选中的面，隐藏其他面。

### 显示全部（Show All）

快捷键：

```text
Alt + H
```

作用：显示回来。

## 为什么隐藏很重要

隐藏不是删除。  
它用于检查：

- 我选中的区域是否准确
- 有没有选到背面
- 有没有漏选
- 这块区域单独看是否完整

练习时先不要急着分离（Separate）。  
先用隐藏（Hide）检查选区。

## 分离选中（Separate Selection）

快捷键：

```text
P > 选中项 / Selection
```

作用：把选中的面分离成新对象。

适合：

- 临时单独减面
- 单独上材质
- 单独检查区域

风险：

- 原对象会留下洞
- 如果选区不准，新对象会带毛边
- 对一体 AI 模型无法自动生成干净边界

所以分离选中（Separate Selection）更适合“临时处理”，不适合期待完美拆件。

## 顶点组（Vertex Group）是什么

顶点组（Vertex Group）可以理解为：

> 给一批点打标签，告诉 Blender 这些点属于某个区域。

用途：

- 标记浮雕
- 标记扣条
- 标记书脊
- 后续配合精简修改器（Decimate）做局部保护

## 创建顶点组（Vertex Group）

步骤：

1. 进入编辑模式（Edit Mode）。
2. 选中一块区域。
3. 右侧对象数据属性（Object Data Properties）。
4. 找到顶点组（Vertex Groups）。
5. 点击 `+`。
6. 命名：

```text
Protect_Ornaments
Protect_Clasp
Protect_Spine
```

7. 点击分配（Assign）。

## 权重绘制（Weight Paint）简单理解

权重绘制（Weight Paint）是给顶点组刷权重。

当前只要理解：

```text
红色 = 权重大
蓝色 = 权重小
```

如果精简修改器（Decimate）支持顶点组控制，可以用权重决定：

- 哪些地方少减
- 哪些地方多减

当前阶段不必深入，只要知道顶点组（Vertex Group）是局部保护的基础。

## 魔法书练习 1：选扣条

目标：准确选中右侧扣条附近面。

步骤：

1. 选中 `MagicBook`。
2. 编辑模式（Edit Mode）。
3. 面选择（Face Select）。
4. 正面视图。
5. 用 `C` 圈选扣条。
6. 按 `Shift + H` 只显示扣条。
7. 旋转视图检查：
   - 有没有选到封面大平面
   - 有没有漏掉扣条侧壁
   - 菱形扣件是否完整
8. `Alt + H` 显示回来。
9. `Ctrl + Z` 撤销到练习前。

完成标准：

```text
你能只显示扣条，并判断选区是否多选/漏选。
```

## 魔法书练习 2：选书脊圆柱

目标：只选左侧圆柱书脊，不选封面左边框。

步骤：

1. 切到侧面视图。
2. 用框选或圈选选中圆柱主体。
3. `Shift + H` 只显示选中区域。
4. 检查：
   - 圆柱上下环箍是否包含
   - 封面边框是否误选
   - 书脊上的浮雕是否包含

完成标准：

```text
书脊作为一个区域看起来完整，但没有吃进太多封面。
```

## 魔法书练习 3：选封面大平面

目标：选中封面平面，不选中心浮雕。

这比较难，但很有用，因为主体大平面通常可以减面更多。

步骤：

1. 正面视图。
2. 面选择（Face Select）。
3. 先框选封面区域。
4. 用中键圈选取消中心浮雕和扣条。
5. `Shift + H` 检查。

完成标准：

```text
剩下的区域主要是封面平面，而不是浮雕和扣条。
```

## 常见错误

### 错误 1：没开透视选择（X-Ray）就选不到背后

有时你需要选穿透区域。  
可以打开透视选择（X-Ray），但要注意它会选到背面。

建议：

- 精准选外表面时，不开透视选择（X-Ray）
- 需要选整体厚度时，再开透视选择（X-Ray）

### 错误 2：分离选中（Separate Selection）后以为拆件成功

分离选中（Separate Selection）只是把选中面分成新对象。  
它不会自动补边，也不会变成干净零件。

### 错误 3：选区没检查就执行修改

任何局部减面或删除前，先：

```text
Shift + H
```

只看选区。

## 本章完成标准

你能做到：

- 用框选、圈选选择区域
- 用 H / Shift+H / Alt+H 检查选区
- 用 `P > 选中项（Selection）` 临时分离
- 创建一个顶点组（Vertex Group）
- 能解释为什么 AI 一体模型很难自动拆件
