# AI 3D 游戏资产制作工作流学习手册

## 从 AI 概念设计到游戏级资产制作

版本：V1.0

------------------------------------------------------------------------

## 1. 当前 AI 建模工作流

当前流程：

需求 → Codex 生成设计描述 → AI 生成概念图 → 筛选方案 → 生成多视图 →
Tripo / 混元3D生成模型 → Blender优化 → 降低面数 → AI生成纹理 →
导出游戏资产

优势： - 不需要专业建模背景 - 适合独立游戏开发快速迭代 -
可以批量制作游戏道具

主要问题： 1. 纹理边界模糊 2. 降面导致细节损失 3. 缺少专业游戏资产流程

------------------------------------------------------------------------

# 2. 当前质量瓶颈

## 纹理问题

AI贴图容易出现：

-   金属和宝石颜色混合
-   材质边界模糊
-   细节不稳定

原因：

AI无法理解明确材质区域。

专业流程：

模型区域定义 → 材质分类 → 纹理制作

# 4. Substance Painter

Substance Painter 是游戏行业常用材质制作软件。

负责：

-   颜色
-   金属度
-   粗糙度
-   磨损
-   划痕
-   灰尘
-   PBR材质

Blender负责模型。

Substance负责模型是什么材质。

对于魔法剑：

剑刃： - 金属材质

宝石： - 发光透明材质

手柄： - 皮革材质

可以分别控制。

------------------------------------------------------------------------

# 5. UV基础

UV就是把3D模型展开成2D贴图坐标。

需要学习：

-   检查AI模型UV
-   修复明显错误
-   减少贴图拉伸
-   给重要区域更多空间

不需要学习电影级UV。

------------------------------------------------------------------------

# 6. Bake烘焙

Bake不是加权法线。

Weighted Normal： 改善模型光照效果。

Bake： 把高模细节转换成贴图。

流程：

High Poly高模 ↓ Low Poly低模 ↓ Bake ↓ Normal Map / AO / Curvature

效果：

低面数模型拥有接近高模的视觉细节。
