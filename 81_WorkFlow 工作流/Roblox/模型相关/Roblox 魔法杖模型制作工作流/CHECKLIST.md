# Roblox 魔法杖多视图执行与验收清单

## 1. 效果图阶段

- [ ] 只生成一张效果图用于筛选，没有提前生成多视图。
- [ ] 每把法杖完整、互不遮挡、正面朝向一致。
- [ ] 用户已经明确选择目标法杖。

## 2. 正视图门禁

- [ ] 当前只生成或扣取了 `front.png`。
- [ ] 用户已明确确认 `front.png`。
- [ ] 单一物体、完整可见、没有触边或裁切。
- [ ] 没有相邻物体像素和嵌套矩形底图。
- [ ] 没有文字、水印、UI、特效和背景场景。

未通过本节时，禁止生成其他视图。

## 3. 结构与深度锁

- [ ] 总高定义为 100%，各段比例已记录。
- [ ] 固定组件数量和位置已记录。
- [ ] 颜色和材质已写死。
- [ ] 四个侧向输出的可见性合同已由 Codex 主动询问、复述并获得用户确认。
- [ ] 杖身、宝石、托架和尾部的局部深度已记录。

## 4. 侧向可见性合同门禁

- [ ] `left.png` 的必须看见 / 必须隐藏结构已确认。
- [ ] `right.png` 的必须看见 / 必须隐藏结构已确认。
- [ ] `left45.png` 的必须看见 / 必须隐藏结构已确认。
- [ ] `right45.png` 的必须看见 / 必须隐藏结构已确认。
- [ ] 单侧结构的准确数量、位置和前后遮挡关系已逐项记录。
- [ ] 文件名与相机观察方向的映射已由 Codex 复述并得到用户确认。
- [ ] 没有用“是否对称”的判断替代上述确认。

未通过本节时禁止生成任何侧向视图，标记 `SIDE_VISIBILITY_CONTRACT_MISSING`。

## 5. left45 门禁

- [ ] 正交 45°，零俯仰、零翻滚。
- [ ] 总高和纵向锚点与正面一致。
- [ ] 组件数量、颜色和材质无漂移。
- [ ] 宝石和托架显示可信厚度。
- [ ] 全物体完整，四周留白充分。

## 6. left90 双门禁

- [ ] 同时参考了 `front.png + left45.png`。
- [ ] 相机为严格垂直 90°，不是 80° 或 3/4。
- [ ] 杖身保持圆柱 / 椭圆直径，没有变成细线。
- [ ] 宝石显示侧体、倒角或凸面厚度，没有变成彩色薄片。
- [ ] 托架保留前后叠层。
- [ ] 金属环和尾部保留三维体积。

## 7. 其余侧向视图

- [ ] `left/right/left45/right45` 分别符合自己的已确认合同。
- [ ] 必须看见与隐藏的结构、数量、位置和遮挡关系均正确。
- [ ] 如果使用镜像，用户已明确点名来源文件和目标文件。
- [ ] 镜像授权内容和日期已写入运行记录；授权没有扩展到未点名文件或其他资产。

违反可见性合同标记 `SIDE_VISIBILITY_CONTRACT_BROKEN`；未获授权镜像标记 `UNCONFIRMED_SIDE_MIRROR`。

## 8. 背视图

- [ ] 轮廓、总高、组件数量和纵向锚点一致。
- [ ] 材质分区一致。
- [ ] 背面细节合理简化，没有重新设计。

## 9. 最终目录

- [ ] 6 张图画布一致、等比缩放、上下留白接近。
- [ ] contact sheet 中所有视图明显是同一物体。
- [ ] 没有任何裁切、文字、水印或场景。
- [ ] 最终目录只包含以下文件：

```text
front.png
back.png
left.png
right.png
left45.png
right45.png
```
