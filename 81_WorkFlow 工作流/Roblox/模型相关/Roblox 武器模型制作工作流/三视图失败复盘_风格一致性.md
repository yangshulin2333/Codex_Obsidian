# 三视图失败复盘：风格一致性

更新时间：2026-06-15

## 触发背景

用户反馈“风格不对啊”“你太让我失望了”。这说明三视图流程虽然执行了生成、检查和入库步骤，但没有真正守住用户最在意的视觉目标：看起来必须像参考截图的同系列 Roblox 武器，而不是另起一个新风格。

## 失败问题

1. 改款幅度过大。
   用户要求“颜色和形状稍微变化”，不是重新设计成另一把不同风格的武器。局部颜色、宝石、纹路、边缘形状可以微调，但武器身份、比例、材质和渲染质感不能被改掉。

2. 风格锁定不够严格。
   参考图是 Roblox 视口里的 3D 武器模型截图。后续输出必须保留这种视口截图感、低模游戏资产感、材质粗细、光照、比例和装饰密度。不能变成平面矢量图、过度简化低模图、写实海报或另一种概念设计。

3. 过度关注流程合规。
   生成三张图、运行本地渲染、写入记录都不是最终目标。最终目标是：图片能否让用户一眼判断“这是原武器的同系列改款”，并且能稳定用于 3D AI 建模。

4. 没有先做风格小样确认。
   当风格风险很高时，应先产出一张正视图候选让用户确认方向，再继续侧视图和背视图。不要在风格未确认时一次性完整交付三张图。

5. 三视图建模价值不足。
   侧视图不能只是细线，背视图也不能像另一把武器。三张图必须来自同一个设计定义，并能表达厚度、背面面板、侧面装饰和主轮廓关系。

## 后续硬性规则

1. 第一优先级是原图风格一致性，不是“重新设计得更完整”。
2. 先锁定参考截图的视觉风格，再锁定武器结构，最后才允许颜色和局部形状小改。
3. “同系列改款”默认只允许小改，不允许换武器类型、换材质语言、换渲染风格或重做比例。
4. 如果用户说“风格不对 / 风格变了 / 失望 / 不像”，立刻停止继续产出最终图，先做复盘和一张正视图纠偏小样。
5. 本地 Blender / 矢量 / Three.js 只是工具路线，不自动代表风格正确。每次都必须用参考截图做视觉对照。
6. 最终验收先问两个问题：
   - 像不像参考图的同系列武器？
   - 能不能直接喂给 3D AI 建模？

## 正确执行顺序

1. 读取参考图，写出视觉锁定：
   - 武器类型
   - 主轮廓比例
   - 材质语言
   - 主色和发光色
   - 装饰密度
   - Roblox 视口 / 低模 / 贴图质感

2. 写出允许变化范围：
   - 颜色只做轻微偏移
   - 局部宝石、纹路、边角、刃形小改
   - 不改变总高度、主结构、风格、材质大类

3. 高风险任务先做一张正视图候选。

4. 正视图风格通过后，再生成 side / back。

5. 三张图入库前必须人工视觉检查，不只检查文件尺寸和路径。

## 失败候选处理

失败候选可以保留在版本目录中用于追溯，但最终回复和后续推荐必须明确标记“不推荐使用”。如果旧版风格错误，新版目录必须使用 `_v2_`、`_v3_`，不要覆盖旧结果。
