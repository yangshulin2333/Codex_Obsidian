## 四档修改程度

```
基本不改：尽量保持原图设计，只整理视角、构图、清晰度和对称性，不重新设计，不添加明显新元素。
```

```
轻微优化：保持原图高度相似，只轻微调整边缘、比例、装饰细节和颜色层次，让武器更规整、更清楚。
```
