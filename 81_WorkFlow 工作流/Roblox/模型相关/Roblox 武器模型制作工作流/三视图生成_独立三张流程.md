# Roblox 武器三视图独立生成流程

更新时间：2026-06-15

## 适用场景

当用户提供武器参考截图，并表达下面这类需求时，使用本流程：

```text
根据这个武器生成同系列改款三视图
用于 3D AI 模型生成
颜色和形状稍微变化
注意图片一致性
```

本流程只负责生成概念参考图，不负责把 FBX / GLB 打包成 Roblox 可导入文件。用户给模型下载目录或 FBX 并要求“生成可直接导入 roblox 版本”时，仍然走 `Prepare-RobloxWeaponImport.ps1` 固定打包流程。

## 默认交付规则

从 2026-06-10 起，三视图生成默认交付三张独立图片：

```text
*_front_view.png
*_side_view.png
*_back_view.png
```

不要默认只生成一张三视图合图再裁切。合图可以作为人工检查用的附加文件，但不能替代三张独立视角图。

## 错误图隔离与风格保护规则

从 2026-06-15 起，用户强调“风格一致 / 用于 3D AI 模型生成 / 重新生成 / 不要跑偏”时，正式交付不要默认先调用内置图像生成。优先使用本地可控流程，例如 Blender 正交渲染、可控矢量绘制、Three.js 场景或已有模型固定视角截图。

### 风格一致性失败复盘规则

如果用户反馈“风格不对 / 风格变了 / 不像 / 太失望”，必须先读取并执行：

```text
D:\SVN\Project_Analysis_Package\Roblox 武器模型制作工作流\三视图失败复盘_风格一致性.md
```

这类反馈说明问题不只是图片生成失败，而是没有守住参考图的武器身份和 Roblox 视口风格。下一版不要直接继续完整生成三张图，应先做一张正视图纠偏小样，并重点确认：

1. 是否像参考图的同系列武器。
2. 是否保留原截图的 3D / Roblox / 低模游戏资产质感。
3. 是否只做了颜色和局部形状小改。
4. 是否没有把武器改成另一种材质语言、另一种比例或另一种美术风格。

本地 Blender、矢量绘制、Three.js 或图像生成只是工具路线，不自动代表风格正确。视觉验收必须优先于流程完成度。

如果内置图像生成出现任意一种情况，立刻停止把它作为主交付路线：

```text
无关信息图
图表
咖啡 / 人物 / 税表 / 传记类图片
文字海报
非武器内容
武器类型明显变了
风格从 Roblox 低模截图变成平面插画或写实海报
```

处理规则：

1. 错误图不要复制到 `generated_views`。
2. 错误图不要作为最终回复的交付内容。
3. 同一任务不要反复重试同一种失控路线。
4. 改走本地可控渲染或绘制，并在 `PROMPT.md` 记录 `generation_route`。
5. 如果用户要求“重新生成”，在原目录旁新建 `_v2_`、`_v3_` 目录，不覆盖旧输出，方便追溯。
6. 如果上一版被用户指出“风格变了”，新版必须先锁定参考图的渲染风格，再锁定颜色和形状变化。

## 强制入库门禁

从 2026-06-15 起，三视图正式交付必须经过“候选图 -> 人工验收 -> 正式入库”三步，不允许把生成目录里的图片直接当成最终交付。

硬性禁止：

```text
不要用 C:\Users\14176\.codex\generated_images 全局最新 PNG 作为复制来源
不要用 Get-ChildItem -Recurse | Sort-Object LastWriteTime -Descending | Select-Object -First 1 来选图
不要在没有 view_image / 人工视觉检查前写入 generated_views
不要把无关图、信息图、人物图、海报图、带文字图写入工作记录
```

正确入库顺序：

1. 先记录本次图像生成工具返回的“本次生成目录”，例如 `C:\Users\14176\.codex\generated_images\019...`。只允许从这个目录挑候选图。
2. 复制前必须用 `view_image` 查看候选图，确认它是单把武器、正确视角、无文字、无人物、无信息图、无 UI、无水印。
3. 通过检查后，使用固定脚本复制到正式目录：

```powershell
& "D:\SVN\Project_Analysis_Package\Roblox 武器模型制作工作流\scripts\Approve-ThreeViewCandidate.ps1" `
  -SourcePath "候选图完整路径" `
  -ExpectedRunDir "本次生成目录或本地可控输出目录" `
  -OutputDir "D:\SVN\Project_Analysis_Package\Roblox 武器模型制作工作流\generated_views\武器名_日期_three_views" `
  -WeaponName "武器名" `
  -View front `
  -ApprovedByVisualCheck
```

4. `front / side / back` 三张图都入库后，再统一检查尺寸、完整性和一致性。
5. 只有通过检查的正式目录路径才能写入 `工作记录.md` 和最终回复。

如果内置图像生成第一次出现无关图，本任务立刻切换到本地可控流程；不要继续用同样 prompt 反复试。

## 执行步骤

1. 先根据用户参考图写一个“设计锁定说明”，明确武器类型、比例、主轮廓、颜色、材质、装饰位置、Roblox 视口截图感和允许变化范围。
2. 在 `PROMPT.md` 写清楚 `generation_route`，例如 `image_gen_candidate_then_approved_copy` 或 `local_controlled_render`。
3. 如果参考图风格复杂、用户刚指出风格问题，先只生成一张正视图候选让用户确认方向。
4. 风格确认后，分别生成三张图：正视、侧视、背视。
5. 三张图必须共享同一段设计锁定说明，只改变视角要求。
6. 每张图都要求完整显示武器，从顶部尖端到底部尖端不能裁切。
7. 背景使用纯白或浅灰，不要场景、地面、UI、文字、水印。
8. 每张候选图必须先视觉验收，再用 `Approve-ThreeViewCandidate.ps1` 入库。
9. 三张正式图入库后检查一致性；如果只有某一张不一致，只重做那一张，不要整套推翻。
10. 最终回复给三张独立图的可点击链接。
11. 成功或失败后更新 `工作记录.md`。

## 设计锁定模板

```text
Design lock:
Create one same-series redesigned Roblox fantasy weapon based on the provided reference screenshots.
Keep the same weapon family identity: <武器类型、主轮廓、关键结构>.
Make only moderate variant changes: <颜色变化、局部形状变化>.
The front, side, and back images must describe the exact same weapon design.
Use the same total height, same handle length, same head size, same blade shape, same guard position, same pommel shape, and same decorative element placement in all views.
Use a clean Roblox low-poly readable silhouette with hand-painted texture detail, not dense high-poly sculpture.
```

## 三张图 Prompt 模板

### 正视图

```text
Use the shared Design lock.
Generate only the FRONT VIEW of the weapon.
Single weapon, vertical, centered, full length visible, orthographic camera, no perspective.
Show the main silhouette clearly and symmetrically where appropriate.
Plain white or light gray background.
No labels, no text, no watermark, no UI overlay, no character, no hand, no extra weapons.
```

### 侧视图

```text
Use the shared Design lock.
Generate only the 90-DEGREE SIDE VIEW of the exact same weapon.
Single weapon, vertical, centered, full length visible, orthographic camera, no perspective.
Show thickness, side profile, and side-mounted details, but do not invent a different weapon.
All major parts must align with the front view: blade height, handle length, guard position, pommel position.
Plain white or light gray background.
No labels, no text, no watermark, no UI overlay, no character, no hand, no extra weapons.
```

### 背视图

```text
Use the shared Design lock.
Generate only the BACK VIEW of the exact same weapon.
Single weapon, vertical, centered, full length visible, orthographic camera, no perspective.
The back view should match the front view silhouette and proportions, with rear-side panel details only.
Do not change blade shape, handle length, guard position, pommel position, or color family.
Plain white or light gray background.
No labels, no text, no watermark, no UI overlay, no character, no hand, no extra weapons.
```

## 一致性检查清单

生成后至少检查：

1. 三张图是否是同一把武器，而不是三把相似武器。
2. 武器总高度是否一致。
3. 刀刃 / 枪头 / 锤头位置是否一致。
4. 手柄长度和粗细是否一致。
5. 护手、环、宝石、侧翼、尾锥等装饰位置是否一致。
6. 颜色是否属于同一套配色。
7. 是否有文字、标签、水印、UI、手、角色或场景干扰。
8. 是否有顶部或底部裁切。
9. `COPY_AUDIT.txt` 是否存在，并记录了三张图的来源路径、目标路径和尺寸。
10. `PROMPT.md` 是否记录了 `generation_route`、参考图路径、设计锁定和三张图 Prompt。
11. 是否保持参考图的 Roblox 视口 / 低模游戏资产 / 手绘贴图质感。
12. 改款是否只是颜色和局部形状小改，而不是换成另一种武器风格。
