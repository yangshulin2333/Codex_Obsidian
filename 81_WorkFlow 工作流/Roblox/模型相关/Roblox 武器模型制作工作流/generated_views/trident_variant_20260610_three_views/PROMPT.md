# Trident Variant Three Views Prompt

生成时间：2026-06-10

## 设计锁定

基于用户提供的 Roblox 预览截图，生成一把同系列改款长柄三叉矛武器，用于 3D AI 模型生成参考。

必须保留的家族特征：

1. 长柄三叉矛结构。
2. 中央主刃最高，两侧副刃较细。
3. 黑色 / 暗枪灰色刃面。
4. 古金色护环和弧形支撑结构。
5. 灰黑色分段长柄。
6. 头部和尾锥带少量青绿色宝石点缀。

允许变化范围：

1. 中央主刃略加宽，加入银色边缘倒角。
2. 两侧副刃略微外弯。
3. 护环从圆弧感调整为更硬朗的分段弧形。
4. 金属配色从原黑金改为暗枪灰、古金、钢灰、青绿色点缀。
5. 装饰位置可以轻微调整，但三张视图必须保持同一把武器。

低模约束：

```text
low-poly Roblox fantasy weapon, clean flat planes, game-ready low-poly mesh, details painted in texture, not sculpted geometry, simple solid silhouette, no sculpted skull details, no tiny raised ornaments, no dense relief, no noisy surface, no small 3D cracks, optimized for 3000 to 4000 triangles
```

反向约束：

```text
no high-poly sculpted relief, no dense geometry details, no tiny detached parts, no floating fragments, no noisy surface, no hair-like spikes, no small 3D cracks, no complex skull sculpture, no dense filigree, no random blocks, no character, no hand, no UI overlay, no text, no watermark
```
