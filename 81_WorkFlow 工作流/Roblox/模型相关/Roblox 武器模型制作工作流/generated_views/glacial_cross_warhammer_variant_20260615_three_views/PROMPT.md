## Design Lock

```text
Create one same-series redesigned Roblox low-poly fantasy warhammer based on the provided reference screenshots.
Keep the same weapon family identity: a horizontal double-headed rectangular hammer head, chunky side end blocks, round rivets, side-mounted conical spikes, top spikes, a long dark leather-wrapped handle, metal handle bands, and a pointed metal pommel.
Make only moderate variant changes: shift the palette from plain silver-gray to glacial gunmetal with pale cyan enamel accents, simplify the central cross into a low-poly frost diamond cross, sharpen the side spikes slightly, and make the end blocks more beveled.
The front, side, and back images must describe the exact same weapon design.
Use the same total height, handle length, hammer head size, side cap size, spike positions, handle band spacing, collar shape, and pointed pommel in all views.
Use a clean Roblox low-poly readable silhouette with hand-painted texture detail, not dense high-poly sculpture.
```

## View Rules

```text
Front view: wide hammer face visible, centered vertical handle, all spikes and pommel visible, orthographic camera.
Side view: true 90-degree side profile with narrower hammer head, same top spike, same side spikes, same handle bands, same pointed pommel.
Back view: same silhouette and proportions as front view, rear panel details only, simpler rear frost diamond cross.
Plain white or light gray background.
No labels, text, watermark, UI, character, hand, room, floor, or extra weapons.
```

## Consistency Notes

The final deliverable uses a local controlled raster drawing after the first AI-generated draft showed small cross-view drift in the pommel. The three final images share the same coordinate layout, colors, handle band positions, spike positions, and pommel geometry to make the set more stable for 3D AI model generation.

## Avoid

```text
no high-poly sculpted relief, no dense geometry details, no tiny detached parts, no floating fragments, no noisy surface, no hair-like spikes, no small 3D cracks, no complex skull sculpture, no dense filigree, no random blocks
```
