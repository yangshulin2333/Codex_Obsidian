# Buster Sword Variant Three Views Prompt

Date: 2026-06-10

## Purpose

Generate a same-series redesigned Roblox low-poly greatsword from the provided reference screenshots.

This is a concept three-view reference for 3D AI model generation. It is not a Roblox FBX / GLB import package.

## Output Files

```text
buster_sword_variant_front_view.png
buster_sword_variant_side_view.png
buster_sword_variant_back_view.png
buster_sword_variant_three_view_sheet.png
```

## Design Lock

```text
Create one same-series redesigned Roblox low-poly fantasy greatsword based on the provided reference screenshots.
Keep the same weapon family identity: oversized vertical rectangular slab blade, broad blackened gunmetal steel blade body, one angled chisel-cut lower tip, short cylindrical brown leather-wrapped handle rising above a rectangular riveted guard block, five muted bronze rivets on the guard, an upper inset panel area with two circular holes or rear covers, cold blue-gray bevel strips along the blade edge, and painted angular circuit-like grooves.
Make only moderate variant changes from the original reference: dark gunmetal body, cold blue-gray edge bevels, muted bronze rivets, slightly adjusted panel cut lines, and a faceted lower bevel.
The front, side, and back images must describe the exact same weapon design.
Use the same total height, same blade width or side thickness, same handle length, same guard position, same pommel cap, same decorative element placement, and same lower angled tip in all views.
Use a clean Roblox low-poly readable silhouette with hand-painted texture detail, not dense high-poly sculpture.
Details should look painted into the texture or simple flat bevel planes, optimized for about 3000 to 4000 triangles.
```

## Front View Prompt

```text
Use the shared Design lock.
Generate only the FRONT VIEW of the weapon.
Single weapon, vertical, centered, full length visible from handle top to blade tip, orthographic camera, no perspective.
Show the main silhouette clearly, flat-on and symmetric where appropriate.
Plain light gray or white background.
No labels, no text, no watermark, no UI overlay, no character, no hand, no extra weapons.
```

```text
Keep all major vertical landmarks aligned with the front view: handle top, guard, upper panel area, blade length, tip position.
Plain light gray or white background.
No labels, no text, no watermark, no UI overlay, no character, no hand, no extra weapons.
```

## Back View Prompt

```text
Use the shared Design lock.
Generate only the BACK VIEW of the exact same weapon.
Single weapon, vertical, centered, full length visible from handle top to blade tip, orthographic camera, no perspective.
Match the front view silhouette and proportions exactly: broad rectangular slab blade, same right-side cold blue-gray bevel strip, same angled chisel-cut lower tip, same top guard width and rivet row, same handle height.
Show rear-side panel details only: a flatter rear armor plate, rear covers for the two circular holes, angular painted grooves mirrored or rearranged on the upper half, and subtle metal wear.
Plain light gray or white background.
No labels, no text, no watermark, no UI overlay, no character, no hand, no extra weapons.
```

## Avoid

```text
no high-poly sculpted relief, no dense geometry details, no tiny detached parts, no floating fragments, no noisy surface, no hair-like spikes, no small 3D cracks, no complex ornaments, no random blocks, no background scene
```
