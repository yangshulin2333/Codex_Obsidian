## Design Lock

```text
Create one same-series redesigned Roblox low-poly fantasy warhammer based on the provided reference screenshots.
Keep the same weapon family identity: a horizontal double-headed rectangular hammer head, central rectangular face plate, chunky end blocks on both sides, rows of round rivets, white cross/X markings on the side blocks, short conical spikes on the top corners, a vertical dark leather-wrapped handle with evenly spaced metal bands, and a round metal pommel.
Make only moderate variant changes: shift the palette from plain silver-gray to cold frosted steel with blue-gray shadows, darker gunmetal bevels, small pale cyan enamel accents inside the central cross emblem, slightly chamfer the end blocks, and replace the ornate central cross with a simpler low-poly cathedral cross/snowflake emblem painted on the face plate.
The front, side, and back images must describe the exact same weapon design.
Use the same total height, same handle length, same hammer head width, same head thickness, same end block size, same top spike positions, same rivet rows, same cross/X markings, same handle band spacing, and same pommel shape in all views.
Use a clean Roblox low-poly readable silhouette with hand-painted texture detail, not dense high-poly sculpture.
Details should look painted into the texture or simple flat bevel planes, optimized for about 3000 to 4000 triangles.
```
