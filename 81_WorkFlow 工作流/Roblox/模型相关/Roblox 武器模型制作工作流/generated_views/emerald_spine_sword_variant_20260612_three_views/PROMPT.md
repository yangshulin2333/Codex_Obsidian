## Design Lock

```text
Create one same-series redesigned Roblox low-poly fantasy greatsword based on the provided reference screenshots.
Keep the same weapon family identity: vertical dark steel greatsword with the handle at the top, long straight central blade pointing downward, jagged bone-like silver armor plates, black gunmetal inner blade, neon emerald-green glowing cracks running down the center, a bat-wing / thorn-shaped crossguard around the upper blade, several large readable side spikes, a short wrapped cylindrical grip above the guard, and a small diamond pommel cap at the very top.
Make only moderate variant changes: shift the glow from bright lime to emerald-cyan, make the silver armor plates slightly more icy blue-gray, simplify the thorn shapes into larger low-poly readable hooks, add a few painted green energy windows on the blade, and make the lower blade tip a cleaner faceted spear point.
The front, side, and back images must describe the exact same weapon design.
Use the same total height, same grip length, same guard position, same blade length, same blade width or side thickness, same thorn/spike placement, same top pommel shape, same lower blade tip, and same green crack layout in all views.
Use a clean Roblox low-poly readable silhouette with hand-painted texture detail, not dense high-poly sculpture.
Details should look painted into the texture or simple flat bevel planes, optimized for about 3000 to 4000 triangles.
```
