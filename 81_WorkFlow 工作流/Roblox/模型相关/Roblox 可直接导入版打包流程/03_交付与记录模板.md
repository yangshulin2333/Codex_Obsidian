## 最终回复模板

````markdown
已转好，输出名是 `输出名`。

- [打开干净导入目录](<%USERPROFILE%\Documents\RobloxImportPackages\最终导入名_IMPORT_ONLY>)
- [直接导入这个文件](<%USERPROFILE%\Documents\RobloxImportPackages\最终导入名_IMPORT_ONLY\最终导入名.glb>)
- 导入后 Roblox 默认模型名：`最终导入名`
- [内部输出目录，排查用](<%USERPROFILE%\Documents\RobloxImportPackages\输出名_roblox_direct>)
- [兼容测试 embedded FBX](<%USERPROFILE%\Documents\RobloxImportPackages\输出名_roblox_direct\输出名_faces实际面数_embedded_1024tex.fbx>)
- [保底 mesh-only FBX](<%USERPROFILE%\Documents\RobloxImportPackages\输出名_roblox_direct\输出名_faces实际面数_mesh_only.fbx>)
- [压缩贴图](<%USERPROFILE%\Documents\RobloxImportPackages\输出名_roblox_direct\输出名_faces实际面数_texture_1024.jpg>)

验证结果：

```text
ROBLOX_WEAPON_EXPORT_OK
faces=实际面数
texture=1024x1024
filename includes faces实际面数
manifest records faces and texture size when original-name delivery is requested
direct_fbx generated
direct_fbx_texture_mode=external_relative

direct_glb generated
embedded_fbx generated
mesh_only_fbx generated
clean_import_name=最终导入名
clean_import_file=最终导入名.glb
```

Roblox 里优先从干净导入目录选择 `最终导入名.glb`。默认情况下，实际导入文件名只保留编号、面数和贴图尺寸，例如 `05_faces1485_1024tex.glb`；如果用户要求保持原名，则用源模型原名，例如 `Cabbage_Flower.glb`。不要把 `IMPORT_THIS`、长英文描述、`PBR` 等提示词放进文件名。如果需要排查，再打开内部输出目录使用 FBX、embedded FBX、mesh-only FBX 或贴图文件。

GLB 交付时还要确认内部名称已经同步为最终导入名：`scenes[].name`、根 `nodes[].name`、`meshes[].name`、`materials[].name` 都要包含面数短名，不能保留 `Scene` 或内部长名。
````

```markdown
## YYYY-MM-DD HH:mm 输出名 - Roblox 可直接导入版

### 输入

### 执行
- 固定脚本：`scripts\Prepare-RobloxWeaponImport.ps1`
- 输出根目录：`outputs`
- 输出名：`输出名`
- 纹理规格：`-TextureSize 1024`

  - 真 FBX 文件。
  - 输入路径名以 `.fbx` 结尾但实际为目录；内部为 `tripo_convert_*.fbx + tripo_convert_*.fbm`。
  - 表面是 `.fbx`，实际为 ZIP 包。

### 结果
- [最终导入名_IMPORT_ONLY](<%USERPROFILE%\Documents\RobloxImportPackages\最终导入名_IMPORT_ONLY>)：clean_import_file=最终导入名.glb, imported_model_default_name=最终导入名, glb_internal_names_include_faces=True

### 导入顺序
1. 先导入干净目录第一层的 `最终导入名.glb`，导入后 Roblox 默认模型名应为 `最终导入名`。
2. 如果 GLB 贴图异常，再试 `输出名_faces实际面数_direct_1024tex.fbx`，并保持 `输出名_faces实际面数_texture_1024.*` 和 FBX 在同一目录。
3. 如果需要排查 FBX 兼容性，再试 `输出名_faces实际面数_embedded_1024tex.fbx`。
4. 如果仍失败，使用 `输出名_faces实际面数_mesh_only.fbx + 输出名_faces实际面数_texture_1024.*` 保底。
```

## 检查清单

完成前逐项确认：

- [ ] 使用固定脚本，不是临时 Python。
- [ ] 命令显式传入 `-TextureSize 1024`，或确认脚本默认值仍为 1024。
- [ ] 命令显式传入 `-ImportNamePrefix`，确保最终导入名包含编号、面数和贴图尺寸。
- [ ] 默认输出目录是 `%USERPROFILE%\Documents\RobloxImportPackages\输出名_roblox_direct`，除非显式传入 `-OutputRoot`。
- [ ] 有 `*_faces实际面数_direct_1024tex.fbx`。
- [ ] 有 `*_faces实际面数_direct_1024tex.glb`。
- [ ] 有 `*_faces实际面数_embedded_1024tex.fbx`，或明确记录 `embedded_fbx=none`。
- [ ] 有 `*_faces实际面数_mesh_only.fbx`。
- [ ] 有 `*_faces实际面数_texture_1024.*`，或明确记录 `texture=none`。
- [ ] 有 `README_import_order.txt`。
- [ ] 有 `_IMPORT_ONLY` 干净导入目录。
- [ ] 干净目录第一层只有一个推荐导入模型文件、一个 README 和必要的 fallback 子目录。
- [ ] 推荐导入模型文件名符合 `<序号>_faces<实际面数>_1024tex.<fbx/glb>`。
- [ ] 推荐导入模型文件名不包含 `IMPORT_THIS`、长英文描述、`PBR`、`direct`、`embedded` 等提示或调试词。
- [ ] GLB 内部 `scene/root node/mesh/material` 名称已同步包含最终导入名和面数，不再显示 `Scene` 或内部长名。
- [ ] 验证贴图是 `1024x1024`。
- [ ] 确认 `*_direct_1024tex.fbx` 使用外部相对贴图模式，不默认内嵌贴图。
- [ ] 确认 `*_direct_1024tex.fbx` 与 GLB 回导尺寸一致，`fbx_glb_scale_match=True`。
- [ ] 最终回复给可点击链接。
- [ ] 已更新 `logs\工作记录.md`。
