## G0：范围确认

- [ ] 确认是“普通小程序”，不是“小游戏”。
- [ ] 一句话功能描述已确定。
- [ ] 首版页面和核心流程已确定。
- [ ] 已写明“不做”列表。
- [ ] 已检查个人主体当前可选类目。

## G1：账号与主体

- [ ] 注册账号类型为“小程序”。
- [ ] 注册邮箱可用并已激活。
- [ ] 主体信息提交成功。
- [ ] 管理员身份核验成功。
- [ ] 未在文档中保存密码、验证码或身份凭据。

## G2：基础信息与类目

- [ ] 名称可用。
- [ ] 简称无红色报错，或选填时已留空。
- [ ] 头像正常预览且版权清晰。
- [ ] 简介只描述已实现功能。
- [ ] 服务类目与真实功能一致。
- [ ] 主服务类目状态为“已通过”。

## G3：正式 AppID

- [ ] 使用 `wx...` 正式 AppID。
- [ ] 没有误用 `gh_...` 原始 ID。
- [ ] `project.config.json` 中 AppID 正确。
- [ ] `project.private.config.json` 没有覆盖成测试/旧 AppID。
- [ ] 开发者工具显示正确小程序名称。
- [ ] 上传按钮已启用。
- [ ] 未生成或保存不需要的 AppSecret。

## G4：本地开发、隐私和真机

- [ ] 全局配置和页面路径有效。
- [ ] 图片、图标和资源路径有效。
- [ ] 项目不依赖本机绝对路径或临时本地服务。
- [ ] 编译无阻塞错误。
- [ ] 已扫描登录、手机号、定位、相册、摄像头、上传、支付、广告和第三方 SDK。
- [ ] 隐私声明与代码实际行为一致。
- [ ] 至少一台真机完成端到端流程。
- [ ] 真机没有严重布局或交互问题。

## G5：上传开发版本

- [ ] 开发者工具登录的是正确账号。
- [ ] 登录微信拥有该 AppID 的管理员/开发者权限。
- [ ] 新版本号唯一且符合约定。
- [ ] 项目备注准确、简短。
- [ ] 开发者工具显示“代码上传成功”。
- [ ] 后台开发版本显示相同版本号、时间和开发者。

## G6：代码审核

- [ ] 版本描述与实际功能一致。
- [ ] 无登录功能时选择“无需登录账号即可使用”。
- [ ] 未填写个人微信账号或真实密码。
- [ ] 无交易功能时订单中心 path 留空。
- [ ] 隐私选择与代码扫描一致。
- [ ] 非必要未使用审核加急。
- [ ] 当前状态为“审核通过待发布”。
- [ ] 如被驳回，已按具体原因修改并上传新版本。

## G7：小程序备案

- [ ] 主体和管理员信息真实一致。
- [ ] 小程序名称、类目、功能和备案备注一致。
- [ ] 材料按后台要求上传。
- [ ] 管理员本人完成核身并提交。
- [ ] 审核中未无故撤回或重复提交。
- [ ] 已留意电话和 `12381` 短信。
- [ ] 收到短信后已在 24 小时内完成核验。
- [ ] 最终备案状态为“完成”或“通过”。

## 备案等待期间的体验测试

- [ ] 测试朋友只添加为“体验成员”。
- [ ] 没有给普通测试者开发者权限。
- [ ] 已设置体验版并生成体验二维码。
- [ ] 体验成员能够正常进入。
- [ ] 测试结束后已检查是否需要移除成员。

## G8：正式发布

- [ ] 代码审核已通过。
- [ ] 小程序备案已通过。
- [ ] 基础信息和主服务类目仍有效。
- [ ] 管理员已确认线上内容。
- [ ] 已执行全量发布。
- [ ] 后台出现正确线上版本和发布时间。

## G9：公开访问验收

- [ ] 搜索可见性相关设置已开启。
- [ ] 使用非管理员、非体验成员账号测试。
- [ ] 完整名称搜索能够找到，或已记录仍在收录期。
- [ ] 小程序码可以正常打开。
- [ ] 微信分享卡片可以正常打开。
- [ ] 至少两种公开入口通过。
- [ ] 公开账号完成核心流程。
- [ ] 实测版本与后台线上版本一致。

## 快速故障定位

| 现象 | 先检查 |
|---|---|
| 表单提示不完整 | 页面所有红字，尤其简称、头像、简介和类目 |
| 测试号 AppID | 两个项目配置文件、项目导入路径、开发者工具缓存 |
| 上传按钮不可用 | 正式 AppID、登录账号、成员权限 |
| 后台没有开发版本 | AppID 是否一致、后台刷新、上传时间 |
| 审核要求账号密码 | 是否误选“需要登录” |
| 隐私审核失败 | 实际 API/SDK 与后台声明是否一致 |
| 备案审核中 | 电话是否畅通、是否遗漏 `12381` 核验；不要重复提交 |
| 朋友搜不到 | 备案、代码审核、正式发布、搜索设置、收录延迟 |
| 朋友打不开体验版 | 是否为体验成员、微信号是否正确、二维码是否失效 |
