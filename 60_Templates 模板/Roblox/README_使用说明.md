```text
├─ 07_Roblox_AI喂资料模板.md
└─ 08_项目复盘模板.md
```

## 当前阶段建议优先使用

1. `01_Roblox_项目接手模板.md`
2. `02_Roblox_功能拆解模板.md`
3. `03_Roblox_资产审计模板.md`
4. `04_Roblox_问题排查模板.md`

这 4 个模板对应你当前最重要的任务：

- 看懂旧项目
- 拆解一个核心功能
- 整理 UI / 动画 / 特效 / 音效
- 记录问题并准备有效提问

## 使用原则

不要把模板填满当成目标。真正目标是让你能：

1. 快速知道项目入口在哪里
2. 说清楚核心流程
3. 找到代码和资产之间的关系
4. 有问题时能清楚描述
5. 最后能复刻一个最小可运行 Demo
