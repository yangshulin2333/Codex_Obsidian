# AI x 3D 第4课｜游戏道具拓扑重构与优化

## 一句话说明

把 AI 生成或雕刻得到的高面数游戏道具，整理成轮廓正确、网格干净、能够展开 UV、烘焙贴图并导入游戏引擎的低模。

本文只保留武器、工具、宝箱、家具、拾取物等**刚性游戏道具**需要的内容；角色肩、肘、膝、面部和权重变形拓扑不在本文范围内。

## 本课在游戏道具流程中的位置

```text
AI 高模 / 雕刻高模
  → 第4课：重拓扑、贴合和清理
  → 第5课：UV 展开
  → 第6课：高模细节烘焙到低模
  → 第7课：生成和清理 PBR 纹理
  → 游戏引擎导入与实机验收
```

如果只想做可运行的游戏道具，第 4 课的完成标准不是“模型看起来还行”，而是低模已经能稳定进入 UV 和烘焙阶段。

## 输入与输出合同

### 输入

- 一个高面数道具，来源可以是 Hunyuan 3D、Tripo、其他图生 3D 工具或手工雕刻。
- 能明确区分的主要部件，例如剑刃、护手、握柄、宝石和挂饰。
- 高模原文件，必须保留，不能直接覆盖。

### 输出

- `prop_high`：只读高模，保留细节，供后续烘焙。
- `prop_low`：清理后的低模，供 UV、烘焙和游戏引擎使用。
- 一个同时保留高模与低模、集合和命名清楚的 `.blend` 工作文件。
- 必要时另导出 `prop_low.fbx` 或 `prop_low.glb`。

## 道具重拓扑的五条核心原则

### 1. 先保护轮廓，再减少面数

玩家首先看见的是剪影和大结构。剑尖、刃口、护手、握柄、宝石外轮廓、斧刃和锤头等识别点，不能因为减面而明显变形。

不要给所有道具套一个固定面数。合理面数取决于：

- 目标平台；
- 游戏相机距离；
- 同屏实例数量；
- 道具是不是近景核心资产；
- 项目的性能预算。

课程也明确提醒：不要为了追求极小数字，把现代游戏道具硬压成早期游戏的 500 三角面资产。

### 2. 四边面便于编辑，最终三角面并不可怕

- 需要继续调整的曲面、圆柱和连续边流：优先四边面。
- 平整硬表面：合理三角面可以接受。
- N 边面只应有意识地放在完全平整、不会变形且阴影稳定的位置。
- 导入游戏引擎后，网格最终仍会被三角化。

真正要避免的是随机、细长、交叉或扭曲的面，因为它们会破坏阴影、UV 和烘焙。

### 3. 低模必须贴合高模，烘焙包络必须覆盖细节

课程把这条描述为“低模覆盖高模”。更准确的理解是：

- 低模要尽量贴近高模外形；
- 不能明显埋进高模内部；
- 第 6 课使用的 Cage 或 Ray Distance 必须能包住需要投影的高模细节。

低模与高模错位，会造成漏烘焙、黑斑、投影穿透和法线脏点。

### 4. 删除无意义的内部面和碎片

完全藏在剑刃与护手交界、宝石底座内部或握柄连接处的面，不会被玩家看到，却会：

- 浪费 UV 面积；
- 增加三角面；
- 干扰烘焙射线；
- 形成多余 UV 岛。

有意保留的重叠部件可以存在，但完全无用的内部面应删除。

### 5. 高模与低模必须始终分开保存

高模负责几何细节来源，低模负责运行时性能。不要为了方便直接覆盖高模，也不要让两个版本使用含糊的名称。

推荐：

```text
HIGH_SOURCE/
  prop_HIGH

LOW_WORKING/
  prop_LOW
```

## 最短可执行流程

### 步骤 1：备份并整理高模

1. 另存 Blender 工作文件。
2. 将高模放入独立 Collection，例如 `HIGH_SOURCE`。
3. 检查道具由哪些独立部件构成。
4. 删除确认无用的重复对象，但不破坏原始备份。
5. 如果上传 AI 重拓扑平台时文件过大，再对副本添加 `Decimate`：
   - 模式：`Collapse`；
   - 课程起始建议：比例 `0.5`；
   - 应用前必须比较轮廓、尖角和薄片是否损坏。
6. 只导出要重拓扑的选中部件，材质可以不导出。

> 课程记录的 Hunyuan 200 MB、Tripo 100 MB 上传限制属于录课时信息，平台限制可能变化，使用前应重新确认。

### 步骤 2：用 AI 生成低模初稿

课程推荐的顺序：

1. Hunyuan 3D 重拓扑作为免费首选。
2. 输出设置优先选择四边形。
3. 可以生成多次，从中保留轮廓和网格最稳定的一版。
4. 若 Hunyuan 结果不可用，再考虑 Tripo Smart Low Poly、QuadRemesh、RetopoFlow 或 Blender 手工修复。

对规则、对称、硬表面的剑、斧、锤、盾和法杖，AI 往往能完成大部分工作；复杂镂空、链条、薄刃、交叠花纹和大量尖刺仍需人工检查。

### 步骤 3：导入并对齐高低模

1. 将低模放入 `LOW_WORKING` Collection。
2. 高模和低模保持在相同世界坐标、朝向和尺寸。
3. 使用 X-Ray 或 Wireframe 同时观察两者。
4. 开启磁吸并设置 `Snap To: Face`。
5. 在编辑模式移动低模顶点，使其贴合高模。
6. 重点检查：
   - 刀尖、刃口和薄片；
   - 深凹槽和镂空；
   - 部件交界；
   - 护手与握柄连接；
   - 宝石、尖刺和浮雕。

不要只从正面判断，至少旋转检查正、背、侧、顶和底。

### 步骤 4：修复 AI 网格

| 目的 | Blender 操作 |
|---|---|
| 编辑模式 | `Tab` |
| 顶点 / 边 / 面选择 | `1` / `2` / `3` |
| 挤出 | `E` |
| 填面 | `F` |
| 切割 | `K` |
| 连接顶点 | `J` |
| 合并 | `M` |
| 删除 / 溶解 | `X` |
| 循环切割 | `Ctrl + R` |
| 选择相连几何 | `Ctrl + L` |
| 隐藏 / 恢复 | `H` / `Alt + H` |
| 向外重算法线 | `Shift + N` |

优先排查：

1. **重复顶点**：使用 `M > By Distance`，但合并距离必须保持很小；复杂道具不要盲目用大距离全局焊接。
2. **孤立碎片**：从主体选择相连网格，再反选并检查无用碎片。
3. **破洞和断面**：优先重建合理的四边面或三角面，避免一个扭曲 N 边面封住复杂洞口。
4. **极细长三角面**：它们容易造成阴影和 UV 拉伸，应重新布线。
5. **意外内部面**：确认不可见且无结构作用后删除。

### 步骤 5：检查面朝向和法线

Blender 的 Face Orientation 标准显示为：

- **蓝色：正面朝外，通常正确。**
- **红色：背面朝外，通常是翻面或开口问题。**

如果外表面出现红色：

1. 进入编辑模式；
2. 选择问题面或全选；
3. `Shift + N` 执行 Recalculate Outside；
4. 再检查有意开口和非流形位置。

> 重要修正：课程压缩包内的 `lesson-04-hints.md` 把红蓝含义写反了。Blender 官方手册明确说明外侧通常应显示为蓝色，红色代表背面。参见 [Blender Viewport Overlays](https://docs.blender.org/manual/en/latest/editors/3dview/display/overlays.html)。

### 步骤 6：处理对称道具

适用于左右对称的护手、双刃、斧头、盾牌和装饰件：

1. 把要处理的部分分离：`P > Selection`。
2. 删除一半网格。
3. 添加 Mirror 修改器，只修改一侧。
4. 开启中心线合并并检查中心裂缝。
5. 定稿后应用 Mirror。
6. 需要时用 `Ctrl + J` 合并对象。
7. 最后用小距离 `M > By Distance` 焊接中心线。

课程强调：先应用镜像，再做最终合并与中心焊接。

### 步骤 7：完成前清理

进入 [[UV]] 前确认：

- 删除无用内部面；
- 删除孤立碎片；
- 没有异常重复顶点；
- 外侧 Face Orientation 为蓝色；
- 关键轮廓没有被减面破坏；
- 平滑面与硬边阴影正常；
- 高模与低模位置重合；
- 对象名称和 Collection 清楚；
- 低模的旋转、缩放和导出单位已经检查；
- 保存一个可回滚版本。

## 静态游戏道具可以跳过什么

课程的角色示例包含以下内容，普通刚性道具通常不需要：

- 肩、肘、膝、手指和面部变形环线；
- 肌肉或布料方向的角色边流；
- 为权重绘制准备的关节拓扑；
- 狐狸身体、斗篷、手脚和脸部的拆分方法；
- 角色绑定前的变形测试。

普通游戏道具仍要保留：

- 圆柱握柄和曲面区域的均匀边段；
- 支撑轮廓的必要边；
- 受控倒角和稳定硬边；
- 能正常 UV、烘焙和着色的拓扑。

如果道具本身会弯曲、展开或具有可动画机械结构，再单独增加对应变形拓扑，不要把角色规则无条件套到所有道具。

## 常见失败与修复

### AI 平台拒绝上传

可能原因：文件过大或包含无关对象。

处理：

- 对高模副本使用温和 Decimate；
- 只导出选中物体；
- 不携带无用材质、灯光和相机；
- 再次检查当前平台限制。

### 低模轮廓变形

可能原因：减面过强或 AI 重拓扑忽略薄片、尖端和镂空。

处理：

- 换一个 AI 生成版本；
- 降低减面强度；
- 在关键轮廓补边并手工贴合；
- 不要用纹理掩盖真正的轮廓缺失。

### 烘焙出现黑斑、漏投影或穿透

可能原因：

- 高低模错位；
- 低模埋进高模；
- Cage / Ray Distance 不够或过大；
- 隐藏内部面干扰射线。

处理：回到 X-Ray 检查贴合，再在第 6 课调整 Cage，而不是直接在贴图上涂掉所有错误。

### 填面后阴影破碎

可能原因：使用 `F` 创建了扭曲的非平面 N 边面。

处理：用 Knife 或连接顶点把区域重建为稳定的四边面或少量合理三角面，并重算法线。

### 合并距离后细节消失

可能原因：`Merge by Distance` 距离过大，误把邻近但不应连接的顶点焊在一起。

处理：立即撤销，缩小距离，只处理明确的中心线或重复顶点区域。

## 最终记忆句

> 游戏道具重拓扑不是“把面数压得越低越好”，而是用足够少且稳定的几何保住轮廓，并让 UV、烘焙、材质和游戏运行都可靠。
