# Blender 检查洞 / 破面知识点

### 1. 检查有没有洞：非流形

作用：

```text
找洞口边、缺面、孤立点、孤立边、坏面
```

操作：

```text
Tab 进入编辑模式
2 切到边选择
Alt + A 取消全选
选择 → 按特征全选 → 非流形
```

英文：

```text
Select → Select All by Trait → Non-Manifold
```

---

### 2. 判断结果

|选中内容|说明|
|---|---|
|一圈边被选中|有洞 / 缺面|
|单独一条边|孤立边|
|单独点|孤立点|
|一堆杂乱边|可能有重叠面、破面、内部坏结构|

---

### 3. 修洞

规则洞：

```text
选中洞口边 → F
```

不规则洞：

```text
选 3 个点 → F
选 3 个点 → F
逐个补三角面
```

低模武器可以直接用三角面补，没问题。

---

### 4. 清理孤立点 / 孤立边

删除无用点线：

```text
X → 顶点
X → 边
```

只是想去掉多余线但保留面：

```text
X → 溶解顶点
X → 溶解边
```

原则：

```text
能溶解就先溶解，少直接删除。
```

---

### 5. 合并没焊接的点

全选：

```text
A
```

按距离合并：

```text
M → 按距离合并 / By Distance
```

距离建议：

```text
0.001 起步
不够再试 0.005
```

不要一开始太大，容易把细节粘坏。

---

### 6. 修完后重算法线

```text
A 全选
Shift + N
```

作用：

```text
重新计算外侧法线，避免补面后黑面、阴影异常。
```

---

### 7. 推荐检查流程

```text
1. Tab 进入编辑模式
2. A 全选
3. M → By Distance，距离 0.001
4. Alt + A 取消选择
5. 选择 → 按特征全选 → 非流形
6. 有洞就 F 或三角补面
7. 有孤立点线就删除或溶解
8. A 全选
9. Shift + N 重算法线
```

核心记忆：

```text
非流形 = 找洞和坏网格
F = 补面
M By Distance = 焊点
X Dissolve = 清理多余线
Shift + N = 修法线
```

# 一、移动点的位置

## 1. 进入顶点选择

```text
Tab 进入编辑模式
1 切到顶点选择
```

然后点你要移动的黑色小点。

如果不好选：

```text
Alt + Z
```

开启透明/X-Ray，方便选到背后的点。

---

## 2. 移动点

选中点后按：

```text
G
```

然后鼠标移动。

确认：

```text
左键
```

取消：

```text
右键 / Esc
```

---

## 3. 限制方向移动

如果你只想沿某个轴移动：

```text
G + X    沿 X 轴移动
G + Y    沿 Y 轴移动
G + Z    沿 Z 轴移动
```

比如红框那个尖点，如果只是想上下调整，大概率用：

```text
G + Z
```

如果视角不是标准正视图，也可以直接：

```text
G
```

然后慢慢拖。

---

## 4. 沿着原来的边滑动点

这个很重要。

如果你不想乱拉，只想让点沿着连接的边滑动：

```text
选中点
G G
```

也就是连续按两次 `G`。

这个叫：

```text
顶点滑移 / Vertex Slide
```

适合调整低模武器上的点，不容易破坏整体形状。

---

# 二、在边上增加点

## 方法 1：细分边，最适合你现在

```text
Tab 编辑模式
2 切到边选择
选中一条边
右键 → 细分 / Subdivide
```

左下角调：

```text
Number of Cuts / 切割次数
```

常用：

```text
1
```

意思是在这条边中间加 1 个点。

---

## 方法 2：刀具切点 / 切线

如果你想自己决定点的位置，用刀具：

```text
K
```

操作：

```text
K
点一下边
点到另一条边或另一个点
Enter 确认
```

取消：

```text
Esc
```

这个适合你在洞口附近自己切一条新线。

---

# 三、点和线的常用操作表

## 点操作

|操作|快捷键|作用|
|---|---|---|
|顶点选择|`1`|选择点|
|移动点|`G`|自由移动|
|沿轴移动|`G + X/Y/Z`|限制方向移动|
|沿边滑动|`G G`|点沿着已有边滑动|
|合并点|`M`|把多个点合成一个|
|按距离合并|`A` 后 `M → By Distance`|清理重叠点|
|删除点|`X → 顶点`|删除点，会破面|
|溶解点|`X → 溶解顶点`|删除多余点，尽量保留面|

---

## 线操作

|操作|快捷键|作用|
|---|---|---|
|边选择|`2`|选择线|
|移动边|`G`|移动整条边|
|边滑移|`G G`|沿相邻面滑动边|
|细分边|右键 → `Subdivide`|在边上加点|
|创建边|选 2 个点 → `F`|两点之间生成一条边|
|连接点切线|选 2 个点 → `J`|在面上切出一条线|
|删除边|`X → 边`|删除边，可能破面|
|溶解边|`X → 溶解边`|去掉多余线，但尽量保留面|

---

# 四、F 和 J 的区别

这个容易混。

## F：创建边 / 补面

```text
选 2 个点 → F = 生成一条边
选 3 个点 → F = 生成一个三角面
选 4 个点 → F = 生成一个四边面
```

你补洞时最常用：

```text
选 3 个点 → F
```

---

## J：在已有面上切线

```text
选 2 个点 → J
```

它是在已有面内部切一条线。

区别：

```text
F = 补东西
J = 切东西
```

---

# 五、删除点线时要注意

## 删除 Delete

```text
X → 顶点 / 边 / 面
```

会真的删掉东西，容易产生洞。

---

## 溶解 Dissolve

```text
X → 溶解顶点
X → 溶解边
```

不会直接破坏大面，适合清理多余点线。

所以：

```text
修洞、补面时少用删除
整理多余线时优先用溶解
```

# 六、把点吸到另一个点 / 边上

如果你想让一个点精准贴到另一个点：

## 方法 1：合并点

选两个点：

```text
M → At Center / 到中心
M → At First / 到第一个点
M → At Last / 到最后一个点
```

常用：

```text
M → At Center
```

如果两个点本来就应该是同一个点，用这个。

---

## 方法 2：吸附移动

顶部打开磁铁图标，然后设置吸附类型：

```text
Vertex / 顶点
Edge / 边
Face / 面
```

然后：

```text
选点 → G → 按住 Ctrl 移动
```

它会吸附到附近的点、边或面。

---

# 七、把多个点对齐

比如你想让几个点在同一高度：

1. 选中这些点
    
2. 按：
    

```text
S + Z + 0
```

意思是：

```text
沿 Z 轴缩放为 0
```

这些点就会变成同一高度。

同理：

```text
S + X + 0
S + Y + 0
```

可以让点在 X 或 Y 方向对齐。

---

# 八、你当前模型建议用的流程

你现在这种低模武器，建议这样修：

```text
1. Tab 进入编辑模式
2. 按 1 顶点选择
3. 选错位的点
4. G 或 G G 调整位置
5. 如果边太长，按 2 选边 → 右键 Subdivide 加点
6. 选 3 个点 → F 补三角面
7. 补完后 A 全选
8. M → By Distance
9. Shift + N 重算法线
```

---

# 九、最重要的几个快捷键

你先记这些就够用：

```text
1        顶点选择
2        边选择
3        面选择

G        移动
G G      沿边滑动
F        连边 / 补面
J        切线
K        刀具切割
M        合并点
X        删除 / 溶解
A        全选
Alt + Z  透明选择
Shift + N 重算法线
```

你图里红框那个点，如果只是位置不合适，优先用：

```text
1 顶点选择
选中那个点
G G
```

让它沿着原来的边滑动；如果滑不到你要的位置，再用：

```text
G
```

自由移动。
