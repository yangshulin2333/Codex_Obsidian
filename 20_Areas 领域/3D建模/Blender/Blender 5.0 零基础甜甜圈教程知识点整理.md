## 一、界面导航与基础操作（视图控制）

在 Blender 中，熟练使用鼠标和快捷键组合是高效建模的基础。建模前先学会控制视角，否则后面很容易迷路。

- **缩放视图**：滚动鼠标中轮。
- **旋转视图**：按住鼠标中轮并拖动。
- **平移视图**：按住 `Shift` + 鼠标中轮拖动。
- **平滑缩放**：按住 `Ctrl` + 鼠标中轮上下拖动。
- **聚焦选中物体**：选中物体后按小键盘 `.`，视图会自动聚焦到该物体。

### 正交视角切换（数字小键盘）

- `1`：前视图（Front）
- `3`：右视图（Right）
- `7`：顶视图（Top）
- `9`：底视图（Bottom）

### 无小键盘替代方案

- 按住 `Alt` + 鼠标中轮拖动，可自动吸附至最近的视角。
- 也可以按 `~` 呼出视图菜单，选择对应视角或 `View Selected`。

### 界面小设置

如果你使用 4K 显示器，图标太小，可以进入：

`Edit` → `Preferences` → `Interface` → 调整 `Resolution Scale`

这样界面会更适合长时间学习。

## 二、核心模式与选择技巧

Blender 有很多模式，新手前期重点掌握两个：

1. **物体模式（Object Mode）**  
   用来处理整个物体，比如移动、旋转、缩放、复制、删除。

2. **编辑模式（Edit Mode）**  
   用来修改物体内部结构，比如点、边、面。

   - **顶点（Vertices）**：点的操作。
   - **边（Edges）**：线的操作。
   - **面（Faces）**：面的操作。

### 常用切换与选择

- `Tab`：在 Object Mode 和 Edit Mode 之间切换。
- `1`：顶点选择。
- `2`：边选择。
- `3`：面选择。
- `A`：全选。
- `Alt + 左键`：选择一整圈循环边。
- `Alt + Z`：开启 X-Ray 透视模式，方便选中背面的点、边、面。

## 三、建模基础快捷键（核心动作）

掌握这些快捷键，就能完成大部分基础建模任务。

- **G（Grab / Move）**：移动物体或元素。
- **S（Scale）**：缩放大小。
- **R（Rotate）**：旋转。
- **E（Extrude）**：挤出，从已有面、边或点拉出新的几何结构。
- **Ctrl + R（Loop Cut）**：环切，为模型增加循环边。
- **Ctrl + B（Bevel）**：倒角，让边缘变圆滑。
- **I（Inset）**：内插面，在面内部创建一圈新的结构。
- **Shift + D（Duplicate）**：复制物体或几何元素。
- **F**：填充面，常用于封口。
- **Shift + N**：重新计算法线，修复黑面或奇怪阴影。
- **Ctrl + Z**：撤销。

### 轴向锁定

在移动、缩放、旋转时，紧接着按 `X`、`Y` 或 `Z`，可以精准控制方向。

例如：

- `G + Z`：只沿 Z 轴上下移动。
- `S + X`：只沿 X 轴缩放。
- `R + Y`：只绕 Y 轴旋转。

## 四、添加与编辑物体

- **添加物体**：按 `Shift + A` 呼出菜单。
- 常用路径：`Mesh` → 选择基础几何体。

### 常用基础物体

- **Cube**：立方体，适合做建筑、箱子、方形道具。
- **Cylinder**：圆柱体，适合做杯子、树干、柱子。
- **Cone**：圆锥体，适合做树冠、尖塔。
- **Torus**：圆环，适合做甜甜圈。
- **Circle**：圆形，适合做盘子、圆形面片。
- **Plane**：平面，适合做地面、桌面、参考图。

### 低多边形设置（Low Poly）

添加圆柱体、圆锥体等物体时，可以在左下角设置 `Vertices` 数量。

例如：

- 杯子圆柱体可以设为 `14`
- 糖珠圆柱体可以设为 `6`
- 低模树干可以设为 `8`

低模的好处是结构清楚、电脑不卡，也更适合游戏资产。

### 平滑着色

右键点击物体，选择：

- `Shade Smooth`
- `Shade Smooth by Angle`
- `Shade Smooth Auto Smooth`

它不会增加真实面数，但能让模型表面看起来更圆润。

## 五、甜甜圈本体制作

### 1. 添加圆环

`Shift + A` → `Mesh` → `Torus`

圆环是甜甜圈最合适的基础形状。

建议参数：

- `Major Radius`：控制整体大小。
- `Minor Radius`：控制甜甜圈粗细。
- 主分段可以设高一些，例如 `48`。
- 次分段可以设为 `18` 左右。

### 2. 调整尺寸

默认圆环通常太大，可以把它缩小到接近真实甜甜圈大小。

拖动数值时按住 `Shift`，可以进行更细微的调整。

### 3. 平滑处理

右键选择 `Shade Smooth`，让甜甜圈从低清多边形变成圆滑表面。

## 六、马克杯建模知识点

马克杯部分主要用来练习建模基础、修改器、环切和参考图。

### 1. 创建杯身

- `Shift + A` 添加 `Cylinder`。
- 把 `Vertices` 降低到 `14` 左右。
- 调整半径和高度，让它接近杯子的比例。

### 2. 掏空杯子

- 进入 `Edit Mode`。
- 切换到面选择。
- 选中顶部面。
- 按 `X` → 选择 `Faces` 删除顶部面。

这样杯子就从实心圆柱变成空心结构的基础。

### 3. 添加厚度：Solidify 修改器

杯壁不能像纸一样薄，所以需要：

`Modifier` → `Solidify`

作用：给单薄的面增加真实厚度。

这是典型的 **非破坏性工作流（Non-destructive workflow）**，你可以之后再调整厚度。

### 4. 添加圆滑：Subdivision Surface 修改器

`Subdivision Surface` 会让模型变得更圆滑，但也会让边缘变软。

所以需要配合：

- `Ctrl + R` 环切，让杯口和杯底保持硬朗。
- `I` 内插面，改善底部结构。

### 5. 使用参考图

不要完全凭想象建模。可以把杯子参考图拖进 Blender，然后：

- `Alt + R` 清除旋转。
- `R + X + 90` 让图片立起来。
- `S` 调整大小。
- `Numpad 1` 进入前视图。

之后根据参考图调整杯身比例。

### 6. 制作杯把手

杯把手需要真正连接到杯身，而不是简单贴上去。

常用流程：

1. 在杯身侧面选中面。
2. 用 `E` 挤出。
3. 配合 `G`、`R`、`S` 做出弧形。
4. 删除需要连接处的面。
5. 用 `F` 或 `Bridge Edge Loops` 连接开口。
6. 如果出现黑色阴影，按 `Shift + N` 重新计算法线。

## 七、盘子建模知识点

盘子适合练习圆形结构、挤出、厚度和边缘控制。

基本流程：

1. `Shift + A` 添加 `Circle`。
2. 填充类型可以选择 `N-gon`。
3. 进入编辑模式。
4. 使用 `I` 内插面。
5. 使用 `E + Z` 向上挤出盘子边缘。
6. 添加 `Solidify` 增加厚度。
7. 添加 `Subdivision Surface` 让盘子更圆滑。
8. 使用 `Ctrl + R` 或 `Shift + E` 控制边缘锐度。

注意：修改器顺序很重要。不同顺序会得到不同效果。

## 八、糖霜制作知识点

糖霜是甜甜圈教程里最重要的有机建模练习。

### 1. 提取糖霜基底

- 选中甜甜圈。
- 按 `Shift + D` 复制。
- 右键取消移动，让复制体留在原位。
- 重命名为 `Icing`。
- 进入编辑模式。
- 开启 `Alt + Z` 透视模式。
- 删除下半部分面，只保留上半部分。

这样就得到一层覆盖在甜甜圈上的糖霜外壳。

### 2. 添加修改器

糖霜常用修改器顺序：

1. `Shrinkwrap`
2. `Solidify`
3. `Subdivision Surface`

作用分别是：

- **Shrinkwrap**：让糖霜贴合甜甜圈表面。
- **Solidify**：给糖霜增加厚度。
- **Subdivision Surface**：让糖霜更圆滑。

### 3. 制作自然边缘

开启 `Proportional Editing`，快捷键 `O`。

然后选中糖霜边缘点，按 `G + Z` 向下移动。滚动鼠标中轮可以调整影响范围。

这样糖霜边缘不会是一条完美直线，而是更自然的波浪形。

### 4. 制作滴落效果

在糖霜边缘选中几个点或边，按 `E` 向下挤出。

细分后会形成比较自然的滴落形状。

### 5. 雕刻糖霜厚度

当糖霜修改器应用后，可以进入 `Sculpt Mode`：

- 用 `Inflate` 笔刷让滴落末端鼓起来。
- 用 `Grab` 笔刷轻微调整流动方向。

真实糖霜不会厚度完全一致，所以这种“不均匀”反而更真实。

## 九、让模型更自然：不完美才真实

电脑生成的模型太完美，反而容易假。

可以使用 `Lattice` 晶格修改器，让甜甜圈整体轻微变形：

- 中间略微收缩。
- 整体不是完美圆形。
- 局部稍微歪一点。

真实甜甜圈在油炸过程中会变形，所以适当的不规则能增加真实感。

## 十、材质与贴图基础

模型决定形状，材质决定“它看起来是什么”。

### 1. 基础材质参数

- **Base Color**：基础颜色。
- **Roughness**：粗糙度，控制反光强弱。
- **Subsurface Scattering / SSS**：次表面散射，适合食物、皮肤、蜡烛等半透材质。

甜甜圈面包和糖霜可以适当使用 SSS，让它们看起来更柔和、更像食物。

注意：做食物时，SSS 颜色不要偏红太多，否则会有奇怪的肉感。

### 2. PBR 贴图

PBR 是 Physically Based Rendering，意思是“基于物理的渲染”。

常见贴图：

- **Base Color**：颜色贴图，色彩空间用 `sRGB`。
- **Normal Map**：法线贴图，用来制造凹凸感，色彩空间用 `Non-Color`。
- **Roughness Map**：粗糙度贴图，控制哪里亮、哪里哑光，色彩空间用 `Non-Color`。
- **Displacement Map**：置换贴图，会真正改变表面高低，需要较高细分。

### 3. 节点调色

如果贴图颜色不好看，可以在节点里加：

- `RGB Curves`：调整对比度。
- `Hue/Saturation/Value`：调整色相、饱和度和明度。

这类似在 Blender 里做简单的 Photoshop 调色。

## 十一、UV 展开基础

UV 展开可以理解为：把 3D 模型表面剪开，摊平成 2D 图片，方便贴图。

### 关键词

- **UV**：3D 模型对应到 2D 贴图的坐标。
- **Seam**：接缝，也就是模型被“剪开”的地方。
- **Unwrap**：展开。

### 常用操作

- 选中边。
- `Ctrl + E` → `Mark Seam` 标记接缝。
- 全选模型。
- 按 `U` → `Unwrap` 展开。

### 接缝思路

- 接缝尽量放在不明显的位置。
- 杯子的接缝可以放在把手内侧。
- 糖霜可以在内部洞口和外侧底边标记接缝。
- 杯把手要单独考虑，否则贴图容易拉伸。

## 十二、咖啡液面与奶泡

咖啡不一定要重新建模，可以从杯子内部边缘复制一圈面出来。

基本流程：

1. 选中杯子内侧液面高度的一圈边。
2. `Shift + D` 原位复制。
3. `P` → 分离选中项。
4. 选中新物体，按 `F` 填面。
5. 用 `I` 内插面。
6. 中间稍微下压，边缘略高。

这样可以模拟咖啡靠近杯壁时的弯月面效果。

如果使用奶泡图集贴图，可以通过调整 UV，让咖啡表面对准其中一个拉花图案。

## 十三、糖珠散布

糖珠部分重点学习集合、实例化、几何节点和随机性。

### 1. 制作糖珠

- 添加小圆柱体。
- 顶点数可以设为 `6`，保持低面数。
- 加一点细分和环切，让它变成胶囊状。
- 复制几个不同形态的糖珠。
- 放入一个名为 `Sprinkles` 的 Collection。

### 2. 使用 Scatter on Surface

选中糖霜，添加 `Scatter on Surface` 修改器。

设置：

- 实例来源选择 `Collection`。
- 选择 `Sprinkles` 集合。
- 开启随机旋转。
- 调整密度和大小。

### 3. 权重绘制控制范围

如果糖珠跑到底部或内侧，需要用 `Weight Paint` 控制分布区域。

- 红色表示权重高，会生成糖珠。
- 蓝色表示权重低，不生成糖珠。
- 开启 `Front Faces Only`，避免画到背面。

然后在散布修改器里把这个顶点组设置为 `Distribution Mask`。

### 4. 避免糖珠重叠

可以使用类似 `Disk` 的分布方式，并调节 `Minimum Distance`。

作用：让糖珠之间保持最小距离，减少互相穿插。

不要调得太整齐，否则会失去自然撒落的感觉。

### 5. 随机颜色

可以用节点实现糖珠随机颜色：

- `Object Info` 的 `Random`
- 连接到 `ColorRamp`
- 再连接到 `Base Color`

把 `ColorRamp` 插值改成 `Constant`，就能得到明确的不同颜色，而不是渐变色。

## 十四、灯光与构图

灯光决定作品是否有真实感和氛围。

### 1. 主光 Key Light

可以使用 `Sun` 作为主光。

- 能量决定亮度。
- 旋转方向决定影子方向。
- 暖色主光可以模拟清晨阳光。

### 2. 填充光 Fill Light

暗部完全死黑会显得很假。

可以使用偏蓝的 `Point Light` 做冷色填充光，模拟天空漫射光。

技巧：

- 把光源半径调大，阴影会更柔和。

### 3. 反弹光 Bounce Light

可以在背光侧放一个弱光，模拟墙壁或室内环境反射出来的光。

### 4. 窗影效果

可以用几个长条平面挡住光线，模拟窗户缝隙形成的光影。

这会让画面更有故事感，而不是普通商品图。

### 5. 景深 Depth of Field

选中摄像机，开启 `Depth of Field`。

- 对焦目标可以选择甜甜圈糖霜。
- 背景会虚化。
- 观众视线会集中在主体上。

## 十五、渲染引擎与最终输出

### 1. Eevee

Eevee 速度快，适合实时预览。

可以开启：

- `Ray Tracing`
- 更高的阴影质量
- `Light Probe Volume`

Eevee 更像是用很多技巧快速模拟真实光照。

### 2. Cycles

Cycles 更真实，适合最终渲染。

特点：

- 路径追踪。
- 光影更准确。
- 反弹光、软阴影、颜色溢出更自然。
- 渲染更慢，但质量更高。

如果有 NVIDIA 显卡，可以在设置中启用 `OptiX` 和 `GPU Compute`，提高渲染速度。

### 3. 降噪 Denoising

Cycles 渲染会有噪点，开启 `Denoising` 可以让画面更干净。

### 4. 色彩管理 Color Management

可以在渲染设置底部调整 `Look`：

- `Medium High Contrast`
- `High Contrast`

这样画面会更有对比度和冲击力。

### 5. 最终渲染

- 按 `F12` 开始渲染。
- 渲染完成后保存为 PNG。

## 十六、建模思维总结

这套甜甜圈教程真正训练的不是“照着做一个甜甜圈”，而是完整的 3D 制作流程：

1. **基础导航**：学会在 3D 空间里观察。
2. **基础建模**：用点、边、面构建形状。
3. **修改器**：用非破坏性方式提升模型质量。
4. **有机变形**：让模型摆脱完美的电脑感。
5. **材质贴图**：让灰模变成真实物体。
6. **UV 展开**：让贴图正确贴在模型上。
7. **散布系统**：快速制造大量自然细节。
8. **灯光构图**：让作品有氛围和视觉重点。
9. **最终渲染**：把模型输出成完整作品。

新手最重要的原则：

- 先做大形，再做细节。
- 先低模，再细分。
- 先理解流程，再追求效果。
- 不要害怕模型不完美，真实世界本来就不完美。

## 英语学习：本节关键词

- **Orbit**：环视 / 旋转视角  
  例句：Hold the middle mouse button to orbit the view.  
  按住鼠标中键旋转视角。

- **Extrude**：挤出  
  例句：Extrude the face to create the handle.  
  挤出这个面来制作把手。

- **Modifier**：修改器  
  例句：A modifier changes the model without destroying the original mesh.  
  修改器可以在不破坏原始网格的情况下改变模型。

- **Non-destructive workflow**：非破坏性工作流  
  这是 3D、设计、剪辑里非常常见的表达，意思是“保留原始内容，随时可以调整”。

- **Roughness**：粗糙度  
  例句：Higher roughness makes the surface less shiny.  
  粗糙度越高，表面越不反光。

- **Depth of Field**：景深  
  例句：Depth of field helps guide the viewer’s attention.  
  景深可以引导观众的注意力。

- **Render**：渲染  
  例句：Press F12 to render the final image.  
  按 F12 渲染最终图片。
