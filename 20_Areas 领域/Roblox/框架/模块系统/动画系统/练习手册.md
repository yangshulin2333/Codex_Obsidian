# Roblox 原生动画系统 4 课实战训练

> 学习策略：先用 Roblox 原生工具完成 4 个小练习，再去学 Moon Animator。  
> 目标：你不是只会“做出一个动画”，而是能理解动画资产、播放脚本、优先级、事件帧、客户端/服务端边界。

## 0. 总路线

| 课次 | 练习 | 核心能力 | 通过标准 |
|---|---|---|---|
| 第 1 课 | 右手挥手，发布后按 `F` 播放 | 原生编辑器、Publish、AnimationId、LocalScript 播放 | Play 后按 `F`，自己的角色能挥手 |
| 第 2 课 | NPC 循环待机，服务端播放 | NPC 动画、Server Script、Loop、所有客户端可见 | Dummy 自动循环待机 |

## 2. 第 1 课：右手挥手，发布后按 F 播放

### 2.1 本课目标

你要完成：

```text
做一个 R15 右手挥手动画
发布到 Roblox
复制 AnimationId
放入 LocalScript
Play 模式下按 F 播放
```

你要理解：

```text
Save 不等于 Publish
AnimationId 从 Publish 来
LocalScript 适合本地玩家自己的角色表现
Priority = Action 可以覆盖默认手臂动作
```

### 2.2 创建 R15 Rig

操作：

```text
Avatar / 虚拟形象
-> Character / 角色
-> 选择 R15
```

建议把 Rig 改名：

```text
WavePractice_R15
```

### 2.3 创建动画

操作：

```text
Avatar / 虚拟形象
-> Clip Editor
-> 选择 WavePractice_R15
-> 输入动画名
```

动画名建议：

```text
Player_Wave_RightHand_R15_v001
```

### 2.4 设置时间轴

右下角时间轴设置建议：

```text
帧速率: 30 fps
播放速度: 1x
时间长度: 1 秒
捕捉模式: 默认或开启
```

### 2.5 制作关键帧

用 `Rotate` 旋转右臂。先做简单版本：

| 时间 | 姿势 |
|---|---|
| `0:00` | 右手自然下垂 |
| `0:10` | 右上臂抬起 |
| `0:20` | 右手向左摆 |
| `0:30` | 右手向右摆 |
| `1:00` | 回到自然姿势 |

至少建议控制这些部位：

```text
RightUpperArm
RightLowerArm
RightHand
```

如果你只动 `RightUpperArm`，也可以，但动作会比较硬。

### 2.6 设置 Easing

选中关键帧，右键：

```text
Easing Style: CubicV2 或 Cubic
Easing Direction: InOut
```

目的：

```text
让挥手不要像机器一样匀速。
```

### 2.7 设置 Priority

操作：

```text
... 菜单
-> 设置动画优先级
-> Action
```

原因：

```text
挥手是主动动作，应该高于 Idle / Movement。
```

### 2.8 保存和发布

先保存编辑数据：

```text
... 菜单
-> 保存
```

再发布：

```text
... 菜单
-> 发布至 Roblox
```

发布窗口填写建议：

```text
标题: Player_Wave_RightHand_R15_v001
描述: R15 wave practice. Priority: Action. Loop: false.
Creator: 我
删除本地实例: 关闭
在工作间中创建动画对象: 可关闭
```

发布成功后复制 `AnimationId`。

### 2.9 创建 LocalScript

位置：

```text
StarterPlayer
└─ StarterPlayerScripts
   └─ LocalScript
```

建议改名：

```text
WavePracticeClient
```

代码：

```lua
local ContextActionService = game:GetService("ContextActionService")
local Players = game:GetService("Players")

local ANIMATION_ID = "rbxassetid://把你的动画ID放这里"

local player = Players.LocalPlayer

local function loadTrack(character)
	local humanoid = character:WaitForChild("Humanoid")
	local animator = humanoid:WaitForChild("Animator")

	local animation = Instance.new("Animation")
	animation.AnimationId = ANIMATION_ID

	local track = animator:LoadAnimation(animation)
	track.Priority = Enum.AnimationPriority.Action
	track.Looped = false

	return track
end

local character = player.Character or player.CharacterAdded:Wait()
local waveTrack = loadTrack(character)

player.CharacterAdded:Connect(function(newCharacter)
	character = newCharacter
	waveTrack = loadTrack(newCharacter)
end)

local function onWaveAction(actionName, inputState, inputObject)
	if inputState ~= Enum.UserInputState.Begin then
		return
	end

	if waveTrack.IsPlaying then
		waveTrack:Stop(0.1)
	end

	waveTrack:Play(0.1, 1, 1)
end

ContextActionService:BindAction(
	"WavePractice",
	onWaveAction,
	false,
	Enum.KeyCode.F
)
```

### 2.10 验证

点击 Play：

```text
按 F
角色右手挥动
Output 没有红色报错
死亡重生后按 F 仍能播放
```

如果不能播放，检查：

```text
AnimationId 是否是 rbxassetid://数字
动画是否已经 Publish
LocalScript 是否在 StarterPlayerScripts
Output 是否有权限错误
```

## 4. 第 3 课：攻击动画加 Hit Marker，脚本打印

### 4.1 本课目标

你要完成：

```text
做一个简单攻击动画
在命中帧添加 Hit Marker
播放动画时监听 Hit
Output 打印 Hit frame
```

你要理解：

```text
Animation Event / Marker 是动画时间轴上的事件点
攻击命中不应该只靠客户端决定
本课先 print，后面正式战斗要交给服务端验证
```

### 4.2 做攻击动画

动画名：

```text
Player_Attack_Light01_R15_v001
```

时间建议：

| 时间 | 姿势 |
|---|---|
| `0:00` | 预备 |
| `0:08` | 蓄力 |
| `0:15` | 挥出 |
| `0:20` | 命中帧 |
| `0:35` | 收招 |

建议控制：

```text
UpperTorso
RightUpperArm
RightLowerArm
RightHand
LeftUpperArm
```

设置：

```text
Priority: Action
Loop: false
```

### 4.3 添加 Hit Marker

打开事件轨道：

```text
右下角设置菜单
-> 显示动画事件
```

把 Scrubber 移到命中帧：

```text
0:20 左右
```

添加事件：

```text
Event Name: Hit
Parameter: Light01
```

发布动画并复制 `AnimationId`。

### 4.4 创建测试 LocalScript

位置：

```text
StarterPlayer
└─ StarterPlayerScripts
   └─ LocalScript
```

建议改名：

```text
AttackMarkerPracticeClient
```

代码：

```lua
local ContextActionService = game:GetService("ContextActionService")
local Players = game:GetService("Players")

local ANIMATION_ID = "rbxassetid://把你的攻击动画ID放这里"

local player = Players.LocalPlayer
local currentTrack

local function setupCharacter(character)
	local humanoid = character:WaitForChild("Humanoid")
	local animator = humanoid:WaitForChild("Animator")

	local animation = Instance.new("Animation")
	animation.AnimationId = ANIMATION_ID

	local track = animator:LoadAnimation(animation)
	track.Priority = Enum.AnimationPriority.Action
	track.Looped = false

	track:GetMarkerReachedSignal("Hit"):Connect(function(param)
		print("Hit frame reached. Param:", param)
	end)

	currentTrack = track
end

setupCharacter(player.Character or player.CharacterAdded:Wait())
player.CharacterAdded:Connect(setupCharacter)

local function onAttack(actionName, inputState, inputObject)
	if inputState ~= Enum.UserInputState.Begin then
		return
	end

	if currentTrack.IsPlaying then
		currentTrack:Stop(0.05)
	end

	currentTrack:Play(0.05, 1, 1)
end

ContextActionService:BindAction(
	"AttackMarkerPractice",
	onAttack,
	false,
	Enum.KeyCode.F
)
```

### 4.5 验证

点击 Play：

```text
按 F 播放攻击
动作播放到命中帧时 Output 打印:
Hit frame reached. Param: Light01
```

如果没有打印，检查：

```text
事件名是否真的叫 Hit
大小写是否一致
动画是否重新 Publish
脚本里的 AnimationId 是否是新发布的攻击动画
是否打开了 Output
```

### 4.6 重要边界

本课只打印，是为了学习 Marker。

正式战斗不能这样写：

```lua
-- 不推荐：客户端自己决定伤害
enemyHumanoid:TakeDamage(10)
```

正式做法应该是：

```text
客户端播放动画并在 Hit 帧请求攻击结算
服务端验证距离、冷却、状态、目标是否合法
服务端决定是否扣血
```

## 5. 第 4 课：低优先级攻击被走路影响，再改成 Action

### 5.1 本课目标

你要完成：

```text
故意把攻击动画用低优先级播放
一边走路一边按 F
观察手臂动作被走路动画影响或混合
再改成 Action
观察差异
```

你要理解：

```text
Priority 决定同一关节被多个动画控制时谁更强
动画只控制有关键帧的关节
Action 通常用于攻击、交互、技能
```

### 5.2 使用第 3 课攻击动画

继续用：

```text
Player_Attack_Light01_R15_v001
```

为了更容易观察，攻击动画最好控制：

```text
RightUpperArm
RightLowerArm
RightHand
UpperTorso
```

如果只控制 `RightUpperArm`，差异可能不够明显。

### 5.3 低优先级版本

先把脚本里的优先级改成：

```lua
track.Priority = Enum.AnimationPriority.Core
```

完整重点片段：

```lua
local track = animator:LoadAnimation(animation)
track.Priority = Enum.AnimationPriority.Core
track.Looped = false
```

验证方式：

```text
Play
按住 W 走路
走路过程中按 F
观察攻击动作是否弱、混合、被默认走路手臂动作影响
```

注意：

```text
低优先级不一定是完全不播放。
它可能表现为动作变弱、和走路混合、姿势不完整。
这就是动画冲突。
```

### 5.4 改成 Action

把优先级改成：

```lua
track.Priority = Enum.AnimationPriority.Action
```

再验证：

```text
Play
按住 W 走路
走路过程中按 F
观察攻击手臂是否明显覆盖走路摆臂
```

你应该能看到：

```text
Action 版本更强
攻击动作更完整
右手不容易被走路手臂动作抢走
```

### 5.5 进阶观察：按关节覆盖

如果攻击动画只给右手打关键帧：

```text
右手被攻击动画控制
腿仍然走路
身体可能仍然受走路影响
```

如果攻击动画给上半身也打关键帧：

```text
上半身攻击动作更稳定
但也可能让移动时看起来更僵硬
```

这就是动作设计取舍：

```text
只控制手臂 = 可以边走边攻击，更灵活
控制上半身 = 攻击更强，但移动融合更硬
```

## 6. 完成 4 课后的 Moon Animator 学习入口

这 4 课完成后，你再看 Moon Animator 教程，就按这个映射理解：

| Moon Animator 学到的东西 | Roblox 原生对应 |
|---|---|
| 时间轴关键帧 | Keyframe / Track |
| 导出动画 | Publish / AnimationId |
| 事件点 | Animation Marker |
| 循环动作 | Looped |

```text
这个动画最后怎么导出？
AnimationId 在哪里？
Priority 设置了吗？
有没有 Marker？
播放对象是本地玩家、NPC，还是服务端控制对象？
```
