# 故障排查与适用边界

本页把症状与必要证据对应起来。完整步骤见 [[01_Xeno客户端内容归档通用工作流]]；执行入口见 [[02_快速执行与验收清单]]。数值案例来自历史实测，详见“04/07”；它们不是当前环境的默认值。环境发现与路径角色见 [[08_环境迁移与参数配置]]；默认只做原始归档，失败不自动转入源码恢复或预览。

## 故障判断表

| 症状 | 先检查的证据 | 处理与验收边界 |
|---|---|---|
| UI、Toast 显示成功/Attached，但脚本没效果 | 当前客户端握手、真实唯一 print、时间与目标身份 | 状态提示只是 UI 证据；真实 print 未出现就停在 Attach 阶段，不开始批量导出 |
| 报 offsets，或怀疑新版不兼容 | 当前运行 Player 版本、client data/offset 获取结果、通信及实际输出 | 区分兼容信息与本地通信。磁盘最新安装版可能不是当前进程；改版本/重启后重新验证 |
| localhost 服务在 IPv6，IPv4 连接失败 | 实际 listener/端口、IPv4/IPv6 可达性、HTTP 状态、attach ping | 历史有 IPv4/IPv6 不匹配案例，端口细节见“04”。先诊断当前实际 listener；固定 DLL offset/hash 补丁不能跨版本照搬 |
| 大厅导出成功，却没有实战地图 | capture 的 PlaceId、GameId、Workspace 地图树和传送记录 | 同 Universe 不等于同 Place；实战单独采集。大厅快照不能补出未采到的实战场景 |
| 写“第 N 层”，但来源是 HighestFloor 或模板 | 当前 Workspace 状态、当前地图路径、显示标签与时间 | 玩家历史最高层/任务条件不代表当前层。只使用可核对当前状态；地图推进前保存独立快照，旧层被替换后不能回推恢复 |
| 地图只保存附近部分或缺动态区域 | StreamingEnabled、当前已复制对象、加载状态、捕获时间 | 只承诺当前客户端可读范围。关闭 Streaming 也不等于服务端私有内容可见；动态地图可能跨阶段改变 |
| 有 scene 文件但导出不完整 | finish/pipeline、大小、XML 实际解析、头尾、身份 | 文件出现不等于完成；未有完成记录或 XML 解析失败就保留 raw，另建捕获重试 |
| “源码很多”，实际都是注释/失败文本 | 去包装后的 Source 分类、脚本索引、bytecode 解码状态 | placeholder、server-source 不可读、decompile-disabled、error payload 不计成功源码/有效 bytecode；原始 bytecode 不等于原始源码 |
| `.rbxm`、Animation ID 很多，却无动画数据 | 实际反序列化 class、KeyframeSequence/Keyframe/Pose、CurveAnimation | 后缀只标识容器；引用对象/ID 只证明引用存在。按真实已下载动画数据计数，不宣称原游戏运行行为已恢复 |
| HLS master 下载成功，视频仍不能播放 | master/variant/segment/init 分阶段 manifest、403、key/DRM 状态 | 只有 master 不算视频完成。历史大厅全部 5 个 variant 被 403 拒绝，没有 segments 或离线播放文件；只保存失败，不猜地址或绕权限 |
| 下载有 401/403/404、429、5xx 或超时 | HTTP 状态、Retry-After、request key、成功/失败 manifest | 401/403/404 正常记不可取；429/5xx/网络故障做有界退避重试。成功优先合并，保留历史失败，不把 API error JSON 当素材 |
| 缓存里似乎有资源，无法对应 asset ID | 当前明示 ID/URI 与只读索引精确关联、payload 大小/hash | 无精确关联不复制。时间、外观和 opaque hash 都不够；“无候选”不证明整个缓存不存在资源 |
| Terrain 采集报告完成，仍漏块 | 实际 index 集合、连续性、重复项、维度、RLE 总量与块文件 | 历史 producer 完成数与 raw 索引不符，漏 42 条；保留 raw，独立重读缺索引，derived 合并记录多时段来源 |
| CountCells 或 Terrain.Size 与预期不同 | 三通道真实数据、探针/扫描框、源与 native 验证 | CountCells 是近似指标，Size/MaxExtents 不能当占用边界；恢复后重开 native 逐通道核验，局部空探针不能证明全世界为空 |
| native 回读 instance 数减少 | 主要游戏 service、脚本与关键引用、runtime/cache/alias 差异 | Studio 可以移除运行时服务并增加编辑默认项。先分类差异；总数量不等不能直接判损坏，也不能忽略关键地图丢失 |
| 回读工具报 Terrain type 0x23 不支持 | 原 native hash、工具版本、unsupported 诊断与原生读取 | 历史读取器存在 decoder 缺口（版本细节见“04/07”）；回读缺少字段不能证明 native 丢失该字段。单列未覆盖项，不声称无损 |
| 换电脑后启动入口找不到 Studio | 是否完整解压、相对场景路径、Studio 安装路径、CheckOnly | 场景文件可用与本机安装发现是两件事；若选择 native/预览阶段则重新发现 Studio并写本地配置，保留 relative scene 路径。默认 raw 归档无需 Studio；不能依赖旧机 version 目录 |
| ZIP 有素材，场景仍需联网或显示缺资源 | 场景中保留的 URI、素材下载 hash、受限请求和引用重映射情况 | 下载附件不自动重写 scene 的资源 URI；“ZIP 完整”不等于“完全离线可用”。未做重映射/离线验证就明示限制 |
| ZIP 校验失败或混入 `.partial`/`.lock` | 运行中任务、临时产物、来源 hash、entry 集合、CRC/SHA256 | 不在运行中构建正式包。临时文件排除，正常完成后重建；任何集合/hash/CRC 不符都停止交付，不仅检查 ZIP 能否打开 |

## 归档后优化的新增故障（2026-10-10）

以下来自 [[07_EvoMon优化预览版案例与验收]]，复用步骤见 [[06_字节码恢复与场景优化工作流]]。

| 症状 | 必要证据与处理 |
|---|---|
| 字节码解析成功，但没有可读源码 | 字符串/常量提取不是反编译；匹配版本/编码后另做离线恢复与官方语法、编译、AST 验收 |
| `.lua` 编译通过，逻辑仍可能不完整 | 对照输入函数原型、输出 AST 和二进制常量；原变量结构或控制流可能改变，源码默认停用，候选/失败分开 |
| 下载接口 401/403，或 generic URI Preload Failure 很多 | 对应到实际 class/property 和正常渲染日志；不能据通用字符串预加载盲删 MeshPart/字体或声称所有模型损坏 |
| 本地 PNG 已部署，PBR 仍报不支持 | 文件可读不证明 SurfaceAppearance/MaterialVariant 的 texture-pack 用途有效；明确降级并保留父几何，记录白色/基础材质变化 |
| 文件夹和真正服务同名，特殊容器父级报错 | 归档的 Players/StarterPlayer Folder 与真实服务分开；旧特殊脚本容器降为资料 Folder，预览脚本放在真正服务下 |
| Play 以后物体下坠、旧 GUI 遮住画面 | 静态预览固定已保存动态 Parts，关闭旧界面与原启动脚本；使用独立预览，不运行缺失服务端依赖的逻辑 |
| 无 Avatar 的自由相机下，岛屿消失或跳转看不到 | 检查 Streaming 与复制中心；本次静态预览关闭流式卸载，只保留已采到对象，不把该设置推广为生产游戏建议 |
| PowerShell 子进程找不到 Get-FileHash | 使用明确的纯 .NET SHA256 文件读取函数并释放句柄，入口继续做只读 CheckOnly；不通过改变安全策略解决 |
| 同一路径重开仍显示旧候选场景 | 核对当前 Studio 实际文件/会话与最终文件 hash；单独验证副本及语义差异，不能把旧窗口结果归于新产物 |

## 哪些变化需要重新开始验证

- **客户端重启、Player/Xeno 更新或版本不符：** 保存旧诊断，重新核对版本、目标身份、真实 print 和匹配 API dump。
- **大厅传送、地图替换、回合推进或断开：** 停止旧捕获，以新编号保存新场景；不得覆盖此前 raw。
- **导出参数/依赖修改：** 保存旧工具 hash 与改动，新结果单独验收；不能沿用旧 validation 假定新产物通过。
- **下载中断但 raw 不变：** 核对 manifest、已完成文件 hash 与 partial/lock 状态后继续增量；不必无依据重采整张地图。
- **native 修改或 Terrain 恢复变化：** 重新记录 native hash，并验证改后的文件；旧 native 验收不能覆盖新文件。
- **ZIP 重建：** 重新验收复制文件、entry 集合、CRC、逐 entry hash 和整个 ZIP hash。

停止是指暂停该阶段并保留证据。只运行本次已选择阶段；默认 raw 不因未做 native/源码恢复/预览而视为失败。某些资源因正常权限失败，可以继续构建注明缺失的归档；身份不符、raw 不完整、ZIP hash 失败则不能作为成功交付；选择 native 阶段时关键 native 差异同样必须解决。

## 可声称的成果与尚未证明的内容

| 已有证据时可以写 | 证据不足时不应写 |
|---|---|
| 当前 Place/地图/楼层的客户端可读快照已保存 | 游戏所有楼层、未来回合或完整服务端工程已恢复 |
| 明确扫描框与所列 Terrain 块通过三通道验证 | 单凭 CountCells/空探针证明全世界完整 |
| 可读 Source/原始 bytecode/占位失败分别保存 | 保存 bytecode 等于还原全部源码 |
| 某些实际动画容器下载并分类通过 | Animation ID 数等于已下载动画数 |
| ZIP 结构、CRC 和每 entry hash 已通过 | ZIP 校验通过证明游戏完整玩法可运行 |
| Studio Edit 可打开和保存 native | 未测试的 Play、服务端行为或离线运行已成功 |
| 部分附件已获取，受限内容有缺失记录 | 附件存在即 scene 引用全部离线化 |
