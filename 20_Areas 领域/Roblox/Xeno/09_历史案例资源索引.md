# 历史案例资源索引

本页代替旧机器 `file:///` 绝对链接，保留资源身份、用途与原目录内部的相对结构。**索引不等于文件已经打包/迁移/重新验收。** 所有条目是历史记录，当前读取时先解析本地根角色，再确认文件存在、大小及已知 SHA256。没有已知 hash 的条目标记未重验，不能把路径同名当作同一内容。

机器根目录不写入笔记：在 Vault 外配置 `environment.paths.historicalEvidenceRoot`。例如根变化后，`hist-dandy-gameplay-validate-and-extract` 的 artifactId/relativePath 不变。可用“08”的 resolve-artifact 只读命令定位单条记录；不得根据本页直接执行未经审阅的历史脚本。

JSON 索引见 `history-artifacts.json`；新来源用新的 artifactId、角色、相对路径、hash 追加，保留原案例记录。旧8份Markdown文件名保持不变；新增相对链接支持随目录移动。外部 MOC/Wiki 链接只在完整 Vault 中存在，独立拷贝此目录时不会携带那些页面。

## 根角色

| 角色 | 内容 | 迁移规则 |
|---|---|---|
| `historicalEvidenceRoot` | 历史捕获/处理目录、报告、脚本、包 | 本地配置改根；按索引根内相对结构迁移，逐项验证 |
| `historicalGitBackupRoot` | 原 Git 历史备份，不属于游戏归档 | 仅05历史记录引用；本地独立映射，不导出到游戏包 |
| `vaultRoot` | 当前知识库 | 环境发现时登记，不要求旧盘符/库名 |
| `artifactRoot` | 本次及后续捕获/派生/包 | 与笔记同步分开；包内一律相对路径 |
