# 英语单词积累

这篇笔记用于长期记录 `yanzo` 笔记库里出现过的英语单词和技术词。后续遇到新单词时，继续按同样格式追加。

记录字段：

```text
单词 / 短语
音标
汉语意思
发音中文谐音
帮助记忆
来源 / 场景
```

说明：

- 本次先收录当前笔记库中反复出现、适合学习的英语词。
- 随机文件名、图片名、哈希、纯变量名暂不收录。
- 中文谐音只是辅助发音，最终还是以音标和真实发音为准。
