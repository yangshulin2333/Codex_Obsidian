# MPChat 云影卡充值流程（欧易 C2C + TRC20）

## 一句话记忆

**人民币 → 欧易 C2C 买 USDT → 通过 Tron（TRC20）提到 MPChat → 等待入账审核 → 从支付余额划转到虚拟卡。**

> [!warning] 时间敏感
> 平台入口、汇率、提币费、最低充值额、风控和卡费都可能变化。每次操作都以当天 App 确认页和官方帮助页为准。

## 充值 100 美元时买多少

- 不要只买刚好 100 USDT。
- 本次实测购买 **103 USDT**，用于覆盖欧易提币费，并给卡消费费留出余量。
- MPChat 当前卡消费服务费为 **0.8%**。支付 100 美元时，卡片资产至少应有 **100.8 USDT**，建议多留一点余额。
- 欧易提币费会动态变化，提交前检查“实际到账”和“总扣除”。

## 第一步：在欧易 C2C 买 USDT

路径：

`欧易交易所 → C2C 买币 → 快捷区 → 购买 → USDT`

操作：

1. 按币数输入 **103 USDT**，查看实际需要支付的人民币。
2. 使用本人实名的支付宝、微信或银行卡付款。
3. 真正付款后，再点击“我已支付”。
4. 等商家放币，确认 USDT 已进入欧易资金账户。

下单前必须检查：

- 是否出现 `T+3 / T+7 / T+15` 提币限制；急用时不要继续购买受限订单。
- 商家收款人和订单页面是否一致。
- 转账备注不要写“USDT”“买币”等数字货币相关内容。
- 不脱离欧易订单与商家私下交易。

## 第二步：从 MPChat 复制充值地址

路径：

`MPChat → 钱包 → 存款 → USDT 链上充值 → Tron（TRC20）`

操作：

1. 确认币种是 `USDT`。
2. 确认网络是 `Tron（TRC20）`。
3. 复制当前页面生成的充值地址，TRON 地址通常以 `T` 开头。
4. 页面显示的最低充值额必须满足；当前官方说明要求实际到账不少于 10 USDT。

> [!danger] 绝对不要混用网络
> `Tron（TRC20）` 充值地址不能用 Arbitrum、Ethereum、BSC 等其他网络发送。不要把代币合约地址当成充值地址。

## 第三步：从欧易提币到 MPChat

路径：

`欧易 → 资产 → 提币 → 提取数字货币 → USDT → 链上提币`

填写：

- 收款地址：刚从 MPChat 复制的地址。
- 网络：`Tron（TRC20）`。
- 金额：按本次需要填写，提交前确认实际到账金额足够。

最终确认时逐项检查：

- 币种是否为 USDT。
- 网络是否为 Tron（TRC20）。
- 地址开头、结尾是否与 MPChat 页面一致。
- 实际到账、网络费和总扣除是否符合预期。

## 第四步：等待链上确认和 MPChat 审核

欧易显示“已提取/已转出”，只表示欧易已经汇出，不等于 MPChat 已完成入账。

正常流程：

`欧易汇出 → TRON 区块确认 → MPChat/HashKey 入账审核 → 支付余额增加`

可能看到的状态：

- `确认中`：等待区块确认。
- `入账待审核/入账中`：地址和链上转账通常已经识别，等待 AML/KYT 审核。
- `成功`：资金已经进入 MPChat 支付余额。

处理原则：

- 不要因为余额暂未变化而重复转账。
- 正常多数约 30 秒至 15 分钟。
- 链上已经成功但超过 30 分钟仍未入账时，联系 MPChat 客服，私下提供 TxID、币种、网络、金额和时间。

## 第五步：把支付余额划转到虚拟卡

USDT 入账后首先进入“支付余额”，还不能直接作为卡片余额消费。

路径：

`MPChat → 钱包 → 划转`

选择：

- 从：`支付余额`
- 到：目标虚拟卡
- 币种：`USDT`
- 金额：可选择“最大”

确认“划转成功”后，再检查卡片资产是否达到需要支付的金额。

## 第六步：订阅扣款前检查

- 虚拟卡没有被冻结。
- 卡片资产足够覆盖账单金额、0.8% 服务费和少量预授权空间。
- OpenAI 账单页仍保存这张卡，并且它是默认付款方式。
- 自动续费前不要连续试刷；余额不足导致的拒付可能产生额外费用。

## 常见问题速查

| 现象 | 判断与处理 |
|---|---|
| C2C 订单提示 T+N | 该笔资产暂时不能提币；急用时不要付款，避免反复取消订单 |
| 欧易已提取，MPChat 没变化 | 查欧易提币记录中的 TxID，确认链上状态、网络和地址 |
| MPChat 显示“入账待审核” | 已进入审核环节，不要重复充值；超过 30 分钟再联系客服 |
| MPChat 已到账但卡不能刷 | 检查是否还停留在支付余额，需手动划转到卡 |
| 100 美元账单扣款失败 | 检查卡片资产是否至少覆盖账单加 0.8% 服务费，并确认卡未冻结 |

## 隐私规则

普通笔记和公开截图里不要保存或暴露：

- 完整卡号、有效期、CVV
- 姓名、邮箱、账单地址
- 完整钱包地址、充值地址、TxID
- 验证码、密码、助记词、私钥
