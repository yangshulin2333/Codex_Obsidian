# 跨境账户与订阅付款流程记录

## 一句话说明

这页只记录跨境账户、订阅付款和平台收款方案的评估框架，不直接给出当前开户或付款建议。

## 适合记录的内容

- ChatGPT / SaaS 订阅付款路径。
- Roblox DevEx / Tipalti 收款方案评估。
- 香港银行、多币种账户、Payoneer 等方案对比。
- 费用、余额要求、卡组织、收款方式。
- 资金来源解释和合规风险。

## 评估维度

| 维度 | 说明 |
|---|---|
| 合规性 | 是否是正规账户或平台 |
| 可解释性 | 资金来源是否容易说明 |
| 平台兼容 | 是否支持 Roblox / Tipalti / SaaS |
| 成本 | 月费、余额要求、手续费、汇率差 |
| 可获得性 | 是否需要线下开户、地区限制 |
| 稳定性 | 是否适合长期使用 |
| 风险 | 账号、政策、税务、支付失败 |

## 历史笔记口径

当前库里已有两类历史记录：

- `Fiat24 + 欧易 + Arbitrum` 用于一次 ChatGPT Plus 付款流程。
- `HSBC HK One + Mastercard Debit Card` 用于 Roblox DevEx / 跨境账户方案评估。

这些内容具有时间敏感性。再次执行前必须重新核验官方规则、费用、账户条件和平台支持。

## 不写入普通 Wiki 的内容

- 完整银行卡号。
- 身份证件信息。
- 完整钱包地址。
- 登录账号、密码、助记词、私钥。
- 为规避税费或平台规则而生成的地址、电话、身份资料。
