# 高风险金融内容核验清单

## 一句话说明

涉及钱、账户、政策、税务、交易规则的内容，必须标明核验状态，不能把旧笔记当成当前事实。

## 必须重新核验的内容

- 银行开户条件。
- 月费、最低余额、账户维护费。
- 税务、消费税、地区政策。
- 交易所提币规则。
- 链上网络和手续费。
- 平台收款方式。
- 卡组织和支付失败规则。
- 投资产品、利率、收益率。

## 记录方式

| 项目 | 记录 |
|---|---|
| 核验日期 | YYYY-MM-DD |
| 来源 | 官方网站 / App 页面 / 客服 / 账单 |
| 是否截图 | 是 / 否 |
| 是否仍可执行 | 是 / 否 / 不确定 |
| 风险 | 费用 / 合规 / 账号 / 汇率 / 操作 |

## Codex 边界

Codex 可以帮助：

- 整理流程。
- 做风险清单。
- 区分事实和判断。
- 生成待核验问题。

Codex 不应该替代：

- 专业财务建议。
- 税务建议。
- 法律建议。
- 实时投资判断。
