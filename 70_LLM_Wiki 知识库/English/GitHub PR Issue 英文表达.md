# GitHub PR Issue 英文表达

## 一句话说明

这页用于写 GitHub issue、PR 描述、review 回复和提交说明，保持简洁、专业、容易理解。

## PR 标题

| 中文 | 英文 |
|---|---|
| 修复 HUD 资源刷新问题 | Fix HUD resource refresh issue |
| 添加装备服务 | Add equipment service |
| 更新文档索引 | Update documentation index |
| 调整拼装台 UI 状态 | Adjust AssemblyBench UI states |

## PR 描述模板

```markdown
## Summary

- Added ...
- Updated ...
- Fixed ...

## Verification

- Ran ...
- Checked ...

## Notes

- This does not change ...
```

## Issue 模板

```markdown
## Problem

The current behavior is ...

## Expected Behavior

It should ...

## Steps to Reproduce

1. ...
2. ...
3. ...

## Notes

...
```

## Review 回复

| 中文 | 英文 |
|---|---|
| 已修复。 | Fixed. |
| 我已经更新了这里。 | I updated this part. |
| 这个建议合理。 | This suggestion makes sense. |
| 我保留了当前实现，因为... | I kept the current implementation because ... |
| 我会再补一个测试。 | I will add one more test. |

## 常用动词

| 动词 | 用法 |
|---|---|
| add | Add a new file or feature |
| update | Update existing content |
| fix | Fix a bug |
| remove | Remove unused code |
| rename | Rename a file or variable |
| verify | Verify the behavior |
