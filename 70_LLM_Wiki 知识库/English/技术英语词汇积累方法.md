# 技术英语词汇积累方法

## 一句话说明

技术英语词汇不只记中文意思，还要记录音标、场景、记忆方式和自己会在哪里用到它。

## 记录字段

```text
单词 / 短语
音标
汉语意思
发音中文谐音
帮助记忆
来源 / 场景
```

中文谐音只作为入门辅助，最终以音标和真实发音为准。

## 优先收录什么

- Obsidian 和笔记系统高频词。
- Git / GitHub / 同步相关词。
- 文件、路径、系统相关词。
- AI 工具相关词。
- Roblox / 编程高频词。
- 自己经常看见但读不准的词。

## 不优先收录什么

- 随机文件名。
- 图片哈希。
- 纯变量名。
- 只出现一次且不影响理解的词。

## 技术词例子

| 单词 | 含义 | 场景 |
|---|---|---|
| repository | 仓库 | GitHub |
| commit | 提交 | Git |
| branch | 分支 | Git |
| source | 来源 | YAML / docs |
| template | 模板 | Obsidian |
| controller | 控制器 | Roblox / MVC |
| request | 请求 | Client / Server |
| equipment | 装备 | 游戏系统 |

## 使用方法

1. 遇到新词先记录来源。
2. 查音标和核心含义。
3. 写一个简单例句。
4. 标出自己在哪个项目会用。
5. 以后写英文说明时优先复用。
