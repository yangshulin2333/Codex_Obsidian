# 英语常见错误与发音纠正

## 一句话说明

这页记录自己的常见英语错误和纠正方式，优先关注技术沟通里高频出现的词和发音。

## tr / dr 不要混

`tr` 不是简单浊化成 `dr`。

更准确的感觉：

```text
tr = light ch-r
dr = heavy j-r
```

例子：

| 单词 | 音标 | 说明 |
|---|---|---|
| tree | /triː/ | `tr` 清，声带不明显震动 |
| try | /traɪ/ | `tr` 清 |
| dry | /draɪ/ | `dr` 浊，声带震动 |
| dream | /driːm/ | `dr` 浊 |

## tʃ / dʒ

| 音 | 例词 | 说明 |
|---|---|---|
| /tʃ/ | chair, choose | 清，短而干脆 |
| /dʒ/ | job, jump | 浊，声带震动 |

## ts / dz

| 音 | 例词 | 说明 |
|---|---|---|
| /ts/ | cats, hats | 清，短促收尾 |
| /dz/ | beds, words | 浊，短而沉 |

## Bootstrap 的读法

```text
Bootstrap /ˈbuːtstræp/
= boot + strap
```

不要简单读成“布拽普”。更好的记法：

```text
BOOT + strap
```

## 常用术语

| 单词 | 含义 | 简单例句 |
|---|---|---|
| voiceless | 清辅音的 | /t/ is a voiceless sound. |
| voiced | 浊辅音的 | /d/ is a voiced sound. |
| cluster | 辅音连缀 | /str/ is a consonant cluster. |
| pronunciation | 发音 | I want to improve my pronunciation. |
| stress | 重音 | The stress is on the first syllable. |
