# CET4 友好商务英语句库

## 一句话说明

这页收集适合 CET-4 水平的简洁商务英语，目标是清楚、专业、好懂，不追求复杂句。

## 基本风格

- Use short sentences.
- Use common words.
- Be polite and direct.
- Avoid long clauses.
- Say the main point early.

## 开场

| 中文 | 英文 |
|---|---|
| 你好，我想确认一下这个问题。 | Hi, I would like to confirm this issue. |
| 我想和你同步一下当前进展。 | I would like to share the current progress with you. |
| 这里是本周的简短更新。 | Here is a short update for this week. |
| 我有一个问题需要确认。 | I have one question to confirm. |

## 进度

| 中文 | 英文 |
|---|---|
| 这个任务已经完成。 | This task is complete. |
| 这个功能已经实现，但还没有测试。 | This feature is implemented, but not tested yet. |
| 我正在检查问题原因。 | I am checking the cause of the issue. |
| 下一步是运行测试。 | The next step is to run the tests. |
| 我会在验证后更新结果。 | I will update the result after verification. |

## 问题和风险

| 中文 | 英文 |
|---|---|
| 当前有一个风险。 | There is one current risk. |
| 这个问题可能影响上线。 | This issue may affect the release. |
| 我需要更多信息才能继续。 | I need more information to continue. |
| 这个改动可能影响其他模块。 | This change may affect other modules. |

## 请求确认

| 中文 | 英文 |
|---|---|
| 请确认这个方向是否可以。 | Please confirm if this direction is okay. |
| 你能帮我确认一下吗？ | Could you help confirm this? |
| 如果没有问题，我会继续下一步。 | If there are no issues, I will continue with the next step. |
| 请告诉我你更喜欢哪个方案。 | Please let me know which option you prefer. |

## 收尾

| 中文 | 英文 |
|---|---|
| 谢谢，我会继续跟进。 | Thank you. I will continue to follow up. |
| 我会在完成后更新。 | I will update you when it is done. |
| 如果有变化，我会及时说明。 | If there are any changes, I will let you know. |
