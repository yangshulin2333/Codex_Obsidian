# Tripo 多视图工作流

## 一句话说明

Tripo 多视图工作流用于把一张 Roblox 武器参考图，扩展成同系列改款的 `front / back / left / right` 四张建模参考图。

## 核心原则

```text
一把武器一个上下文。
先锁 1 张同系列改款 front。
再根据武器类型扩 back / left / right。
四个方向必须像同一把武器旋转。
```

## 为什么不能直接生成四张

常见失败：

- 四张图像四把同系列但不同设计的武器。
- 侧视变成 3/4 视图。
- 平面型武器被横向压缩成假侧视。
- 体块型武器被压成一条线，丢失体积。
- 旧武器候选图污染新武器上下文。
- 低模被误解成儿童化、简陋化。

## 标准流程

```text
1. 新武器独立上下文
2. 写 DNA 卡和风格锁
3. 只生成同系列改款 front
4. 用户确认 front
5. front 升级为唯一设计锁
6. 判断武器类型
7. Codex 主动询问并复述 left/right 各自必须看见、必须隐藏的结构
8. 用户确认两份侧向可见性合同
9. 分别按合同生成 back、left、right；镜像只在用户明确授权时使用
10. 做四视图一致性检查
11. 最终只交付 00_final_tripo_upload/front.png back.png left.png right.png
```

## v1.4 执行优化

- `front` 仍必须先获得人工确认。
- 用户明确要求“剩余视图一起生成”后，可以切换为批量继续模式；只合并等待，不合并独特视图。
- `left/right` 是两个独立输出合同；不从外观判断是否可镜像。只有用户明确授权共用几何时，`right` 才可由 accepted `left` 做确定性水平镜像。
- 图像生成长时间无输出时先等待 / 恢复原任务，禁止重复提交相同任务。
- 正式图统一画布时只允许等比缩放、居中和补边，不允许非等比拉伸。
- 更广泛的机器、宝箱、瓶罐、工作台、开放框架和落地长体请使用 [[../../81_WorkFlow 工作流/Roblox/模型相关/Roblox 通用游戏素材道具制作工作流/README|Roblox 通用游戏素材道具制作工作流]]。

## 武器类型

| 类型 | 侧视规则 |
|---|---|
| 平面型 | 侧视必须是真 90 度窄边，不能保留正面大面积纹理 |
| 长柄枪头型 | 枪头宽度变窄，但枪头长度、护颈、枪托轮廓要保留 |
| 体块型 | 侧视仍要有圆鼓、球体、锤头等体积，不能压成细线 |

## 四视图一致性门

最终交付前必须检查：

- 武器类别一致。
- 总高度一致。
- 主结构位置能对上。
- 材质和颜色体系一致。
- 细节密度一致。
- back 像同一把武器转到背面，side 像同一把武器转到 90 度。

## 交付边界

这份工作流只负责：

- 同系列改款参考图。
- Tripo / 3D AI 建模前多视图输入。
- 平面型、长柄枪头型、体块型视图生成规则。

不负责：

- Roblox FBX / GLB 打包。
- Blender 修模。
- Roblox Studio 导入问题。
