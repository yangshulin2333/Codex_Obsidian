# GitHub 与资源 Wiki

这个领域用于长期沉淀 GitHub 仓库、工具、课程、网站、文章、官方文档和其他可复用资源。

## 目标

- 不只收藏链接，还要记录用途和适用场景。
- 区分“看过”“用过”“验证过”“已废弃”。
- 把资源和本地项目、工作流、学习目标连接起来。
- 对工具安装、命令和版本保持可追踪。

## 资源卡字段

```markdown
# 资源名称

## 链接

## 它是什么

## 适合什么场景

## 我为什么收藏

## 使用或验证记录

## 风险和限制

## 相关项目 / 笔记
```
