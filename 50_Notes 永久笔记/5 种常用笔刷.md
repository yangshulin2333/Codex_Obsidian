第三课里说的 5 种常用笔刷，可以理解成：

```text
Mask 遮罩
Clay 黏土
Grab 抓取
Elastic Grab 弹性抓取
Inflate 膨胀
```

另外 `Shift = Smooth 平滑` 几乎一直配合使用，虽然它不一定被算进“五种”里，但实际修模型离不开。

**1. Mask 遮罩**

遮罩不是用来“修形状”的，而是用来**保护区域**。

你可以把它理解成：我只想修坏的地方，不想影响好的地方，就先把好的地方遮住。

常见用途：

```text
修护手时，保护刀身
修剑柄时，保护配重
修刀尖时，保护刀身主体
清理粘连时，保护不该被拉动的部分
```

常用操作：

```text
F        调整笔刷大小
Ctrl     反向涂抹
Alt+M    清除遮罩
```

武器模型里特别重要。因为武器是硬表面，很多地方边缘清楚，一旦没有遮罩，Smooth 或 Grab 很容易把刀刃、护手、棱角一起带歪。

**2. Clay 黏土**

Clay 的感觉像往模型上“糊泥巴”或“刮泥巴”。

它适合处理：

```text
局部缺肉
表面坑洞
AI 生成的破碎凹陷
连接处太薄
局部形体不够饱满
```

比如剑柄上有一块凹陷，或者护手某个地方被 AI 生成得坑坑洼洼，可以先用 Clay 补一点体积，再用 Smooth 轻轻抹平。

注意：武器模型不要过度用 Clay。角色可以有柔软肉感，但武器如果 Clay 用多了，会变成泥巴感，刀身和护手会不够利落。

**3. Grab 抓取**

Grab 是用来改**大轮廓**的。

它不是修细节，而是把一块区域整体拉动。

适合：

```text
刀尖歪了，拉正
护手一边太高，拉平
剑柄弯了，拉直
配重偏了，拉回中线
装饰位置偏移，拉到正确位置
```

使用技巧：

```text
用大笔刷修大轮廓
用正交视图操作
不要在透视视角里乱拉
拉完后从正面、侧面都检查一次
```

常见错误是笔刷太小，用 Grab 拉出尖刺或皱褶。修武器轮廓时，笔刷宁可大一点，慢慢拉。

**4. Elastic Grab 弹性抓取**

Elastic Grab 和 Grab 很像，但它更“柔和”，会带着周围区域一起变形，比较不容易拉裂表面。

适合：

```text
调整护手弧度
拉顺剑柄包带
移动挂饰、布条、飘带类结构
把局部装饰从主体里拉出来
修 AI 粘连部位
```

区别可以这样记：

```text
Grab：直接拉，适合硬拉大形状
Elastic Grab：带弹性，适合保持体积和过渡
```

如果你用普通 Grab 拉某个护手尖端，周围可能会被扯出难看的变形；Elastic Grab 会自然一些。

武器里有布条、绑带、弯曲护手、弯刀轮廓时，Elastic Grab 很有用。

**5. Inflate 膨胀**

Inflate 是让表面鼓起来，或者按住 Ctrl 让它缩进去。

适合：

```text
补小洞
加厚太薄的地方
让塌陷区域鼓回来
修剑柄、护手边缘的薄片感
临时封住 AI 生成的小破洞
```

比如刀柄上有个小洞，不值得进入 Edit Mode 慢慢补面，可以用 Inflate 先把周围鼓起来，再 Smooth 一下，外观上就能封住。

注意：Inflate 是快速视觉修复，不等于拓扑真的漂亮。后面如果要降面或重拓扑，只要外观成立，很多时候就够了。

**Smooth 平滑怎么配合**

`Shift` 按住就是 Smooth。

它的作用是把刚才修过的区域抹顺：

```text
Clay 补完后 Smooth
Inflate 鼓起来后 Smooth
Grab 拉完有皱褶后 Smooth
清掉小毛刺时 Smooth
```

但武器模型要小心：

```text
不要把刀刃 Smooth 圆
不要把护手棱角 Smooth 糊
不要把低模硬边抹没
```

所以修武器时，Smooth 通常只轻轻用，不要一直刷。

**你现在修武器的推荐组合**

实际操作可以按这个顺序：

```text
Mask 保护好区域
Grab / Elastic Grab 修大轮廓
Clay 补缺损
Inflate 补薄和小洞
Shift Smooth 清理脏面
```

一句话记法：

```text
Mask 控范围，Grab 改轮廓，Clay 补体积，Elastic Grab 拉自然，Inflate 补薄洞，Smooth 做收尾。
```

你看第三课时重点盯这几个笔刷的“使用场景”，不用急着记所有按钮。真正掌握的标准是：看到一个坏模型，你能判断该用哪个笔刷，而不是所有问题都拿 Smooth 硬抹。
