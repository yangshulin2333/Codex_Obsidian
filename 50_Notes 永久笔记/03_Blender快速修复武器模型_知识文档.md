# Blender 快速修复武器模型知识文档

更新时间：2026-06-07

适用场景：你已经用 Meshy 或其他 AI 工具生成了一把武器模型，目前大约 `10万面`，目标是先快速修好明显问题，再降低到 Roblox 更适合的 `3000-4000 三角面`左右。

这份文档对应课程第三课“雕塑”，但已经改成武器模型工作流。第三课原案例是角色高模，重点是孔洞、粘连、不对称、部件融合；武器模型也会遇到这些问题，只是修复策略更偏向硬表面、轮廓保护和低模友好。

## 先记住结论

不要一上来就降面。

正确顺序是：

```text
备份原模型
-> 检查坏问题
-> 修复明显几何错误
-> 保住大轮廓
-> 删除没用的小碎片
-> 再进入降面/重拓扑
-> 导入 Roblox 预览
```

如果模型还带着孔洞、漂浮碎片、穿插、法线翻转、粘连装饰，直接从 `10万面`压到 `3000面`，这些问题会被放大，最后就会出现大三角块、黑斑、破面、贴图错位。

## 当前目标不是精修，是快速修到可降面

你现在的阶段只需要达到：

1. 远看轮廓完整。
2. 刀身、护手、剑柄、挂饰等主要部件不缺块。
3. 没有明显漂浮垃圾面。
4. 没有一眼可见的洞。
5. 没有外表面蓝色法线翻转。
6. 细小雕花、裂纹、浮雕不强求保留。
7. 降到 `3000-4000 三角面`后，武器仍然像原来的武器。

对 Roblox 低模武器来说，真正重要的是轮廓、颜色、材质和少量关键结构。太细的裂纹、浮雕、骷髅脸、密集尖刺，最后通常应该靠贴图或特效表现，不应该靠真实几何硬撑。

## 修复前准备

### 1. 建议文件结构

在 Blender 里建立三个 Collection：

```text
00_raw_original      原始导入模型，不动
01_repair_high       修复用高模
02_lowpoly_test      降面测试版本
```

操作原则：

1. 原始模型复制一份再修。
2. 每次大操作前复制一份对象。
3. 不要在唯一版本上直接 Remesh 或 Decimate。
4. 降面版本和修复版本分开管理。

### 2. 先切换正确观察模式

不要只看带贴图的预览。

依次检查：

```text
Solid View          看真实几何轮廓
MatCap              看凹凸和表面噪点
Wireframe           看面数密度和大三角
Face Orientation    看法线方向
Statistics          看 Faces / Tris 数量
```

重点：

- `Face Orientation` 中，外表面正常应该是蓝色。
- 如果从外面看到大片红色，通常是法线翻转。
- 如果某些地方纹理看着没问题，但 Solid View 有洞，说明贴图遮住了几何错误。

### 3. 先应用变换

对修复对象执行：

```text
Object Mode
-> 选中模型
-> Ctrl+A
-> Apply All Transforms
```

原因：

1. 镜像、雕刻、Remesh、Decimate 都依赖正确缩放。
2. 如果缩放没应用，笔刷强度、镜像轴、体素尺寸可能都不稳定。
3. 后续导出 Roblox 时也更容易控制大小。

## 10 分钟快速诊断清单

打开模型后先不要修，先判断问题类型。

### A. 能保留的问题

这些问题不一定要修：

- 看不见的内部穿插。
- 被护手、刀柄、装饰盖住的内部面。
- 贴图里表现的细纹。
- 很细小的高模浮雕。
- 不影响轮廓的小凹凸。

原因：这些东西对 Roblox 武器价值低，强修会浪费时间，降面时也很难保住。

### B. 必须修的问题

这些问题要优先处理：

- 刀身断裂或缺口很明显。
- 护手和刀身粘成一团，轮廓读不清。
- 剑柄有大洞。
- 模型旁边漂浮着碎片。
- 外表面出现大片红色法线。
- 降面前就已经有明显大三角破面。
- 左右对称武器明显歪斜。

原因：这些问题降面后会更明显，并且会影响 Roblox 预览效果。

## 快速修复的核心工具

第三课提到的核心工具，武器模型只需要先掌握这些：

### 1. Mask 遮罩

用途：保护不想被改动的区域。

典型场景：

- 修护手时保护刀身。
- 拉直刀柄时保护配重。
- 平滑破面时保护锋利边缘。

常用操作：

```text
Sculpt Mode
Mask Brush
Ctrl 反向
Alt+M 清除遮罩
F 调整笔刷大小
```

学习重点：你不是每次都整把武器一起修，而是遮住好区域，只动坏区域。

### 2. Smooth 平滑

用途：去掉 AI 生成的脏噪点、破碎面、小毛刺。

常用操作：

```text
Sculpt Mode
按住 Shift 使用 Smooth
```

注意：

- 刀刃边缘不要过度 Smooth，否则会变钝。
- 护手棱角不要过度 Smooth，否则会失去低模硬边风格。
- Smooth 适合修脏面，不适合修大形状。

### 3. Grab 抓取

用途：调整轮廓、大块位置、局部变形。

典型场景：

- 把歪掉的刀尖拉回中线。
- 把护手两端调平。
- 把剑柄末端拉到正确位置。

注意：

- Grab 是修大轮廓，不是修细节。
- 操作前最好打开正交视图，避免从错误角度拉歪。

### 4. Inflate 膨胀

用途：补薄、封小洞、让塌陷区域鼓起来。

典型场景：

- 刀柄局部塌陷。
- 护手边缘太薄。
- AI 生成的小洞需要先视觉封住。

注意：

- Inflate 只能快速补形状，不一定真正修好拓扑。
- 如果后续要重拓扑或降面，只要视觉上闭合，有时已经够用。

### 5. Trim / Flatten 修平

用途：处理武器硬表面。

典型场景：

- 刀身表面凹凸不平。
- 护手平面被 AI 做成泥巴感。
- 剑柄端面不平。

学习重点：武器和角色不一样，武器更需要干净平面、清晰边缘、明确轮廓。

## 武器模型推荐修复顺序

### 第一步：删除漂浮碎片

进入 Edit Mode：

```text
Tab
Select > Select All by Trait > Loose Geometry
X Delete
```

如果碎片不是 Loose Geometry，可以用：

```text
Edit Mode
选中一个碎片面
Ctrl+L 选择连接区域
X Delete
```

判断规则：

- 如果碎片对轮廓没有贡献，删。
- 如果碎片是重要装饰，但位置歪了，先分离出来再摆正。
- 如果碎片非常小，降面后保不住，删。

### 第二步：检查法线方向

打开：

```text
Viewport Overlays
-> Face Orientation
```

外表面如果看到红色：

```text
Edit Mode
A 全选
Mesh > Normals > Recalculate Outside
```

如果仍有局部错误：

```text
选中错误面
Mesh > Normals > Flip
```

判断规则：

- 偶尔内部红色可以不管。
- 外表面大片红色必须修。
- Roblox 里黑面、消失面，有时就是法线问题。

### 第三步：修大轮廓

先修远看形状，不修细纹。

优先顺序：

1. 刀身直不直。
2. 刀尖是否完整。
3. 护手是否清楚。
4. 剑柄是否完整。
5. 配重是否完整。
6. 装饰是否影响轮廓。

推荐视角：

```text
正视图
侧视图
顶视图
正交视图
```

常用操作：

- `Grab` 拉轮廓。
- `Smooth` 去噪点。
- `Flatten` 修平面。
- `Mask` 保护好区域。

### 第四步：处理孔洞

孔洞分两类。

第一类：小洞，不影响结构。

处理方式：

```text
Sculpt Mode
Inflate 补起来
Shift Smooth 平滑
```

第二类：大洞，影响外形。

处理方式：

```text
Edit Mode
选洞口边
F Fill
或 Grid Fill
再 Smooth / Flatten
```

注意：

- 武器模型不一定必须完全水密。
- 但外观上能看到的大洞，要在降面前处理。
- 如果大洞附近拓扑很乱，后面降面会变成大块破面。

### 第五步：处理粘连和穿插

AI 武器常见问题：

- 护手粘到刀身。
- 刀柄绑带和剑柄融成一团。
- 装饰尖刺和主体穿插。
- 宝石、挂件半嵌在表面。

快速判断：

```text
如果粘连影响轮廓，修。
如果粘连藏在内部，看不见，可以不修。
如果粘连是低模后必然消失的小细节，删。
```

常用方法：

1. 用 `Mask` 保护主体。
2. 用 `Grab` 把粘连部件拉开。
3. 用 `Trim / Flatten` 清掉连接残渣。
4. 用 `Smooth` 统一表面。

如果某个装饰太复杂，建议直接删掉或压成简单形状。不要为了一个小装饰拖慢整把武器。

### 第六步：必要时对称修复

如果武器应该左右对称，比如剑、斧、枪头，可以强制做对称。

适合场景：

- 一边护手坏了，另一边是好的。
- 刀身左右不平衡。
- 配重歪斜。

基础思路：

```text
保留好的一半
删除坏的一半
加 Mirror Modifier
确认中线
Apply
Merge by Distance
```

注意：

- 做 Mirror 前必须 `Ctrl+A Apply All Transforms`。
- 原点要在正确中线。
- 如果武器本身是非对称设计，不要强行镜像。

### 第七步：不要过度 Voxel Remesh

第三课里常用 `Voxel Remesh` 把角色高模融合成一个表面。武器模型要谨慎。

Voxel Remesh 适合：

- 整块模型像泥一样破碎。
- 很多部件需要融合成一个整体。
- 拓扑完全烂掉，后面准备重新拓扑。

Voxel Remesh 不适合：

- 刀刃需要锋利。
- 护手需要硬边。
- 模型已经只有 `10万面`，还算能编辑。
- 只是局部小洞、小碎片、小穿插。

原因：

武器是硬表面资产，过度 Remesh 会把硬边变软，把刀刃变厚，把低模轮廓变成泥巴感。

如果必须用，先复制对象，只在复制版本上测试。

## 修复到什么程度可以开始降面

满足下面 8 条，就可以进入降面测试：

1. 正视图轮廓好看。
2. 侧视图厚度合理。
3. 刀尖、护手、剑柄、配重完整。
4. 没有明显漂浮碎片。
5. 外表面没有大片红色法线。
6. 大洞已经补掉。
7. 细节没有密集到一压面就碎。
8. 你愿意接受小细节主要靠贴图表现。

不要等模型完美。你的目标是 Roblox 低模武器，不是影视级高模。

## 降面前必须理解：Faces 和 Tris

Blender 里看到的 `Faces` 不一定等于游戏里的三角面。

游戏引擎最终通常按三角面计算。一个四边面会变成两个三角面。

检查方式：

```text
Viewport Overlays
-> Statistics
查看 Tris
```

目标建议：

```text
Roblox 武器目标：3000-4000 Tris
如果 Blender 显示 3000 Faces，但 Tris 可能已经 6000 左右
```

所以后面写“3000面”时，默认按 `3000-4000 Tris`更稳。

## 快速修复后的降面思路

这部分不是第四课完整拓扑，只是告诉你修完后怎么衔接。

### 方案 A：Decimate 快速降面

适合：

- 武器轮廓简单。
- 没有复杂浮雕。
- 模型主要靠贴图表现。

操作：

```text
Modifier
-> Decimate
-> Collapse
-> 调 Ratio
-> 观察 Tris
```

判断：

- 降到 8000 Tris 看一次。
- 降到 5000 Tris 看一次。
- 降到 3500 Tris 看一次。
- 如果 3500 Tris 已经破相，说明源模型不适合硬压。

### 方案 B：手动保轮廓 + 局部删线

适合：

- 刀身、护手、剑柄结构清楚。
- 只有局部地方面太密。

操作思路：

- 刀身平面可以大量简化。
- 护手外轮廓要保留。
- 剑柄圆柱段可以减少段数。
- 细小浮雕直接删或烘到贴图。

### 方案 C：重新生成低模友好模型

适合：

- 降到 8000 Tris 已经很丑。
- 护手和装饰全是大三角块。
- 骷髅、裂纹、浮雕密集。
- 轮廓本身就不清楚。

这种情况不要继续硬修。回到参考图和 Prompt，让 AI 从源头生成低模友好的武器。

## 第三课观看重点

你看第三课时，不需要平均用力。重点看这些：

### 必看

1. 为什么要用 Solid / Normal / Face Orientation 检查几何。
2. Mask 如何保护区域。
3. Grab 如何修大轮廓。
4. Smooth 如何清理脏表面。
5. Inflate 如何补洞和补薄。
6. Voxel Remesh 什么时候用，什么时候不用。
7. Apply Transform 为什么重要。

### 可以略看

1. 头部替换。
2. 手部替换。
3. 角色身体比例。
4. 衣服垂坠。
5. 角色绑定相关铺垫。

### 要转换成武器思维

课程讲角色时，经常追求“融合成一个封闭表面”。武器不一定每处都要这样。

武器更关注：

- 轮廓是否清楚。
- 硬边是否还在。
- 刀刃是否锋利。
- 护手是否读得出来。
- 低模后是否还能看出设计。

## 常见错误和处理

### 错误 1：还没修就直接降到 3000 面

结果：

- 大三角块。
- 装饰糊掉。
- 刀身破面。
- 贴图再好也救不回来。

处理：

先回到高模，修轮廓、删碎片、补大洞，再分阶段降面。

### 错误 2：把所有细节都当成必须保留

结果：

- 面数降不下去。
- 低模结构非常脏。
- Roblox 中视觉反而乱。

处理：

只保留大轮廓和关键结构。小裂纹、小花纹、小浮雕交给贴图。

### 错误 3：Smooth 把刀刃磨圆

结果：

- 武器变成橡皮泥。
- 低模风格不够利落。

处理：

刀刃附近用 Mask 保护，或者只对脏面局部 Smooth。

### 错误 4：Voxel Remesh 后武器变软

结果：

- 硬表面消失。
- 刀尖变厚。
- 护手边缘变糊。

处理：

武器模型优先局部修，不要默认整把 Voxel Remesh。必须 Remesh 时先复制测试。

### 错误 5：只看贴图，不看几何

结果：

- 贴图视图好看，Solid View 破碎。
- Roblox 里换光照后问题暴露。

处理：

每次修完都切换 Solid / Wireframe / Face Orientation 检查。

## 一次实际操作模板

你可以按这个流程练第一把 `10万面`武器：

```text
1. 导入模型。
2. 复制原始对象，放入 00_raw_original。
3. 复制修复对象，放入 01_repair_high。
4. Ctrl+A Apply All Transforms。
5. 打开 Statistics，记录 Faces / Tris。
6. Solid View 检查轮廓。
7. Face Orientation 检查外表面法线。
8. 删除漂浮碎片。
9. 修刀身、护手、剑柄、刀尖这些大结构。
10. 补明显孔洞。
11. 清理明显粘连。
12. 不修细小浮雕。
13. 复制到 02_lowpoly_test。
14. 用 Decimate 分阶段测试 8000 / 5000 / 3500 Tris。
15. 导出临时 FBX/GLB。
16. 放到 Roblox 纯色预览棚看效果。
```

## 每次修完要记录什么

建议在 `工作记录.md` 里记录：

```text
武器名：
原始面数：
修复后面数：
降面后 Tris：
主要修复问题：
哪些细节删掉了：
Roblox 导入是否成功：
预览效果：
下一次要调整的 Prompt：
```

这样你不是只修一把武器，而是在积累自己的 Roblox 武器资产流程。

## 最终掌握标准

你真正掌握“快速修模型”，不是会背笔刷名字，而是能在 10-20 分钟内判断：

1. 这个模型值得修，还是应该重新生成。
2. 哪些问题会影响 Roblox。
3. 哪些细节可以删。
4. 降面前必须修哪些地方。
5. 降到 `3000-4000 Tris`后，轮廓还能不能保住。

如果一个 `10万面`武器经过快速修复后，能稳定进入降面测试，并且在 Roblox 预览棚里远看成立，这一阶段就算达标。
